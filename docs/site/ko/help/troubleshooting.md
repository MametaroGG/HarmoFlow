# 문제 해결 {#troubleshooting}

증상에 따라 [실행 실패·갑작스러운 종료](#startup-checks), [GPU 오류](#gpu-errors), [복구 절차](./projects.md#gpu-recovery)를 먼저 확인하세요. 해결되지 않으면 [문의 양식](#report-template)을 이용하세요.

## 실행되지 않거나 갑자기 종료될 때 {#startup-checks}

### 먼저 보관할 정보와 데이터

- 오류 메시지 전체, 발생 시각, 직전 작업을 기록합니다. 화면을 캡처할 때는 개인정보나 공유할 수 없는 작품이 포함되지 않았는지 확인하세요.
- 앱이 응답하면 씬을 저장합니다. 내용이 누락된 것처럼 보이면 정상 저장본을 덮어쓰기 전에 “씬 다른 이름으로 저장”을 사용하세요.
- 원인을 확인하는 동안 프로젝트와 자동 저장을 보관합니다. 설정이나 자동 저장 폴더를 삭제하는 것을 첫 해결 방법으로 삼지 마세요.

### 안전한 확인 순서

1. [설치 절차](./start.md#app-install)를 확인하고 시작 메뉴의 HarmoFlow 또는 HarmoFlow Trial을 실행합니다. 다운로드가 불완전하면 BOOTH에서 같은 제품판의 설치 프로그램을 다시 받으세요. 설치된 파일을 함께 유지하고, `harmoflow.exe`만 옮기거나 알 수 없는 사이트에서 누락된 DLL을 구하지 마세요.
2. Windows와 Vulkan 1.2를 지원하는 GPU·드라이버를 사용하는지 확인합니다. 드라이버 업데이트는 PC 또는 GPU 제조사의 공식 배포처를 이용하세요. 앱 사용을 위해 Vulkan SDK를 설치할 필요는 없습니다.
3. 다른 앱의 작업을 저장한 뒤 게임·영상 편집기 등 GPU 부하가 큰 앱을 닫고 HarmoFlow를 다시 실행합니다. 필요하면 Windows도 다시 시작합니다.
4. 앱이 열리면 원본 프로젝트를 보관하고 작은 새 프로젝트와 낮은 작업 해상도로 확인합니다. 실행 직후인지, 특정 모델에서만 발생하는지, 해상도 변경·페인팅·내보내기 중인지 나누어 기록합니다.
5. 같은 오류가 반복되면 저장하지 않은 작업이 있는 상태에서 재현을 반복하지 말고 [진단 정보](#diagnostic-info)를 첨부해 문의하세요. Windows 경고나 보안 소프트웨어를 비활성화하고 진행하는 것은 권장하지 않습니다.

::: warning 갑자기 종료된 경우
모든 충돌 뒤에 복구 안내가 표시되는 것은 아닙니다. GPU 오류 후 복구는 복구용 자동 저장이 성공했고 해당 데이터를 이용할 수 있을 때만 가능합니다. 안내가 없으면 마지막 저장 씬이나 이용 가능한 [자동 저장](./projects.md#autosave-location)을 확인하세요. 저장하지 않은 모든 변경 사항의 복구를 보장하지는 않습니다.
:::

## GPU 오류 메시지에 따라 확인하기 {#gpu-errors}

| 메시지·증상 | 다음 확인 사항 |
| --- | --- |
| GPU 메모리(VRAM)가 부족합니다 | 다른 GPU 사용 앱을 닫고 텍스처 해상도를 낮춰 보세요. 파트(텍스처 세트)가 많을수록 메모리가 더 필요합니다. “환경 설정 → VRAM”에서 미리보기 메모리 사용량도 줄일 수 있습니다 |
| GPU가 응답하지 않습니다 | 부하가 큰 다른 앱을 닫고 공식 드라이버 업데이트를 확인합니다. 당시 작업과 응답이 멈추기 전 상황을 기록하세요 |
| GPU가 초기화되었습니다 | 절전 모드에서 복귀하거나 드라이버를 업데이트한 직후인지 기록합니다. 반복되면 공식 드라이버 업데이트를 검토하고 발생 조건을 알려 주세요 |
| 그 밖의 GPU 오류 | “상세 정보” 전체와 GPU 모델명, 드라이버 버전, 당시 작업을 기록하세요 |

메모리 부족 시에는 작업 이전 상태로 돌아가 앱을 계속 사용할 수 있는 경우도 있습니다. 앱이 열려 있으면 씬 상태를 확인하고 저장한 뒤 부하를 줄여 다시 시도하세요. 종료나 다시 시작을 요청하면 [GPU 오류 후 복구](./projects.md#gpu-recovery)를 따르세요. 해상도나 VRAM 설정은 한 번에 하나씩 바꾸면 원인을 파악하기 쉽습니다.

## UV가 테두리만 보일 때

::: details 해결 방법
“와이어 설정”의 표시를 “삼각형”으로 변경합니다. UV 셸 표시에서는 아일랜드의 외곽만 그려집니다.
:::

## 와이어가 너무 진하거나 촘촘해 보일 때

::: details 해결 방법
선 두께와 불투명도를 낮추거나 UV 셸 표시로 전환합니다. 텍스처 자체를 확인하려면 UV 와이어를 끌 수 있습니다.
:::

## 파트를 전환할 수 없을 때

::: details 해결 방법
불러온 모델에 파트가 하나뿐이면 전환 항목이 비활성화됩니다. 파트가 여러 개라면 채널 패널 위쪽에서 선택할 수 있습니다.
:::

## 메시 맵이 표시되지 않을 때

::: details 해결 방법
자동 베이크가 끝날 때까지 기다립니다. 오류가 표시되면 내용을 확인하고 “다시 베이크”를 시도하세요. 불러온 모델을 변경하면 이전 처리 결과는 폐기됩니다.
:::

## 레이어 패널 표시

레이어 패널의 톱니바퀴 메뉴에서 내용 미리보기 표시를 전환할 수 있습니다. 이 설정은 UI 레이아웃에 저장됩니다. 미리보기에는 그려진 머티리얼의 BaseColor가 작은 UV 이미지로 표시됩니다. 각 행을 위해 레이어 전체를 다시 베이크하지 않고 GPU 베이크 결과를 재사용합니다.

폴더 행은 페인트 레이어 행보다 낮게 표시되며, 선택한 행에는 안쪽 테두리가 표시됩니다. 레이어 이름의 위쪽 절반이나 아래쪽 절반으로 드래그하면 해당 삽입 위치에 선이 표시됩니다. 폴더 가운데로 드래그하면 테두리가 표시되고 폴더 안으로 이동합니다. 폴더의 맨 위나 맨 아래에서는 삽입 위치에 선이 표시되어, 하위 레이어를 포함한 폴더 전체의 앞뒤로 순서를 바꿀 수 있습니다. 폴더를 이동해도 하위 레이어는 유지되며 Undo/Redo도 지원합니다.

## 버전과 로그 확인하기 {#diagnostic-info}

- **버전**: “도움말 → HarmoFlow 정보”의 `v…`를 기록합니다. 제목 표시줄 중앙의 대괄호 안 빌드 시각도 보이면 함께 적어 주세요. 앱이 실행되지 않으면 다운로드한 배포 파일 이름과 버전을 적습니다.
- **GPU와 Windows**: Windows 버전, GPU의 정확한 모델명, VRAM 용량, 그래픽 드라이버 버전을 기록합니다. GPU가 여러 개라면 확인할 수 있는 모델을 모두 적어 주세요.
- **앱 로그**: “창 → 콘솔”에서 처리 결과를 확인하고 “복사”로 텍스트를 가져올 수 있습니다. 콘솔에는 현재 실행 중의 기록이 최대 5,000개까지 메모리에 보관됩니다. 다시 실행한 뒤 이전 기록을 읽을 수 있는 영구 로그 파일은 아닙니다. 가능하면 종료·다시 시작·지우기 전에 기록을 보관하세요.

::: tip 로그 복사와 공유
콘솔 표시를 필터링해도 “복사”는 보관 중인 로그 전체를 복사합니다. 텍스트 편집기에 붙여 넣고 발생 시각 전후 등 관련 부분만 남기세요. 사용자 이름, 로컬 전체 경로, 비공개 파일 이름은 가려 주세요. 실행되지 않아 로그를 수집할 수 없다면 그 사실과 오류 메시지 내용을 알려 주면 됩니다.
:::

## 문의 양식 {#report-template}

아래 양식을 복사해 아는 항목을 작성하고 [豆々庵 BOOTH 상점](https://mametarovv.booth.pm/)을 통해 판매자에게 문의하세요. 모르는 항목은 “알 수 없음”으로 적어도 됩니다. 비밀번호나 구매 시 결제 정보는 적지 마세요.

```text
문제 요약:
HarmoFlow 버전 / 정식판 또는 체험판:
빌드 시각(알고 있다면):
Windows 버전:
GPU 모델명 / VRAM 용량 / 드라이버 버전:
발생 날짜와 시각:
수행 중이던 작업:
재현 순서: 1. … 2. … 3. …
기대한 결과 / 실제 결과:
발생 빈도(매번 / 가끔 / 한 번):
새 프로젝트에서도 발생하는지 / 특정 데이터에서만 발생하는지:
모델 형식, 파트 수, 작업 해상도(알고 있다면):
추가 플러그인 유무, 이름, 버전:
오류 메시지 전체:
마지막 정상 저장 시점 / 복구 안내와 복구 결과:
시도한 해결 방법과 결과:
첨부(관련 로그, 이미지, 재현용 샘플):
샘플 공유 가능 여부 / 공유 범위 제한:
```

처음부터 프로젝트 전체를 보낼 필요는 없습니다. 로그·이미지·샘플은 필요한 최소 범위로 제한하고, 미공개 작품·고객 정보·제삼자 에셋이 포함되지 않았는지 확인하세요. 구매한 에셋은 재배포 조건을 확인해야 합니다. 공유 허가가 없으면 같은 문제를 재현하는 작은 자체 제작 샘플로 바꾸거나 데이터를 공유할 수 없다고 알려 주세요.
