# 플러그인 설치 및 관리 {#plugins}

플러그인은 HarmoFlow에 조작 패널이나 이미지 필터를 추가하는 기능입니다. 이 페이지에서는 **전달받은 파일을 사용하는 방법**을 설명합니다. 직접 만들려면 [플러그인 만들기](./plugin-development.md)를, 처음부터 사용할 수 있는 색조 보정·톤 커브·그라데이션 맵은 [기본 조정 기능](./adjustments.md)을 참고하세요.

## 먼저 파일 형식 확인하기 {#plugin-types}

| 형식 | 추가·실행 위치 | 주요 용도 |
| --- | --- | --- |
| Lua 확장(`.lua`) | 플러그인 → 플러그인 추가／보기... | 슬라이더와 버튼이 있는 패널을 등록하여 레이어 작업을 모아 실행 |
| DLL 플러그인(`.dll`) | 같은 추가 화면 | 네이티브 코드로 이미지 필터 등을 등록. Windows x64용 빌드 필요 |
| 일반 Lua 스크립트(`.lua`) | 창 → 스크립트 (Lua) → 실행／파일 실행... | `hf` API 처리를 한 번 실행. 패널 등록과는 별개의 기능 |

**확장자가 같은 `.lua`라도 일반 스크립트와 플러그인용 확장은 다릅니다.** 플러그인으로 추가하는 Lua에는 패널을 등록하는 `hf.register_panel`이 필요합니다. 일반 스크립트를 추가 화면에 전달해도 기대한 플러그인 패널이 만들어지지 않습니다.

::: warning 추가하기 전에
작업 중인 씬을 저장하고 배포처와 지원하는 HarmoFlow 버전을 확인하세요. DLL은 앱과 같은 프로세스에서 실행되는 네이티브 코드입니다. Lua 확장에도 제한은 있지만, 안전을 보장하는 격리 환경은 아닙니다. 신뢰할 수 있는 제작자의 파일만 사용하세요.
:::

## 추가부터 실행까지 {#install-plugin}

1. 상단의 “플러그인 → 플러그인 추가／보기...”를 엽니다.
2. “플러그인 추가...”에서 배포받은 `.lua` 또는 `.dll`을 선택합니다.
3. 파일이 앱의 저장 위치로 복사되고 로드가 시작됩니다. Lua 확장은 그리기와 진행 중인 다른 작업이 끝난 뒤 등록됩니다. 추가 완료가 표시되어도 Lua 확장 목록에서 등록 결과를 확인하세요.
4. 상단의 “플러그인” 메뉴를 다시 열고 등록된 항목을 선택합니다. **추가·찾아보기 화면은 관리용이며, 실행은 플러그인 메뉴에서 합니다.**
5. 작은 테스트용 씬에서 처리 결과를 확인합니다. 레이어를 추가하는 확장이라면 레이어 목록에 의도한 결과가 만들어졌는지도 확인하세요.

추가한 파일은 다음 시작 시 로드 대상이 됩니다. 실행 메뉴에 항목이 없다면 [정상적으로 로드되지 않을 때](#plugin-troubleshooting)를 참고하세요.

현재 구현은 시작할 때 파일 이름순으로 앞의 Lua 파일 16개까지만 로드를 시도합니다. 실행 중에는 확장을 최대 32개까지 로드할 수 있지만, 재시작 후에도 모두 자동으로 로드하려면 `extensions/` 바로 아래의 `.lua` 파일을 16개 이하로 유지하세요.

## 어디에 저장되나요? {#plugin-folders}

앱에서 추가하면 **HarmoFlow 실행 파일과 같은 위치**에 있는 다음 폴더에 저장됩니다. 프로젝트 폴더에 넣는 파일이 아닙니다.

```text
HarmoFlow 실행 파일이 있는 폴더/
├─ extensions/
│  └─ my_panel.lua
└─ plugins/
   └─ my_filter.dll
```

수동으로 배치할 때도 같은 위치를 사용합니다. 시작 시에는 각 폴더 **바로 아래**에 있는 파일을 검색합니다. ZIP 상태로 두거나 더 깊은 하위 폴더에 넣지 말고, 소문자 `.lua`／`.dll` 확장자를 사용하세요. 추가 화면에서 복사하면 확장자는 소문자로 통일됩니다.

추가 화면에는 같은 이름의 파일을 덮어쓰는 기능이 없습니다. 같은 이름이 이미 있다면 아래 업데이트 절차를 따르세요.

## 업데이트·삭제하기 {#update-plugin}

1. 씬을 저장하고 HarmoFlow를 종료합니다.
2. Lua 확장은 `extensions/`, DLL은 `plugins/`에서 해당 파일을 확인합니다.
3. 업데이트하려면 기존 파일을 다른 위치에 백업한 뒤 새 파일로 교체합니다. 더 이상 사용하지 않으려면 해당 폴더 밖으로 옮깁니다.
4. HarmoFlow를 다시 시작하고 목록의 로드 상태와 메뉴 항목을 확인합니다.

실행 중 다시 로드·언로드·삭제하는 전용 기능은 없습니다. 같은 DLL을 다시 로드하거나, 같은 패널 ID를 가진 Lua 확장을 다른 이름으로 추가해도 업데이트되지 않습니다. 백업 파일을 `.dll`／`.lua` 확장자 그대로 같은 폴더에 남겨 두면 시작 시 로드 대상이 되므로 다른 위치에 보관하세요.

## 정상적으로 로드되지 않을 때 {#plugin-troubleshooting}

| 증상·표시 | 확인할 사항 |
| --- | --- |
| 같은 이름의 파일이 있음／추가할 수 없음 | 같은 이름의 파일은 덮어쓰지 않습니다. 앱을 종료하고 기존 파일을 확인한 뒤 교체하세요 |
| Lua 추가 후 메뉴에 항목이 없음 | 목록의 Lua 로드 결과를 확인하세요. 일반 스크립트가 아니라 `hf.register_panel`로 패널을 등록하는 확장인지 확인하세요 |
| 재시작 후 일부 Lua 확장이 없음 | 시작 시 파일 이름순으로 앞의 16개 파일만 로드를 시도하며, 잘못된 파일도 개수에 포함됩니다. `extensions/` 바로 아래의 `.lua` 파일 수를 확인하세요 |
| Lua 패널 ID가 중복됨 | `extensions/`에 같은 확장의 이전 버전이나 복사본이 남아 있는지 확인하세요 |
| `Could not load DLL` | Windows x64용인지, 필요한 런타임 라이브러리와 종속 DLL이 모두 있는지 제작자의 설명과 대조하세요 |
| `DLL exports no hf_plugin_init` | HarmoFlow용 진입점을 찾지 못했습니다. 다른 앱용 DLL이거나 빌드 설정이 잘못되었을 수 있습니다 |
| `Plugin init failed or wrong API version` | 플러그인이 지원하는 버전을 확인하고 제작자에게 로드 결과를 전달하세요 |
| `Already loaded` | 같은 DLL은 다시 로드할 수 없습니다. 업데이트할 때는 앱을 종료하고 파일을 교체한 뒤 다시 시작하세요 |
| 수동으로 배치한 파일을 찾을 수 없음 | 앱 옆의 올바른 폴더 바로 아래에 있는지, 확장자가 소문자인지, ZIP 압축을 풀었는지 확인하세요 |

다른 사이트에서 출처가 불분명한 DLL을 찾아 추가하기 전에 배포처의 요구 사항을 확인하세요. 문제를 보고할 때는 HarmoFlow와 플러그인의 버전, 파일 이름, 표시된 오류, 추가한 절차를 함께 전달하면 원인을 찾기 쉽습니다.
