## UV 에디터에서 그리기와 이동하기

페인트 도구와 페인트 레이어를 선택한 뒤 UV 에디터의 캔버스를 드래그하면, 대응하는 모델 표면에 그릴 수 있습니다. 마우스 휠로 확대/축소하고, 가운데 버튼 드래그 또는 Space + 왼쪽 드래그로 화면을 이동합니다. Shift + Space + 왼쪽 또는 오른쪽 드래그로 화면을 회전할 수 있습니다. Shift + Space + 왼쪽 또는 오른쪽 더블 클릭으로 각도만 초기화할 수 있으며, 확대/축소 배율과 표시 위치는 유지됩니다. “전체 보기”는 회전·이동·확대/축소를 모두 초기화합니다. 이동과 회전 중에는 전용 커서가 표시됩니다. 패스의 앵커 편집에도 사용할 수 있습니다. UV 배치 자체를 다시 펼치는 도구는 아닙니다.

텍스트·도형·이미지 스탬프는 뷰포트에서 Ctrl + Alt + 드래그로 크기를, Shift + Space + 드래그로 각도를 조절할 수 있습니다. 두 조작 모두 왼쪽 버튼과 오른쪽 버튼을 지원합니다.

## 와이어와 배경 조절하기

“UV 와이어”로 선 표시를 전환하고, “와이어 설정”에서 색상·불투명도·선 두께를 조절합니다. 기본값은 가는 와이어입니다.

- **삼각형** — 내부 모서리도 표시합니다. 감지된 유사 사각형의 대각선은 숨길 수 있습니다.
- **UV 셸** — UV 아일랜드의 외곽을 표시합니다. 사각형 아일랜드는 테두리만 표시됩니다.
- **전체 보기** — 확대하거나 이동한 화면을 전체가 보이는 상태로 되돌립니다.

배경에서는 BaseColor 등의 채널과 이미 생성된 곡률·AO·노멀·위치 맵을 선택할 수 있습니다.
