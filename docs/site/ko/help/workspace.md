## 파이 메뉴로 도구 전환하기 {#pie-menu}

Ver.0.1.1에서는 3D 뷰포트와 UV 캔버스에서 커서 주위에 파이 메뉴를 열 수 있습니다.

1. 3D 뷰포트 또는 UV 캔버스 위에서 마우스 오른쪽 버튼을 누릅니다.
2. 버튼을 누른 채 원하는 항목 방향으로 슬라이드합니다.
3. 오른쪽 버튼을 놓으면 해당 항목이 선택됩니다. Esc를 누르면 취소됩니다. 슬라이드하지 않고 버튼을 놓아도 선택 없이 메뉴가 닫힙니다.

브러시 페인트, 색 혼합, UV 셸 채우기 등의 도구를 작업 위치 가까이에서 전환할 수 있습니다. 카메라 조작이나 브러시 크기 조절처럼 기존에 지정된 오른쪽 버튼 조작은 해당 조합 키를 누르면 우선 적용됩니다. 키보드와 마우스 조작은 [단축키 참고](./shortcuts.md)를 확인하세요.

파이 메뉴를 여는 동작은 고정되어 있습니다. 열리지 않으면 Ctrl·Shift·Alt 등의 보조 키를 놓고 그리기나 텍스트 입력을 끝낸 뒤 다시 시도하세요.

## 텍스처 세트와 메시 파트

HarmoFlow의 텍스처 세트는 메시 파트 단위로 구성됩니다. 같은 머티리얼을 사용하는 파트도 각각 별도의 텍스처 세트로 취급합니다.

일반 브러시와 스탬프는 선택한 기존 레이어가 속한 텍스처 세트에 그려집니다. 다른 파트에 그리려면 레이어 패널 위쪽 목록에서 세트를 바꾸거나 모델을 Shift+Alt+오른쪽 클릭하세요. 에셋 브라우저에서 새 머티리얼을 칠할 때도 현재 선택한 텍스처 세트가 대상입니다. 칠하기 전에 대상 세트를 선택하세요. 다른 텍스처 세트에는 자동으로 적용되지 않습니다.

## 패널별 기능

| 패널 | 기능 |
| --- | --- |
| 레이어 | 페인트와 Fill을 겹치고 표시·불투명도·합성 조절 |
| 채널 | 파트 선택, 작업 해상도와 각 채널 확인 |
| 텍스처 세트 설정 | 레이어 옆의 탭. 채널과 메시 맵 확인 |
| UV 편집기 | 선택한 파트의 텍스처와 UV 와이어 확인 |

## 패널 열기와 배치 초기화

닫은 패널은 “창” 메뉴에서 다시 표시할 수 있습니다. 배치를 되돌리려면 “레이아웃 초기화”를 사용하세요. 각 항목 위에 커서를 올리면 조작에 관한 도움말이 표시됩니다.
