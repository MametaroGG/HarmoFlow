# 모서리와 오목한 곳에 웨더링 추가하기 {#weathering}

## 형상에 맞춰 웨더링 배치하기

1. **웨더링용 Fill 레이어 선택하기**

   프로시저럴 패턴을 활성화하고 색상이나 Roughness 등을 조절합니다.

2. **“메시 배치” 선택하기**

   “볼록한 모서리”, “오목한 모서리”, “차폐된 오염 (AO)” 중에서 선택합니다. “전체 표면”은 형상으로 범위를 제한하지 않는 배치입니다.

   메시 맵을 베이크하는 중이면 배치가 갱신될 때까지 기다립니다. 결과가 갱신되지 않으면 표시된 오류를 확인하고 “메시 맵 다시 베이크”를 사용하세요.

3. **강도와 패턴 조절하기**

   “메시 영향도”로 형상의 영향을 조절하고, “강도”, “스케일” 등으로 웨더링 분포를 다듬습니다.

## 설정 저장과 UV 변형

형상에 따른 배치에는 채우기 이미지의 UV 변형이 적용되지 않습니다. 배치 설정은 씬과 머티리얼 프리셋에 저장되며, Undo/Redo도 지원합니다.
