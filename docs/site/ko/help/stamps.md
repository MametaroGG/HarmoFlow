# 스탬프·텍스트·도형 {#stamps}

## 모델에 스탬프 배치하기

<GuideMedia name="stamp-settings" />

스탬프 패널에는 이미지, 텍스트, 도형, Clone(복제) 탭이 있습니다. 이미지·텍스트·도형은 설정한 뒤 “모델에 배치”를 선택하고 모델을 클릭합니다. 페인트로 배치되므로 배치 후에는 원래 텍스트나 도형 매개변수를 직접 편집할 수 없습니다. 수정하려면 Undo로 되돌리고 다시 설정하거나 전용 레이어에서 다시 그리세요.

“Clone”에서 스포이드와 같은 조작으로 모델 위의 복제 원본을 지정합니다. 기본 조작은 Ctrl+Shift+왼쪽 마우스 버튼이며, 버튼을 놓으면 확정됩니다. 이후 페인트 레이어에서 드래그하면 원본을 지정한 시점의 합성된 BaseColor를 복사하여 칠할 수 있습니다.

“Aligned”를 켜면 스트로크 사이에도 원본과 대상의 상대 위치를 유지합니다. 끄면 각 스트로크가 원본 위치에서 다시 시작됩니다. Normal 등 다른 채널이나 조명이 반영된 화면 색상을 복사하는 기능은 아닙니다.

## 이미지·텍스트·도형 설정

| 탭 | 설정과 용도 |
| --- | --- |
| 이미지 | 이미지를 추가하거나 드롭하고, 크기·불투명도·회전을 설정하여 무늬나 데칼을 배치합니다. 프로젝트 이미지를 오른쪽 클릭하고 “Register as Image Stamp”를 선택하면 이미지 탭에서 사용할 수 있습니다. |
| 텍스트 | 입력 문구, 시스템 글꼴, 크기, 불투명도, 자간, 줄 간격, 정렬, 회전 지정 |
| 도형 | 사각형·타원·다각형·별 선택. 채우기, 선 두께, 꼭짓점 수, 별의 안쪽 반지름 비율, 크기, 불투명도, 회전 설정 |

## 텍스트 꾸미기와 미리보기

텍스트는 글꼴 검색·즐겨찾기, 굵게, 대문자 변환, 밑줄, 취소선을 지원합니다. T로 텍스트 배치를 시작할 수 있습니다. 텍스트/도형 미리보기에서는 불투명도 반영 여부를 전환할 수 있습니다. 스탬프 불투명도는 브러시와 독립적인 설정입니다.
