## 그리기의 기본

페인트 레이어를 선택하고 B로 페인트 도구로 전환한 뒤 모델 위를 드래그합니다. 스트로크는 표면의 위치·법선 등의 정보로 유지되며, 현재 UV에 베이크됩니다. 여러 PBR 채널을 활성화하면 색상과 거칠기 등을 같은 스트로크로 그릴 수 있습니다.

| 설정 | 효과 |
| --- | --- |
| 크기 | 획의 굵기. 대괄호 키 또는 Ctrl+Alt+가로 드래그로도 조절 가능 |
| 경도 | 브러시 팁 가장자리의 흐림 정도. 낮출수록 가장자리가 부드러워짐 |
| 불투명도 | 한 번 그릴 때의 진하기. 레이어 전체의 불투명도와는 별개 |
| 간격 | 브러시 팁을 배치하는 거리. 높이면 점 사이가 더 벌어짐 |
| 흔들림 보정 | 입력 경로의 흔들림을 줄이는 강도 |
| 필압 크기 | 펜의 필압을 크기에 반영 |
| 브러시 팁 | 원형 팁 또는 가져온 이미지 팁 선택 |
| 대칭 | 선택한 X / Y / Z축을 기준으로 대칭 그리기 |
| 다중 채널 그리기 | 그릴 채널의 활성화 여부와 값 설정 |

브러시 패널에서 카테고리별로 프리셋을 선택하고, 조절한 설정을 프리셋으로 저장할 수 있습니다. “PNG 브러시 가져오기”로 사용자 지정 팁을 추가할 수 있습니다. 지우개는 전용 패널에서 크기와 팁 등을 조절합니다.

프로젝트 안의 이미지를 오른쪽 클릭하고 “Register as Brush Tip”을 선택하여 브러시 패널에서 사용할 수도 있습니다.

U를 누르거나 손가락 아이콘을 클릭하여 “Color blending”을 엽니다. 페인트 레이어를 선택하고 3D 뷰 또는 UV 에디터에서 드래그하세요. 선택한 색을 더하지 않고 이미 그려진 색을 사용합니다.

- Blur(흐림): 경계를 부드럽게 처리
- Color mix(색 혼합): 주변 색을 섞기
- Fingertip(손가락): 스트로크 방향으로 색을 늘이기
- Bristle blend(붓 혼합): 미세한 질감을 남기며 섞기

크기, 강도, 농도 등의 설정은 브러시별로 유지됩니다. B를 누르면 일반 페인트로 돌아갑니다. 마스크나 머티리얼이 칠해진 영역의 경계를 부드럽게 할 때도 사용할 수 있습니다.

## 면과 UV 아일랜드 채우기

폴리곤 채우기는 클릭한 면을, UV 셸 채우기는 해당 면이 속한 UV 아일랜드를 채웁니다. 커서를 올렸을 때의 하이라이트로 대상 범위를 확인한 뒤 클릭하세요. “유사 사각형 반영”은 감지한 삼각형 쌍을 하나의 사각형으로 취급하는 설정입니다.

### 머티리얼로 칠하기

머티리얼 브라우저에서 머티리얼을 선택한 뒤 브러시로 모델에 칠할 수 있습니다. 도구 모음의 “폴리곤 채우기”와 “UV 셸 채우기”는 3D 뷰 또는 UV 에디터에서 클릭한 영역에 색상, 노멀, 거칠기 등을 함께 적용합니다. 머티리얼을 바꿔도 현재 칠하기 방식은 유지됩니다.

이미 칠한 머티리얼 레이어나 머티리얼 폴더를 선택하면 같은 소재로 더 칠할 수 있습니다. 지우개는 브러시 범위의 적용 영역을 지웁니다. 기존 레이어에 일반적으로 그릴 때는 해당 레이어의 텍스처 세트가 대상입니다. 라이브러리에서 새 머티리얼을 칠하기 시작할 때는 처음 닿은 파트가 대상이 됩니다.

## 스포이드와 팔레트

페인트 도구에서 Ctrl+Shift를 누르면 모델의 합성된 BaseColor를 미리 볼 수 있습니다. Ctrl+Shift+왼쪽 버튼을 누른 채 움직이다가 마우스 버튼을 놓으면 색상을 선택합니다. 마우스 버튼보다 먼저 Ctrl+Shift를 놓으면 취소됩니다. 조명이 반영된 화면 색상이 아닌 BaseColor에서 색상을 추출합니다.

“색상 팔레트”에는 색상 조절, 유사 색상, 색상 히스토리, 믹서가 있습니다. 믹서 위를 드래그해 색상을 섞고, 오른쪽 클릭 또는 Alt로 색상을 추출합니다. “스와치”는 저장한 색상을 선택하는 패널이며, 불필요한 색상은 오른쪽 클릭 메뉴에서 삭제할 수 있습니다.
