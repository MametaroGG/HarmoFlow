# 단축키 한눈에 보기 {#shortcuts}


## 키보드와 마우스 그림으로 확인하기 {#visual-key-config}

Ver.0.3.0의 키 설정에서는 키보드와 마우스 그림으로 할당을 확인하고 편집할 수 있습니다. 키별 필터링, 탐색 키와 숫자 키패드 표시, 일본어·영어·한국어·중국어 배열 표시를 지원합니다. 긴 단축키가 잘리는 문제도 개선했습니다.

저장된 설정이 있으면 아래 초기 할당 표보다 앱에 표시되는 현재 할당을 우선하세요.

### 선택 도구 조작(Ver.0.3.0) {#selection-tool-shortcuts}

Ver.0.3.0에서 M은 선택 영역을 호출하고 S는 브러시 계열 도구의 대칭을 전환합니다. Ctrl+T는 선택한 페인트 변형, K는 레이어 이동을 호출합니다. 사각형·타원·올가미·다각형·선택 펜·선택 지우개·슈링크·메시 선택 등 개별 도구는 처음에 미할당입니다. 도구 목록이나 파이 메뉴에서 선택하거나 키 설정에서 할당하세요. 이전의 V·W·E·R 등을 현재 기본 키로 사용하지 마세요.

- 사각형이나 타원 선택 중 Shift를 누르면 정사각형이나 원을 만들 수 있습니다
- 선택 펜과 선택 지우개는 필압과 브러시 크기 단축키를 지원합니다. 현재 할당은 키 설정에서 확인하세요
- 선택한 페인트를 이동·회전·확대 및 축소할 수 있습니다. 도구 사용법은 [페인트 선택과 변형](./brush.md#paint-selection-transform)을 참조하세요
## 키 설정 확인과 변경

“환경 설정 → 키 설정”에서 왼쪽의 작업 이름 검색과 단축키 검색을 전환한 뒤 작업을 선택합니다. 오른쪽에는 선택한 작업의 현재 할당이 표시됩니다. 할당 버튼을 클릭하여 편집하거나 “+ 추가”로 다른 할당을 추가합니다. 할당이 없는 작업은 목록에 미할당으로 표시됩니다.

키보드와 마우스 그림에서 색이 있는 키는 이미 할당된 키입니다. 키를 선택하면 작업 목록을 필터링할 수 있습니다. 키보드 배열 선택과 Ctrl, Shift, Alt 컨트롤이 있으며, 이동 키와 숫자 키패드는 접을 수 있는 영역에 모여 있습니다.

할당 창에서 “기본값으로 재설정”, “Remove”(제거), “취소”를 사용할 수 있습니다. 고정 작업은 변경할 수 없습니다. 일반 왼쪽 클릭이나 동시에 사용되는 작업과 충돌하는 조합은 할당할 수 없습니다. 원하는 입력을 다른 작업이 사용 중이라면 먼저 기존 할당을 확인하세요.

아래 이미지는 작업 목록과 키보드 및 마우스 그림이 있는 키 설정 화면입니다.

할당 추가·변경·제거·기본값 복원은 즉시 저장됩니다.

### 패스

C·F는 패스 작도 중 뷰포트 위에서 사용합니다. Delete 또는 Backspace는 작도 중 마지막 앵커를 삭제하고, 기존 패스를 편집할 때는 선택한 앵커를 삭제합니다.

Esc는 미완성 작도를 취소합니다. 3D 뷰포트에서 기존 패스를 재편집 중이면 변경 내용을 유지하고 편집을 끝냅니다.

패스 닫기의 초기 할당은 C이며, 투명색 전환도 C를 사용합니다. 저장된 설정을 불러오면 패스 닫기가 미할당 상태가 될 수 있습니다. 미할당으로 표시되면 다른 작업과 충돌하지 않는 키를 지정하세요.

| 작업 | 키·마우스 조작과 조건 |
| --- | --- |
| 열린 패스 완료 | Enter<br>작도 중 또는 3D에서 패스 재편집 중 |
| 패스 취소 | Esc<br>작도 중 또는 3D에서 패스 재편집 중 |
| 마지막 앵커 제거 | Delete / Backspace<br>작도 중 |
| 패스 닫기 | 키 설정에서 확인(초기 등록: C)<br>작도 중 3D 뷰포트 위에서 |
| 패스 닫고 채우기 | F<br>작도 중 3D 뷰포트 위에서 |
| 선택한 앵커 삭제 | Delete / Backspace<br>3D 뷰포트 또는 UV 편집기에서 앵커 선택 시 |
