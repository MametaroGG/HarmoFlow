# 단축키 한눈에 보기 {#shortcuts}

## 키 설정 확인과 변경

조작하는 패널이나 도구에 따라 키의 의미가 달라집니다. 입력 창을 편집 중일 때는 도구 조작이 동작하지 않을 수 있습니다.

“환경 설정 → 키 설정”에서 작업 이름이나 조건으로 검색하여 키보드와 마우스 할당을 변경할 수 있습니다. “+” 버튼이 있는 작업에는 다른 할당을 추가할 수 있습니다. 일반, 편집, 파일, 도구, 그리기, 레이어, UV 편집기 등의 작업을 설정할 수 있습니다.

고정 작업은 변경할 수 없습니다. 일반 왼쪽 클릭이나 동시에 사용하는 작업과 충돌하는 조합은 할당할 수 없습니다. 아래 표는 기본 할당입니다.

## 작업과 키·제스처

| 작업 | 키·제스처 |
| --- | --- |
| 파이 메뉴 | 오른쪽 버튼을 누른 채 슬라이드하고 놓아서 선택. Esc로 취소 (3D 뷰포트／UV 캔버스, 기존 오른쪽 버튼 설정 우선) |
| 페인트 / 색 혼합·흐림 / 패스 / 텍스트 | B / U / P / T |
| 카메라 회전 | Alt+왼쪽 드래그 |
| 카메라 확대/축소 | 휠, Alt+오른쪽 드래그, Ctrl+왼쪽 드래그(오른쪽 또는 위로 확대, 왼쪽 또는 아래로 축소) |
| 카메라 이동 | 가운데 드래그, Space+왼쪽 드래그 |
| 레이어 복사／잘라내기／붙여넣기／복제 | Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D(레이어 패널에 포커스가 있을 때) |
| 레이어 삭제 | Delete(레이어 패널에 포커스가 있을 때) |
| 커서 아래의 텍스처 세트 열기 | Shift+Alt+오른쪽 클릭 |
| UV 캔버스 이동 | 가운데 드래그 또는 Space+왼쪽 드래그 |
| 브러시 크기 | [ / ], Ctrl+Alt+왼쪽 또는 오른쪽 버튼으로 가로 드래그 |
| 스포이드 | 페인트 중 Ctrl+Shift+왼쪽 버튼, 놓아서 색상 선택 |
| 선택 추가·해제 | 선택 도구에서 Shift+클릭 |
| 열린 패스 확정 / 닫기 / 닫고 채우기 | Enter / C / F(C·F는 패스 작도 중 뷰포트 위에서) |
| 패스 작도 취소 / 작도 중 마지막 앵커 삭제 | Esc / Delete 또는 Backspace |
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 저장 / 버전 번호를 늘려 저장 | Ctrl+S / Ctrl+Alt+S |
| 환경 설정 | Ctrl+, |
| 뷰포트 촬영 | F12 |
| 엔진 일시 정지 | Shift+Esc |

Delete 또는 Backspace는 패스 작도 중 마지막 앵커를 삭제합니다. 기존 패스를 편집할 때는 선택한 앵커를 삭제합니다.
