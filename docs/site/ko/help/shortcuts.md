# 단축키 한눈에 보기 {#shortcuts}

## 키 설정 확인과 변경

“환경 설정 → 키 설정”에서 작업 이름, 조건 또는 할당으로 검색할 수 있습니다. 할당을 클릭하면 변경하고, “+”로 다른 할당을 추가합니다. “더하기”가 표시된 작업은 미할당 상태이며, 이 버튼으로 할당을 추가합니다. 변경 사항은 작업별로 저장됩니다.

할당 창에서 “기본값으로 재설정”, “Remove”(제거), “취소”를 사용할 수 있습니다. 고정 작업은 변경할 수 없습니다. 일반 왼쪽 클릭이나 동시에 사용되는 작업과 충돌하는 조합은 할당할 수 없습니다. 원하는 입력을 다른 작업이 사용 중이라면 먼저 기존 할당을 확인하세요.

아래 표는 Ver.0.1.1의 초기 할당과 고정 조작입니다. 저장된 설정이 있다면 키 설정에 표시된 할당을 우선하세요. 텍스트를 입력하거나 환경 설정 또는 파이 메뉴를 연 동안에는 도구 키보드 단축키를 사용할 수 없습니다. 앱에서 영어로 표시되는 일부 작업 이름은 표에도 그대로 표기했습니다.

Ver.0.1.1에서는 창 포커스 이동과 “Toggle Corner / Smooth”에 표의 기본 조작을 사용하세요. 키 설정에서 바꿔도 실제 조작에 반영되지 않을 수 있습니다.

### 패스

C·F는 패스 작도 중 뷰포트 위에서 사용합니다. Delete 또는 Backspace는 작도 중 마지막 앵커를 삭제하고, 기존 패스를 편집할 때는 선택한 앵커를 삭제합니다.

Esc는 미완성 작도를 취소합니다. 3D 뷰포트에서 기존 패스를 재편집 중이면 변경 내용을 유지하고 편집을 끝냅니다.

패스 닫기의 초기 할당은 C이며, 투명색 전환도 C를 사용합니다. 저장된 설정을 불러오면 패스 닫기가 미할당 상태가 될 수 있습니다. “더하기”가 표시되면 다른 작업과 충돌하지 않는 키를 지정하세요.

| 작업 | 키·마우스 조작과 조건 |
| --- | --- |
| 열린 패스 완료 | Enter<br>작도 중 또는 3D에서 패스 재편집 중 |
| 패스 취소 | Esc<br>작도 중 또는 3D에서 패스 재편집 중 |
| 마지막 앵커 제거 | Delete / Backspace<br>작도 중 |
| 패스 닫기 | 키 설정에서 확인(초기 등록: C)<br>작도 중 3D 뷰포트 위에서 |
| 패스 닫고 채우기 | F<br>작도 중 3D 뷰포트 위에서 |
| 선택한 앵커 삭제 | Delete / Backspace<br>3D 뷰포트 또는 UV 편집기에서 앵커 선택 시 |
| Toggle Corner / Smooth | 왼쪽 더블 클릭<br>3D 뷰포트에서 재편집 중인 기존 패스의 앵커 위 |
