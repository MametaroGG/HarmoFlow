# 색조 보정·톤 커브·그라디언트 맵 {#adjustments}

세 효과 모두 아래 레이어의 합성 결과를 보정하며 원래 그린 내용은 유지합니다. 전체 밝기와 색감을 다듬으려면 **색조 보정**, 어두운 부분·중간 톤·밝은 부분을 나누어 조절하려면 **Tone Curve(톤 커브)**, 밝기에 따라 새로운 색을 배정하려면 <strong>Gradient Map(그라디언트 맵)</strong>을 선택하세요.

## 추가하고 다시 편집하기 {#add-and-edit}

1. 레이어 패널에서 대상 텍스처 세트와 보정을 추가할 위치를 선택합니다.
2. 반원 모양의 “New adjustment layer” 아이콘을 누른 뒤 “색조 보정”, “Tone Curve” 또는 “Gradient Map”을 선택합니다.
3. 새 레이어를 선택하고 속성에서 “대상 채널”과 보정값을 설정합니다. 색상을 바꾸려면 먼저 BaseColor를 선택하세요.
4. 레이어 표시를 켜고 끄며 결과를 비교합니다. 나중에 같은 레이어를 선택하면 다시 편집할 수 있습니다. 레이어를 옮기면 영향을 받는 아래쪽 내용도 달라집니다.

대상 채널은 BaseColor·Normal·Roughness·Metallic·Height·Emission입니다. 조정 레이어 하나는 선택한 채널 하나에 영향을 줍니다. Roughness·Metallic·Height는 수치 분포이므로 단순한 색상 변경과 구분하여 조절하세요.

[플러그인](./plugins.md)에서 같은 효과를 여는 방법도 있습니다. “대상 텍스처 세트”와 “대상 채널”을 선택하고 뷰포트의 실시간 미리보기를 확인한 뒤 “적용”을 누르면 다시 편집할 수 있는 조정 레이어가 추가됩니다. “취소”를 누르거나 보정 창에 포커스가 있을 때 Esc를 누르면 원래 표시로 돌아갑니다.

현재 버전에서는 일부 컨트롤이 영어로 표시됩니다. 아래 조작 절차에는 실제 화면의 이름을 사용합니다.

## 색조 보정 {#color-adjustment}

다시 칠하지 않고 전체 밝기, 색의 선명도와 색상을 바꿀 때 사용합니다.

| 항목 | 범위 / 기본값 | 효과 |
| --- | --- | --- |
| 밝기 | −1~1 / 0 | 전체를 밝게 또는 어둡게 조절 |
| 대비 | 0~3 / 1 | 밝고 어두운 부분의 차이를 줄이거나 늘림 |
| 채도 | 0~3 / 1 | 0은 무채색, 1은 원래 채도, 높이면 더 선명해짐 |
| 색조 | −180~180 / 0 | 색상환을 회전하여 색감을 바꿈 |
| 감마 | 0.1~3 / 1 | 중간 톤 조절. 1보다 크면 밝아지고 작으면 어두워짐 |

밝기와 대비를 조금씩 조절한 다음 채도와 색상을 맞추고, 마지막에 감마로 다듬으면 변화를 확인하기 쉽습니다. 극단적인 설정은 밝거나 어두운 부분의 계조를 잃게 할 수 있으므로 BaseColor 단독 표시와 일반 질감 표시를 비교하세요. “Reset adjustment”는 보정 값을 초기화하지만 보정 종류와 대상 채널은 유지합니다. 대상을 잘못 골랐다면 채널을 별도로 다시 선택하세요.

## 톤 커브 {#tone-curve}

가로축은 원래 밝기(Input), 세로축은 보정 후 밝기(출력)입니다. 왼쪽 아래는 어두운 부분, 오른쪽 위는 밝은 부분에 해당합니다. 대각선보다 위로 올린 구간은 밝아지고 아래로 내린 구간은 어두워집니다.

1. “Channel”에서 “RGB (Master)”를 선택하여 전체 명암을 조절합니다. 개별 색감을 조절하려면 “Red (R)”, “Green (G)” 또는 “Blue (B)”를 선택합니다.
2. 그래프를 클릭하여 점을 추가하고 드래그하여 커브를 바꿉니다. 선택한 점은 “Input”과 “출력”으로도 조절할 수 있습니다.
3. 어두운 부분을 조금 낮추고 밝은 부분을 조금 올리면 대비가 커집니다. 효과가 강하면 “Strength”를 낮추세요. 0은 보정 없음, 1은 전체 효과입니다.

각 커브는 양 끝점을 포함하여 2~16개의 점을 지원합니다. Input과 출력은 0~1 범위입니다. 양 끝점은 입력 위치가 고정되며 삭제할 수 없습니다. 중간 점은 “Remove point”로 제거할 수 있습니다.

“Curve presets”에는 선형, 대비, Soft contrast, Lift shadows, 무광, Darken이 있습니다. 프리셋은 현재 선택한 커브에 적용됩니다. RGB 전체 커브 다음에 개별 R·G·B 커브가 적용됩니다.

## 그라디언트 맵 {#gradient-map}

아래쪽 내용의 밝기를 읽어 어두운 부분부터 밝은 부분까지 색을 배정합니다. 뷰포트의 왼쪽에서 오른쪽으로 색을 칠하는 기능이 아닙니다. 모델의 위치와 관계없이 비슷한 밝기의 부분은 비슷한 색으로 바뀝니다.

1. 그라디언트의 색상점을 선택하고 색상 선택기 또는 #RRGGBB 코드로 색을 지정합니다.
2. 점을 드래그하거나 “위치”를 조절하여 어떤 밝기에 색을 대응시킬지 정합니다. 0% 쪽은 어두운 부분, 100% 쪽은 밝은 부분입니다.
3. 중간 색이 필요하면 “Add color”를 사용합니다. 예를 들어 어두운 부분에 남색, 중간에 빨강, 밝은 부분에 연노랑을 두면 원래 명암을 활용한 3색 배색이 됩니다.
4. “Strength”를 낮추어 원래 색을 더 남길 수 있습니다. 0은 보정 없음, 1은 전체 매핑 효과입니다.

색상점은 2~16개입니다. “Remove”는 선택한 점을 제거하고 “Reverse”는 색과 위치를 좌우로 뒤집습니다. “Presets”에서 배색을 검색하고 선택한 뒤 색과 위치를 다듬을 수 있습니다. 점은 이웃한 점 사이에서 이동합니다.

## 저장·내보내기와 효과 확인 {#save-and-check}

- 보정값을 계속 편집하려면 .harmos 장면도 저장하세요. 세 효과 모두 저장 후 다시 편집할 수 있으며 설정 변경은 실행 취소/다시 실행을 지원합니다.
- 일반 이미지 내보내기에는 합성 결과가 반영됩니다. PSD에는 대상 채널의 래스터 레이어로 저장되며 Photoshop의 기본 조정 레이어로 변환되지 않습니다. Photoshop에서 아래쪽 내용을 바꿔도 이 보정이 자동으로 다시 계산되지는 않습니다. [내보내기](./export.md)를 참고하세요.
- 변화가 보이지 않으면 대상 세트·채널, 레이어 표시·불투명도·순서를 확인하세요. 조정 레이어 아래에 내용이 있는지, 마스크나 클리핑으로 효과가 제한되는지도 살펴보세요.
- 원래 투명한 영역을 채우는 기능은 아닙니다. 빈 곳에 색을 추가하려면 [머티리얼 또는 페인트 레이어](./layers.md)를 사용하세요.
