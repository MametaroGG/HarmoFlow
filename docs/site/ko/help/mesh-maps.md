# 베이크된 형상 정보 확인하기 {#mesh-maps}

## 메시 맵 확인하기

<GuideMedia name="mesh-maps" />

“텍스처 세트 설정”의 메시 맵 목록에 자동으로 생성된 맵이 표시됩니다. 썸네일을 클릭하면 확대할 수 있고, “UV 에디터에 표시”를 선택하면 배경으로 표시할 수 있습니다.

## 네 가지 맵 읽는 방법

| 맵 | 읽는 방법 |
| --- | --- |
| 곡률 | 흰색은 볼록한 부분, 회색은 평면, 검은색은 오목한 부분 |
| 앰비언트 오클루전(AO) | 흰색은 차폐되지 않은 부분. 어두울수록 차폐가 강한 부분 |
| 오브젝트 공간 노멀 | 모델 안에서 면이 향하는 방향을 RGB로 표현. 채널의 Normal과는 용도가 다름 |
| 위치 | 모델 전체의 경계 안에서 위치를 RGB로 표현 |

## 베이크 해상도와 지원 범위

자동 베이크는 텍스처 세트당 1024px입니다. “다시 베이크”로 갱신할 수 있습니다. “파일 → 메시 맵 베이크”에서는 256 / 512 / 1024 / 2048px 중에서 선택하여 네 가지 PNG를 출력할 수 있습니다. 수동 출력 해상도는 자동 베이크에 적용되지 않습니다.

::: details 현재 지원 범위
현재 모델의 모든 파트를 이용하는 셀프 베이크입니다. AO는 반구 방향으로 64개의 레이를 사용하며, 최대 거리는 모델 대각선 길이의 15%입니다. 곡률은 면의 각도와 모서리까지의 거리로 계산합니다.

UV의 0~1 영역을 대상으로 하며, 같은 텍스처 세트 안에서 UV가 겹치면 첫 번째 면의 결과를 공유합니다. 하이폴리에서의 전사, 케이지, UDIM, ID·두께·Bent Normal 베이크는 지원하지 않습니다.
:::
