# 프로젝트·저장·복구 {#projects}

## 새로 만들기와 모델 불러오기

“파일 → 새 프로젝트”에서 저장 위치를 정하고 “모델 가져오기”로 모델을 불러옵니다. FBX, OBJ, glTF / GLB, DAE, PLY, STL, 3DS, BLEND를 지원합니다. 텍스처를 제작하려면 모델에 UV를 준비하세요. UV가 없는 형식이나 데이터의 경우, 파일 형식의 불러오기 지원 여부와 텍스처 편집 가능 여부는 별개입니다.

프로젝트는 에셋과 씬을 모아 두는 작업 폴더입니다. “프로젝트 설정”에서 루트 폴더와 텍스처 해상도를 변경할 수 있습니다. 씬 확장자는 `.harmos`입니다.


패키지 에셋은 [Unity Package 가져오기](./assets.md#unitypackage-import)를, FBX 변형과 파트 표시는 [메시와 셰이프 키](./viewport.md#mesh-visibility)를 참고하세요.

## 저장 방법 구분하기

| 작업 | 용도 |
| --- | --- |
| 씬 저장 | 현재 편집 상태 저장. Ctrl+S |
| 다른 이름으로 씬 저장 | 다른 이름으로 편집 상태 남기기 |
| 버전 번호를 늘려 저장 | 번호를 올려 버전 남기기. Ctrl+Alt+S |
| 씬 열기 | 저장한 편집 상태에서 작업 재개 |
| 패키지로 내보내기 | 프로젝트를 `.harmopackage`로 묶어 옮기기 |
| 이전과 같은 위치로 내보내기 | 이전 패키지 출력 위치 다시 사용 |
| 패키지 열기 | 설정된 위치에 풀어서 열기 |
| 압축 풀 위치를 지정하여 열기 | 이번에 풀 위치를 선택하여 열기 |

## 자동 저장과 복구

“환경 설정 → 자동 저장”에서 활성화하고, 간격(1~60분), 접두사, 변경 시에만 저장할지 여부, 보관 개수를 지정합니다. 보관 개수 0은 모두 남기는 설정입니다. “지금 자동 저장”과 저장 폴더 열기도 사용할 수 있습니다.

“파일 → 자동 저장 복구”에서 저장된 스냅샷을 선택합니다. “이전 저장 복구”는 사용 가능한 이전 저장 상태로 되돌리는 기능입니다. 복구한 내용을 확인한 뒤에는 일반 씬 저장을 수행하세요.

### 자동 저장 위치와 선택 방법 {#autosave-location}

저장된 프로젝트의 스냅샷은 프로젝트 폴더 안의 `autosave`에 생성됩니다. 저장하지 않은 세션은 HarmoFlow의 앱 데이터 영역을 사용합니다. “환경 설정 → 자동 저장”의 “현재 폴더”와 “자동 저장 폴더 열기”로 실제 위치를 확인하세요.

“자동 저장 복구”에서 날짜·시각·대상을 확인한 뒤 스냅샷을 선택합니다. 프로젝트에 속한 자동 저장은 프로젝트의 씬 폴더에 `원래씬이름_recovered_번호`라는 별도 씬으로 추가됩니다. 프로젝트에 없는 에셋은 복원하고 기존 에셋 파일은 변경하지 않습니다. 미저장 세션의 자동 저장은 저장하지 않은 씬으로 열리며, 일반 저장 시 저장 위치를 선택합니다. 복구 전에 현재 작업의 자동 저장도 시도하지만, 중요한 작업은 먼저 일반 저장을 해 두세요.

자동 저장은 일반 저장이나 백업을 대신하지 않습니다. 보관 개수 제한으로 오래된 스냅샷이 정리될 수 있으므로, 남겨 둘 버전은 다른 이름으로 저장하거나 증분 저장·백업으로 보관하세요. 복구 문제를 확인하는 동안 원본 프로젝트와 자동 저장을 삭제하거나 옮기지 마세요.

## GPU 오류 후 작업 복구하기 {#gpu-recovery}

::: warning 복구에는 성공한 자동 저장이 필요합니다
GPU 오류가 발생하면 복구용 자동 저장을 시도하지만 항상 성공하지는 않습니다. 저장 실패, 데이터 누락, 강제 종료 등으로 복구하지 못할 수 있으며, 저장하지 않은 모든 변경 사항의 복구를 보장하지는 않습니다.
:::

1. 오류 화면의 원인·작업·상세 정보를 기록하고, 작업이 자동 저장되었다는 안내인지 복구용 자동 저장이 실패했다는 안내인지 확인합니다. 저장이 성공하면 “다시 시작”을 선택하거나 “종료”한 뒤 HarmoFlow를 다시 실행합니다.
2. 다음 실행 시 “작업 복구”가 표시되면 대상을 확인하고 “복구”를 선택한 뒤 불러오기가 끝날 때까지 기다립니다. 원래 프로젝트를 사용할 수 없거나 원래 미저장 작업이었다면 저장하지 않은 씬으로 열릴 수 있습니다.
3. 복구된 모델, 레이어, 최근 페인팅, 머티리얼과 이미지를 확인합니다. 정상적으로 열렸다는 것만으로 모든 내용이 복구되었다고 판단하지 마세요.
4. 내용을 확인한 뒤 “씬 저장”(Ctrl+S)을 실행합니다. **복원만으로 원본 씬 파일을 덮어쓰지는 않으며, 일반 저장을 할 때까지 디스크의 원본 파일은 바뀌지 않습니다.** 기존 저장본도 남기려면 “씬 다른 이름으로 저장”을 사용하세요.

나중에 복원하려면 **“나중에” 버튼을 누르기 전에 마우스를 올리고 툴팁에 표시되는 자동 저장 경로를 기록하세요.** 버튼을 누르면 복구 안내가 닫히지만 자동 저장 데이터는 삭제되지 않습니다. 필요할 때 “자동 저장 복구”로 확인할 수 있습니다. 안내가 없거나, 저장에 실패했거나, 복구 중 다시 종료되면 원본 데이터를 보관한 채 [GPU 오류 해결과 문의](./troubleshooting.md#gpu-errors)를 확인하세요. 같은 복구를 반복하기 전에 GPU 부하와 드라이버 상태를 점검하세요.
