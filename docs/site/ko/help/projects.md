# 프로젝트·저장·복구 {#projects}

<GuideFlow kind="save-export" />

## 새로 만들기와 모델 불러오기

“파일 → 새 프로젝트”에서 저장 위치를 정하고 “모델 가져오기”로 모델을 불러옵니다. FBX, OBJ, glTF / GLB, DAE, PLY, STL, 3DS, BLEND를 지원합니다. 텍스처를 제작하려면 모델에 UV를 준비하세요. UV가 없는 형식이나 데이터의 경우, 파일 형식의 불러오기 지원 여부와 텍스처 편집 가능 여부는 별개입니다.

프로젝트는 에셋과 씬을 모아 두는 작업 폴더입니다. “프로젝트 설정”에서 루트 폴더와 텍스처 해상도를 변경할 수 있습니다. 씬 확장자는 `.harmos`입니다.


패키지 에셋은 [Unity Package 가져오기](./assets.md#unitypackage-import)를, FBX 변형과 파트 표시는 [메시와 셰이프 키](./viewport.md#mesh-visibility)를 참고하세요.

### 새 씬과 프로젝트 폴더 {#new-scene-project-root}

“새 프로젝트”는 scenes, assets, autosave와 workspace.json이 들어 있는 폴더를 만듭니다. 새 씬은 Ctrl+S로 저장하세요. 한 프로젝트의 여러 씬은 같은 에셋을 공유할 수 있습니다.

“파일 → 새 씬”(Ctrl+N)은 현재 작업 해상도로 새 씬을 시작합니다. 변경 사항이 있으면 “저장 후 새로 만들기”, “저장하지 않고 새로 만들기”, “취소” 중에서 선택합니다. 카메라 이동도 저장 확인 대상이 될 수 있습니다.

“프로젝트 설정 → 변경...”과 홈 화면의 프로젝트 선택은 프로젝트 폴더를 지정하는 기능입니다. 현재 씬을 닫거나 기존 씬과 에셋을 이동하지 않습니다. 씬을 바꾸려면 “씬 열기”를 사용하세요. 프로젝트 폴더나 workspace.json을 열면 scenes에서 가장 최근에 수정된 씬이 열립니다. 특정 버전을 열려면 해당 .harmos 파일을 직접 선택하세요.

## 저장 방법 구분하기

| 작업 | 용도 |
| --- | --- |
| 씬 저장 | 현재 편집 상태 저장. Ctrl+S |
| 씬 다른 이름으로 저장 | 다른 이름으로 편집 상태를 보관합니다. Ctrl+Shift+S. 다른 프로젝트에 저장하면 현재 라이브러리의 에셋도 대상 프로젝트로 복사합니다. |
| 증분 저장 | 번호를 올려 버전 남기기. Ctrl+Alt+S |
| 씬 열기 | 저장한 편집 상태에서 작업 재개 |
| 패키지 내보내기 | 프로젝트를 `.harmopackage`로 묶어 옮기기 |
| 패키지 다시 내보내기 | 확인 창 없이 마지막으로 내보낸 패키지를 즉시 덮어씁니다. 실행하기 전에 메뉴에 커서를 올려 출력 경로를 확인하세요 |
| 패키지 열기 | 설정된 위치에 풀어서 열기 |
| 패키지를 지정 위치에 열기... | 이번에 풀 위치를 선택하여 열기 |

패키지를 내보내면 먼저 현재 씬을 저장합니다. 아직 저장하지 않은 작업은 패키지 옆에 프로젝트 폴더를 만듭니다. 패키지에는 workspace.json과 scenes·assets·autosave 폴더가 포함되며 프로젝트 루트의 다른 파일은 포함되지 않습니다. 공유하기 전에 다른 씬과 자동 저장에 공유할 수 없는 내용이 없는지 확인하세요.

### 증분 저장과 패키지 위치 {#save-package-locations}

“증분 저장”은 현재 씬과 같은 폴더에 name_001.harmos, name_002.harmos 같은 파일을 만들고 해당 버전에서 작업을 이어갑니다. 각 버전은 프로젝트 에셋을 공유하며, 저장할 때마다 프로젝트 전체를 복제하지 않습니다.

“패키지 열기”의 기본 압축 해제 위치는 다운로드 폴더입니다. “환경 설정 → 일반 → 패키지 압축 해제 폴더”에서 변경할 수 있습니다. “패키지를 지정 위치에 열기...”는 이번 작업에만 사용할 위치를 선택합니다. 같은 이름의 비어 있지 않은 폴더가 있으면 번호가 붙은 별도 폴더에 풉니다.

앱은 “패키지 다시 내보내기”의 출력 위치를 기억합니다. 프로젝트를 바꾼 뒤에도 실행 전에 해당 명령에 커서를 올려 경로를 확인하세요.

## 새 3D 패스가 포함된 씬의 호환성 {#scene-version-compatibility}

::: warning Ver.0.1.1 또는 그보다 오래된 버전도 사용하는 경우
[Ver.0.1.2](https://github.com/MametaroGG/HarmoFlow/releases/tag/Ver.0.1.2)의 새 3D 패스가 포함된 씬은 Ver.0.1.1 및 그 이전 버전에서 열 수 없습니다. 구버전에서도 사용할 씬은 변경 전 파일을 보관하세요.
:::

새 3D 패스를 추가하거나 이전에 UV 좌표로 저장한 패스를 3D 뷰에서 다시 만들기 전에 “씬 다른 이름으로 저장” 또는 “증분 저장”으로 별도 파일에서 작업하고 원본 파일은 덮어쓰지 말고 보관하세요. 다시 만들어야 하는 패스는 [패스의 UV 아일랜드 경계](./paths.md#path-uv-island-boundaries)를 참고하세요.

## 자동 저장과 복구

정기 자동 저장은 기본적으로 꺼져 있습니다. 초기 설정은 5분 간격, 변경이 있을 때만 저장, 스냅샷 20개 유지입니다. 화면에서 지정할 수 있는 유지 개수는 0〜50개이며, 0은 모두 유지합니다. 그리기나 다른 처리 중에는 정기 저장을 기다립니다. “지금 자동 저장”은 정기 자동 저장을 꺼 둔 상태에서도 사용할 수 있습니다.

“환경 설정 → 자동 저장”에서 활성화하고, 간격(1~60분), 접두사, 변경 시에만 저장할지 여부, 보관 개수를 지정합니다. 보관 개수 0은 모두 남기는 설정입니다. “지금 자동 저장”과 저장 폴더 열기도 사용할 수 있습니다.

“파일 → 자동 저장 복구”에서 저장된 스냅샷을 선택합니다. “이전 저장 복구”는 사용 가능한 이전 저장본에서 별도의 복구 씬을 만들어 열며 원본 씬 파일은 유지합니다. 복구한 내용을 확인한 뒤에는 일반 씬 저장을 수행하세요.

### 자동 저장 위치와 선택 방법 {#autosave-location}

저장된 프로젝트의 스냅샷은 프로젝트 폴더 안의 `autosave`에 생성됩니다. 저장하지 않은 세션은 HarmoFlow의 앱 데이터 영역을 사용합니다. “환경 설정 → 자동 저장”의 “현재 폴더”와 “자동 저장 폴더 열기”로 실제 위치를 확인하세요.

“자동 저장 복구”에서 날짜·시각·대상을 확인한 뒤 스냅샷을 선택합니다. 프로젝트에 속한 자동 저장은 프로젝트의 씬 폴더에 `원래씬이름_recovered_번호`라는 별도 씬으로 추가됩니다. 프로젝트에 없는 에셋은 복원하고 기존 에셋 파일은 변경하지 않습니다. 미저장 세션의 자동 저장은 저장하지 않은 씬으로 열리며, 일반 저장 시 저장 위치를 선택합니다. 복구 전에 현재 작업의 자동 저장도 시도하지만, 중요한 작업은 먼저 일반 저장을 해 두세요.

자동 저장은 일반 저장이나 백업을 대신하지 않습니다. 보관 개수 제한으로 오래된 스냅샷이 정리될 수 있으므로, 남겨 둘 버전은 다른 이름으로 저장하거나 증분 저장·백업으로 보관하세요. 복구 문제를 확인하는 동안 원본 프로젝트와 자동 저장을 삭제하거나 옮기지 마세요.

## GPU 오류 후 작업 복구하기 {#gpu-recovery}

::: warning 복구에는 성공한 자동 저장이 필요합니다
GPU 오류가 발생하면 복구용 자동 저장을 시도하지만 항상 성공하지는 않습니다. 저장 실패, 데이터 누락, 강제 종료 등으로 복구하지 못할 수 있으며, 저장하지 않은 모든 변경 사항의 복구를 보장하지는 않습니다.
:::

1. 오류 화면의 원인·작업·상세 정보를 기록하고, 작업이 자동 저장되었다는 안내인지 복구용 자동 저장이 실패했다는 안내인지 확인합니다. 저장이 성공하면 “다시 시작”을 선택하거나 “종료”한 뒤 HarmoFlow를 다시 실행합니다.
2. 다음 실행 시 “작업 복구”가 표시되면 대상을 확인하고 “복구”를 선택한 뒤 불러오기가 끝날 때까지 기다립니다. 원래 프로젝트를 사용할 수 없거나 원래 미저장 작업이었다면 저장하지 않은 씬으로 열릴 수 있습니다.
3. 복구된 모델, 레이어, 최근 페인팅, 머티리얼과 이미지를 확인합니다. 정상적으로 열렸다는 것만으로 모든 내용이 복구되었다고 판단하지 마세요.
4. 내용을 확인한 뒤 “씬 저장”(Ctrl+S)을 실행합니다. **복원만으로 원본 씬 파일을 덮어쓰지는 않으며, 일반 저장을 할 때까지 디스크의 원본 파일은 바뀌지 않습니다.** 기존 저장본도 남기려면 “씬 다른 이름으로 저장”을 사용하세요.

나중에 복원하려면 **“나중에” 버튼을 누르기 전에 마우스를 올리고 툴팁에 표시되는 자동 저장 경로를 기록하세요.** 버튼을 누르면 복구 안내가 닫히지만 자동 저장 데이터는 삭제되지 않습니다.

저장한 작업을 나중에 복구하려면 먼저 원래 프로젝트를 연 다음 “파일 → 자동 저장 복구”를 선택하세요. 목록에는 현재 프로젝트의 자동 저장이 표시되며, 미저장 세션에서는 앱 데이터의 자동 저장이 표시됩니다. 원하는 스냅샷이 없다면 기록한 경로와 “현재 폴더”를 비교하세요.

안내가 없거나, 저장에 실패했거나, 복구 중 다시 종료되면 원본 데이터를 보관한 채 [GPU 오류 해결과 문의](./troubleshooting.md#gpu-errors)를 확인하세요. 같은 복구를 반복하기 전에 GPU 부하와 드라이버 상태를 점검하세요.
