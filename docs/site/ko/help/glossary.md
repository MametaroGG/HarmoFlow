# 용어 설명 {#glossary}

## 텍스처 제작 용어

| 용어 | 뜻 |
| --- | --- |
| 메시·폴리곤 | 정점과 면으로 구성된 3D 형상. 폴리곤은 그 면을 뜻함 |
| 메시 파트 | 모델을 구성하는 부품. HarmoFlow에서는 텍스처 세트의 단위 |
| UV·UV 아일랜드(셸) | 3D 표면과 2D 이미지의 대응 좌표. 그중 연결된 영역이 UV 아일랜드 |
| 유사 사각형 | 삼각형 두 개를 감지해 사각형처럼 취급하는 방식 |
| 텍스처 세트 | 특정 파트에서 사용하는 색상·거칠기 등의 이미지 묶음 |
| 채널 | 색상, 법선, 거칠기 등 질감을 구성하는 정보의 종류 |
| PBR / NPR | 물리적 반사를 기반으로 한 표현 / 툰 등 비사실적 표현 |
| 베이크 | 스트로크나 형상 정보 등을 계산하여 이미지에 반영하는 처리 |
| 메시 맵 | 곡률이나 차폐 등 모델의 형상에서 구한 이미지 |
| 곡률·AO | 볼록하고 오목한 경향 / 주변 형상에 의해 가려지는 정도 |
| 법선·접선 공간 | 면이 향하는 방향 / 표면을 기준으로 하는 좌표계. 일반적인 Normal 텍스처에 사용 |
| 오브젝트 공간 | 모델 자체를 기준으로 하는 좌표계. 형상 맵의 노멀과 스트로크에 사용 |
| Height | 높이 정보. 화면상의 요철 표현에 사용하며 모델 정점 편집과는 별개 |
| Fill | 일정 값·이미지·생성 패턴으로 채우는 레이어 |
| 프로시저럴·시드 | 계산으로 무늬를 생성하는 방식 / 무늬의 배치를 결정하는 수치 |
| 알파·불투명도 | 투명도를 나타내는 정보 / 얼마나 진하게 보일지 정하는 설정 |
| 마스크·클리핑 | 보이는 영역을 지정하는 정보 / 아래 레이어의 그리기 영역을 이용한 제한 |
| 앵커·핸들 | 패스가 지나는 점 / 곡선의 방향과 휘는 정도를 조절하는 손잡이 |
| 셰이프 키 | 정점의 변형을 가중치로 혼합하여 표정 등을 바꾸는 데이터 |
| 리니어·sRGB | 수치로 다루는 색 공간 / 표시를 위한 비선형 색상 인코딩. 수치 맵과 색상 이미지를 혼동하지 말 것 |
| VRAM·BC7 | GPU 메모리 / GPU용 텍스처 압축 형식 |
| IBL·F0·ACES | 환경 이미지를 사용하는 조명 / 정면에서 본 기준 반사율 / 밝기를 표시 범위에 맞추는 톤 매핑 |
| 하이폴리·케이지·UDIM | 세밀한 모델 / 전사 레이의 범위를 정하는 형상 / 여러 UV 타일을 사용하는 방식. 현재 메시 맵 베이크에서는 지원하지 않음 |
