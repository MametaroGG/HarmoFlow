# 환경 설정·히스토리·확장 {#settings}

<span id="시작-화면과-그리기-감도의-기본-설정"></span>


## 외관과 색상 선택하기 {#appearance-theme}

Ver.0.2.0에서는 어둡게, 밝게, 시스템 외관 모드와 일곱 가지 색상 프리셋, 사용자 지정 색상을 선택할 수 있습니다. 홈, 로딩 화면, 파이 메뉴, 뷰포트, UV 편집기도 선택한 색상을 따릅니다.

Ver.0.3.0의 초기 테마는 Windows의 밝게/어둡게 설정을 따르는 “시스템”입니다. 저장된 외관 설정이 있으면 해당 설정을 우선합니다.

고해상도 화면에서 글자와 버튼이 너무 작아지지 않도록 고DPI 디스플레이 배율에 맞춰 UI를 조정합니다. 드롭다운 값은 마우스 휠로도 바꿀 수 있습니다.
## 홈 화면과 최근 사용한 씬

홈 화면 왼쪽에서 프로젝트를 새로 만들거나 선택하고 씬을 불러올 수 있으며, 오른쪽의 “최근 사용한 씬”에서 작업을 재개할 수 있습니다. 성공한 불러오기·저장 기록을 최신 20개까지 유지합니다. 이름이나 경로로 검색할 수 있고, 각 행의 메뉴에서 기록만 제거할 수 있습니다. 파일 자체는 삭제하지 않습니다. 오른쪽 위의 “작업 화면으로”를 선택하면 편집으로 돌아가고, “파일 → 홈”으로 홈 화면을 열 수 있습니다. “시작 시 홈 표시”를 끄면 다음 실행부터 작업 화면으로 시작합니다.

최근 씬의 각 행 메뉴에서 “열기”, “파일 위치 열기”, “경로 복사”, “최근 파일에서 제거”를 사용할 수 있습니다. 파일을 찾을 수 없는 행은 열 수 없습니다. 프로젝트 폴더를 바꿔도 현재 편집 중인 씬은 닫히지 않습니다.

“창 → 언어” 또는 “환경 설정 → 일반 → 언어”에서 표시 언어를 바꿀 수 있습니다. 선택은 다음 실행에도 유지됩니다. 사용자가 정한 머티리얼 이름과 레이어 이름은 번역되지 않습니다.

## 손떨림 보정 조절하기

흔들림 보정이 활성화된 브러시는 면을 비스듬히 볼 때 보정이 조금 더 강해집니다. 화면의 작은 흔들림이 표면에서 크게 나타나는 것을 줄이기 위한 동작입니다. 윤곽 근처에서는 정면보다 입력을 따라가는 속도가 느려집니다. 브러시 점은 표면상의 거리를 따라 배치되지만, 극도로 비스듬한 각도에서는 그릴 면을 정면으로 돌리면 더욱 안정적입니다.

“필기감”에서 “속도에 따른 손떨림 보정”을 켜면 천천히 그리는 동안 흔들림을 줄이고, 빠르게 움직일수록 입력을 더 빠르게 따라갑니다. “속도 반응”으로 변화량을 조절할 수 있습니다. 보정값이 0인 브러시에는 적용되지 않습니다. 새 브러시의 기본 흔들림 보정값은 0.15입니다. 기존에 저장된 브러시의 보정값은 유지됩니다.

## 필압 조절하기

Ver.0.3.0에서는 브러시·지우개·색 혼합·흐리기에 “Automatic pressure flow”(필압에 따른 자동 유량 조절)와 안티앨리어싱(없음·약·중·강)을 추가했습니다. 약한 필압으로 칠하기·지우기·혼합 효과를 줄이고, 브러시 가장자리의 부드러움을 선택할 수 있습니다. 필압 크기 및 필압 불투명도와는 별도 설정입니다. 설정은 스트로크와 함께 저장되며 브러시·지우개 프리셋에도 저장할 수 있습니다. 새 스트로크를 재현하려면 Ver.0.3.0 이상이 필요합니다.

“필압 크기”는 필압에 따라 굵기를 바꾸고, “필압 불투명도”는 필압에 따라 농담을 표현합니다. 균일한 농도로 그리려면 필압 불투명도와 Automatic pressure flow를 모두 확인하세요. 기존 씬의 스트로크는 저장 당시의 설정으로 다시 그려집니다.

먼저 모델을 불러오세요. 불러오기나 패스 편집이 진행 중이면 해당 작업을 마친 뒤 보정을 시작합니다. “환경 설정 → 필기감 → 시험 그리기로 보정”에서 필압을 조절할 수 있습니다. 뷰포트의 모델 위에 펜으로 힘의 강약을 달리해 몇 개의 시험 획을 그린 뒤 “자동 조정 및 확인”을 누르세요. 확인 화면에서 다시 그려 보고, “더 부드럽게”, “더 단단하게”로 미세 조절한 뒤 “완료”로 저장합니다. “취소”를 선택하면 변경하지 않습니다. 마우스 입력은 자동 조절에 사용되지 않으며, 필압의 강약 차이나 샘플이 부족하면 추가 시험 그리기를 안내합니다. 시험 그리기는 씬에 그려지지 않습니다.

시험 그리기는 가장 최근의 한 획만 표시하며 다음 획을 시작하면 이전 획이 지워집니다. 시험 그리기를 지우거나 확인 화면에서 처음부터 다시 그려 보정을 시작할 수 있습니다.

<GuideMedia name="calibrate-pressure" />

필압 곡선이나 최소 필압을 조절하려면 “환경 설정 → 필기감”에서 “고급 필압 설정”을 펼칩니다. 필압 곡선의 “부드럽게”는 약한 힘에도 굵어지고, “단단하게”는 강하게 눌렀을 때 굵어집니다. 최소 필압은 가볍게 닿았을 때의 하한값이며, 필압 부드러움은 변화를 완만하게 만드는 정도입니다. 부드러움을 높이면 입력을 따라가는 데 지연이 생깁니다. 그래프는 입력에 대한 출력을, 모니터는 현재 보정 후의 필압을 표시합니다. 이 필압 설정은 자동으로 저장되어 모든 브러시에 적용됩니다. 마우스에는 적용되지 않습니다.

“보정 곡선 사용”이 켜져 있으면 “필압 곡선”과 “최소 필압”을 조절할 수 없습니다. 두 항목을 직접 조절하려면 먼저 “보정 곡선 사용”을 끄세요.

같은 화면에서 현재 브러시의 필압 크기, 흔들림 보정, 그리기 간격도 조절할 수 있습니다. 브러시별 설정은 브러시 프리셋에 저장해 구분하여 사용하세요.

## 펜의 측면 버튼 사용하기

펜의 측면 버튼은 펜 태블릿 드라이버에서 지정한 클릭으로 사용할 수 있습니다. “오른쪽 클릭”을 지정한 버튼만으로는 카메라가 회전하지 않으며, Alt와 함께 사용하면 확대/축소합니다. 오른쪽 버튼을 누른 채 펜촉을 대도 그려지지 않습니다. 버튼을 놓았을 때 펜촉이 아직 태블릿에 닿아 있어도, 펜을 한 번 떼기 전까지는 그려지지 않습니다. 펜촉이 버튼보다 조금 먼저 닿은 경우에도 오른쪽 클릭으로 처리하며, 그리기 시작한 선은 취소합니다. Shift+Alt를 누르는 동안에는 펜촉이 닿아도 그려지지 않습니다. “왼쪽 클릭”, “가운데 클릭”을 지정한 버튼도 마우스 버튼과 같은 방식으로 사용할 수 있습니다. 측면 버튼의 왼쪽 클릭으로 그릴 때는 필압이 없으므로 마우스와 같은 강도로 그려집니다.

Ver.0.1.2의 [레이어 파이 메뉴](./layers.md#layer-pie-menu)에서는 펜 태블릿으로도 포인터를 목록 위쪽이나 아래쪽에 두어 레이어를 탐색할 수 있습니다. 가운데로 돌아오면 멈추며, 펜촉으로 카드를 탭해서 선택할 수도 있습니다. 3D 뷰포트와 UV 편집기 모두에서 사용할 수 있습니다.

## 파일 선택 화면 바꾸기

파일과 폴더를 선택할 때는 기본적으로 OS 대화상자를 사용합니다. “환경 설정 → 일반 → 내장 파일 브라우저 사용”을 켜면 내장 브라우저로 전환됩니다. 설정은 다음 실행에도 유지됩니다. 이 설정은 모델이나 씬을 여는 등의 파일 선택에 적용됩니다. 플러그인 추가와 Lua 파일 실행은 계속 OS 대화상자를 사용합니다. 새 프로젝트를 만들 때는 기본 대화상자 안에서 프로젝트용 폴더를 만들고 선택하세요.

## 화면 배치와 히스토리

“창”에서 각 패널을 표시하고 도킹으로 배치를 변경할 수 있습니다. 패널 레일에 패널을 넣어 두고 아이콘으로 불러올 수 있습니다. 레일 너비를 넓히면 라벨이 표시되며, 순서 변경·그룹화·레일에서 빼기를 수행할 수 있습니다. 배치를 되돌리려면 “레이아웃 초기화”를 사용하세요.

Ctrl+Z / Ctrl+Y로 편집을 실행 취소하거나 다시 실행할 수 있으며, “작업 기록”에서 작업 내역을 확인할 수 있습니다. Undo가 모든 설정이나 외부 파일 작업을 되돌리는 것은 아닙니다. “콘솔”은 처리 결과와 오류를 확인하는 데 사용합니다. 사용 방법은 이 공식 문서를 참고하세요. 언어는 일본어, 영어, 중국어, 한국어로 전환할 수 있습니다.

### 도구 설정 실행 취소

브러시, 지우개, 색 혼합／흐림, 스탬프, 패스의 도구 설정도 Undo/Redo를 지원합니다. 슬라이더나 숫자 입력란을 연속해서 드래그한 변경은 한 번의 실행 취소로 되돌립니다. 다른 도구로 전환한 뒤에도 이전에 바꾼 설정에 적용됩니다.

브러시나 스탬프 설정을 되돌리면 다음 스트로크부터 반영됩니다. 모든 설정이나 외부 파일 작업을 되돌릴 수 있는 것은 아닙니다.

### 패널을 별도 창으로 분리하기 {#settings-detached-panels}

Ver.0.3.0에서는 패널 탭을 앱 바깥으로 드래그해 별도 창으로 배치할 수 있습니다. 다른 모니터로 옮기면 해당 모니터의 DPI에 맞춰 패널·글자·컨트롤 크기가 조정됩니다. 탭을 원래 도킹 배치로 되돌릴 수도 있습니다.

### 패널 레일 사용하기 {#panel-rail-operations}

패널 제목 표시줄을 패널 바로 드래그하면 아이콘으로 보관할 수 있습니다. 아이콘을 클릭해 열고, 다시 클릭해 닫습니다. 다른 아이콘을 열면 앞서 패널 바에서 연 패널은 닫힙니다. 열린 패널의 제목을 바깥으로 드래그하면 일반 패널처럼 배치할 수 있습니다. 아이콘을 오른쪽 클릭하고 “패널 바에서 제거”를 선택하면 아이콘이 제거됩니다. 패널 바 상단 화살표는 아이콘만 표시하거나 이름도 함께 표시하도록 전환합니다.

### 편집 이력 이동하기 {#history-navigation}

“창 → 작업 기록”에서 행을 클릭하면 해당 작업을 마친 상태로 이동할 수 있습니다. “Latest state”는 보관 중인 다시 실행 작업을 모두 진행합니다. 불러오기나 그리기 등의 작업 중에는 기록을 이동할 수 없습니다. 실행 취소 후 새로 편집하면 그 이후의 다시 실행 기록이 대체됩니다.

“환경 설정 → 일반 → Maximum history (0 = unlimited)”에서 실행 취소와 다시 실행을 합한 보관 개수를 설정합니다. 기본값은 100개이며, 0은 무제한입니다. 변경한 뒤 “저장”을 누르면 적용됩니다. 한도를 넘으면 가장 오래된 실행 취소 기록부터 지우고, 필요하면 가장 먼 다시 실행 기록도 지웁니다. 지워진 기록은 복원할 수 없습니다. 슬라이더를 연속으로 드래그하는 것처럼 묶인 작업은 1개로 셉니다.

### FPS와 프레임 시간 확인하기 {#performance-panel}

“창 → FPS / Frame time”에서 FPS, 평균·P95·최대 프레임 시간, 50ms를 넘은 프레임 수와 그래프를 확인할 수 있습니다. 최근 240프레임의 실제 경과 시간을 측정하므로 프레임 제한과 유휴 대기도 포함되며, GPU 렌더링 시간만을 나타내지는 않습니다. 비교할 작업 전에 “Reset measurements”를 눌러 측정을 초기화하세요. 실험적 텍스처 스트리밍의 ON/OFF 상태도 표시됩니다.

## VRAM과 표시 품질

“환경 설정 → VRAM”에서는 프리셋을 기준으로 설정을 조절할 수 있습니다. 동작이 느리다면 먼저 미리보기 해상도를 낮추고, 필요에 따라 작업 해상도도 낮추세요.

### 프리셋과 미리보기 해상도 {#vram-presets}

Ver.0.3.0에서는 VRAM 설정을 아직 저장하지 않았다면 GPU 메모리 용량과 PC의 RAM 용량에 따라 “최고 품질”, “균형”, “낮은 VRAM”을 자동 선택합니다. 저장된 사용자 설정이 우선 적용됩니다. 순간적으로 변하는 여유 메모리가 아닌 용량을 기준으로 선택합니다.

“균형”은 뷰포트 미리보기를 전체 해상도로, UI 패널 미리보기를 절반 해상도로 표시합니다. 편집 데이터와 내보내기 품질은 유지됩니다.

UV 셸 바깥의 작업 이미지와 이력·내보내기 중 임시 메모리 사용량도 줄였습니다. UV 바깥의 절감 효과는 GPU 지원 여부와 UV 배치에 따라 달라지며, 편집 데이터와 내보내기 품질은 유지됩니다.

“최고 품질”은 전체 해상도 미리보기를 사용하고, “낮은 VRAM”은 4분의 1 해상도 미리보기와 BC7 표시 압축 등을 사용합니다. 개별 설정을 변경하면 “사용자 지정”으로 바뀝니다. “최고 품질”, “균형”, “낮은 VRAM”을 선택하면 실험적 기능이 꺼집니다. “사용자 지정”만 선택하면 현재 설정을 유지합니다.

“절반”과 “4분의 1”은 미리보기 이미지의 가로·세로 해상도를 뜻합니다. UV 편집기를 열어 둔 동안에는 UI 미리보기 해상도가 캔버스 크기에 맞춰 자동 조정됩니다. 내보내기 해상도는 바뀌지 않습니다.

VRAM 옵션을 바꾼 뒤 환경 설정 창 아래의 “저장”을 누르세요. 저장하지 않고 창만 닫으면 변경 내용이 적용되지 않습니다. 메시 UV 바깥 픽셀의 저장 모드 변경은 다음 모델 불러오기 또는 해상도 변경 시 적용됩니다.

| 설정 그룹 | 내용 |
| --- | --- |
| 텍스처 | 메시 UV 바깥 영역 처리, BC7 표시 압축, 채널 지연 로딩과 대상 채널 |
| 베이크 중간 버퍼 | 스냅샷, 라이브 스크래치, 레이어 체크포인트의 지연 할당과 최대 개수 |
| 가져오기 / GPU 준비 | 고속 GPU 경로와 GPU 메모리 할당 배치 |
| 미리보기 | 뷰포트와 UI 패널을 전체/절반/1/4 해상도로 표시 |
| 메모리 기반 설정 | 스테이징 풀, 블록 용량, 유휴 시 재사용 |
| 예산 | VRAM 예산과 초과 경고. 0은 예산 제한 없음 |
| 실험적 기능 | 신경망 텍스처 압축, 가상 텍스처 캐시, 편집하지 않는 텍스처 세트의 메모리 절약. 아래 설명 참고 |

그리기 자체를 UV 아일랜드 안의 픽셀로 제한하려면 브러시 패널의 [“UV 여백 제거 (엄격)”](./brush.md#strict-uv-padding)을 사용하세요. 메시 UV 바깥의 저장·내보내기 설정과는 별개입니다.

### VRAM 예산의 의미 {#vram-budget}

VRAM 예산은 경고와 일부 캐시 조정의 기준입니다. 지정한 양을 넘는 모든 메모리 할당을 막는 설정은 아닙니다. 사용량 막대는 추정치이며 다른 앱의 사용량을 포함할 수 있습니다. 0으로 설정하면 예산을 지정하지 않습니다.

### 표시용 이미지 압축 {#display-compression}

BC7은 뷰포트 표시용 복사본만 압축합니다. “선택하지 않은 세트에 BC7”은 선택한 세트의 일반 미리보기를 유지하고, “모든 세트에 BC7”은 선택한 세트도 압축 대상에 포함합니다. 편집 이미지와 내보내기 데이터는 압축하지 않습니다. 일반 BC7 표시 복사본은 256~512px이며, 전체 해상도 가상 텍스처 캐시는 다르게 동작합니다.

“신경망 텍스처 압축 (뷰포트)”은 기본적으로 꺼져 있는 실험적 기능입니다. 작은 데이터 표현에서 표시 이미지를 복원하므로 세부 묘사나 색상이 원본과 다를 수 있습니다. 미리보기는 256~512px이며 편집·내보내기 이미지는 유지됩니다. “잠재 표현 축소 배율”의 기본값은 4, 최솟값은 2입니다. 전체 해상도 가상 텍스처 캐시나 편집하지 않는 세트의 메모리 절약 기능이 우선하는 경우에는 이 방식을 사용하지 않습니다.

### 가상 텍스처 캐시

가상 텍스처 캐시는 선택하지 않은 세트를 무손실 압축하여 디스크로 옮기고, 선택하면 복원합니다. 전체 해상도 표시도 지원합니다. 전체 해상도에서는 선택하지 않은 세트에 BC7 표시 복사본을 사용하므로 표시 색상이 약간 다를 수 있습니다. 편집 및 내보내기 데이터는 무손실로 유지됩니다.

선택한 세트는 페이지 예산보다 우선합니다. GPU 상주는 텍스처 세트 단위로 관리하며, 보이는 타일 단위로 스트리밍하지 않습니다.

### 편집하지 않는 텍스처 세트의 메모리 절약

Ver.0.3.0에서 자동 선택하는 프리셋은 “Reduce memory for non-edited texture sets”와 가상 텍스처 캐시를 끕니다. 저장된 사용자 설정이 우선하며, 실제 동작은 GPU 지원 여부와 편집 상태에 따라 달라집니다. 이 기능을 켜면 지원 GPU에서는 선택한 세트와 편집 중인 세트를 원래 해상도로 유지합니다. 3초 이상 조작이 없으면 다른 세트를 무손실로 메모리 밖에 보관하고 1/4 해상도로 표시합니다.

현재 활성 레이어가 모든 텍스처 세트를 대상으로 하면 모든 세트를 메모리에 유지합니다. 세트가 하나뿐인 씬에서는 채널 메모리를 줄이지 않습니다. 이 모드는 BC7, NTC, 기존 가상 텍스처 캐시보다 우선하며, 세트 전환 시 복원을 기다려야 할 수 있습니다.

자동 저장은 [저장과 복구](/ko/guide#projects)를 참고하세요. “일반”에는 패키지 압축 풀 위치 설정이 있습니다. “키 설정”에서 작업 이름이나 단축키로 검색하여 키보드와 마우스 할당을 변경할 수 있습니다.

## Lua와 플러그인

“스크립트 (Lua)”에서는 입력한 코드나 Lua 파일을 실행하고 로그를 확인하거나 지울 수 있습니다. `hf` API에는 레이어 추가·편집, 마스크, 이미지 Fill, 머티리얼 프리셋, 브러시, 모델 불러오기, 씬 저장, 패키지, 텍스처 내보내기 등의 기능이 있습니다. 레이어 번호는 1부터 시작합니다.

```lua
hf.log('Layers: ' .. hf.layer_count())
hf.add_layer('paint', 'Practice layer')
```

상단 “플러그인” 메뉴에서 플러그인을 실행합니다. 일반 Lua 스크립트와 패널을 등록하는 Lua 확장은 서로 다른 방식으로 실행됩니다. 목적에 맞는 자세한 가이드를 확인하세요.

- [플러그인 설치와 관리](./plugins.md): 추가, 저장 위치, 실행, 업데이트, 오류 확인
- [플러그인 만들기](./plugin-development.md): Lua 최소 예제, 공식 SDK 다운로드, DLL 빌드와 테스트
- [기본 조정 기능](./adjustments.md): 색조 보정, 톤 커브, 그라디언트 맵


### 스크립트 실행과 Undo {#lua-execution-undo}

일반 Lua 스크립트는 그리기나 다른 처리가 진행 중이면 실행을 기다립니다. Lua 명령에는 약 2초의 실행 제한이 있지만 호출한 모든 처리를 도중에 중단할 수 있는 것은 아닙니다. 긴 작업은 작은 단계로 나누고 출력 로그의 오류를 확인하세요. 확장 기능의 액션과 달리 일반 스크립트 전체가 자동으로 한 번의 Undo로 묶이거나 오류 시 모두 되돌려지는 것은 아닙니다. 실행 전에 씬을 저장하세요.
