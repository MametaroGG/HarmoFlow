# 환경 설정·히스토리·확장 {#settings}

## 시작 화면과 그리기 감도의 기본 설정

홈 화면 왼쪽에서 프로젝트를 새로 만들거나 선택하고 씬을 불러올 수 있으며, 오른쪽의 “최근 사용한 씬”에서 작업을 재개할 수 있습니다. 성공한 불러오기·저장 기록을 최신 20개까지 유지합니다. 이름이나 경로로 검색할 수 있고, 각 행의 메뉴에서 기록만 제거할 수 있습니다. 파일 자체는 삭제하지 않습니다. 오른쪽 위의 “작업 화면으로”를 선택하면 편집으로 돌아갑니다.

흔들림 보정이 활성화된 브러시는 면을 비스듬히 볼 때 보정이 조금 더 강해집니다. 화면의 작은 흔들림이 표면에서 크게 나타나는 것을 줄이기 위한 동작입니다. 윤곽 근처에서는 정면보다 입력을 따라가는 속도가 느려집니다. 브러시 점은 표면상의 거리를 따라 배치되지만, 극도로 비스듬한 각도에서는 그릴 면을 정면으로 돌리면 더욱 안정적입니다.

“그리기 감도”에서 “속도에 따라 흔들림 보정 변경”을 켜면 천천히 그리는 동안 흔들림을 줄이고, 빠르게 움직일수록 입력을 더 빠르게 따라갑니다. “속도 반응”으로 변화량을 조절할 수 있습니다. 보정값이 0인 브러시에는 적용되지 않습니다. 새 브러시의 기본 흔들림 보정값은 0.15입니다. 기존에 저장된 브러시의 보정값은 유지됩니다.

“필압 크기”는 필압에 따라 굵기를 바꾸고, “필압으로 진하기 변경”은 필압에 따라 농담을 표현합니다. 균일한 잉크 선을 그리려면 진하기에 대한 필압을 끄세요. 기존 씬의 스트로크는 저장 당시의 설정으로 다시 그려집니다.

“환경 설정 → 그리기 감도 → 시험 그리기로 필압 조절”에서 필압을 조절할 수 있습니다. 펜으로 힘의 강약을 달리해 몇 개의 선을 그린 뒤 “자동 조절 후 확인”을 누르세요. 확인 화면에서 다시 그려 보고, “더 부드럽게”, “더 단단하게”로 미세 조절한 뒤 “완료”로 저장합니다. “취소”를 선택하면 변경하지 않습니다. 마우스 입력은 자동 조절에 사용되지 않으며, 필압의 강약 차이나 샘플이 부족하면 추가 시험 그리기를 안내합니다. 시험 그리기는 씬에 그려지지 않습니다.

시작할 때 홈 화면에서 새 프로젝트 만들기, 프로젝트 폴더 선택, 씬 불러오기를 수행할 수 있습니다. “작업 화면으로”에서 편집을 시작하고, “파일 → 홈”으로 돌아올 수 있습니다. “시작 시 홈 표시”를 끄면 다음 실행부터 작업 화면으로 시작합니다.

“환경 설정 → 그리기 감도”에서 필압을 조절할 수 있습니다. 필압 곡선의 “가벼운 터치”는 약한 힘에도 굵어지고, “꾹 누르기”는 강하게 눌렀을 때 굵어집니다. 최소 필압은 가볍게 닿았을 때의 하한값이며, 필압 부드러움은 변화를 완만하게 만드는 정도입니다. 부드러움을 높이면 입력을 따라가는 데 지연이 생깁니다. 그래프는 입력에 대한 출력을, 모니터는 현재 보정 후의 필압을 표시합니다. 이 필압 설정은 자동으로 저장되어 모든 브러시에 적용됩니다. 마우스에는 적용되지 않습니다.

같은 화면에서 현재 브러시의 필압 크기, 흔들림 보정, 그리기 간격도 조절할 수 있습니다. 브러시별 설정은 브러시 프리셋에 저장해 구분하여 사용하세요.

펜의 측면 버튼은 펜 태블릿 드라이버에서 지정한 클릭으로 사용할 수 있습니다. “오른쪽 클릭”을 지정한 버튼만으로는 카메라가 회전하지 않으며, Alt와 함께 사용하면 확대/축소합니다. 오른쪽 버튼을 누른 채 펜촉을 대도 그려지지 않습니다. 버튼을 놓았을 때 펜촉이 아직 태블릿에 닿아 있어도, 펜을 한 번 떼기 전까지는 그려지지 않습니다. 펜촉이 버튼보다 조금 먼저 닿은 경우에도 오른쪽 클릭으로 처리하며, 그리기 시작한 선은 취소합니다. Shift+Alt를 누르는 동안에는 펜촉이 닿아도 그려지지 않습니다. “왼쪽 클릭”, “가운데 클릭”을 지정한 버튼도 마우스 버튼과 같은 방식으로 사용할 수 있습니다. 측면 버튼의 왼쪽 클릭으로 그릴 때는 필압이 없으므로 마우스와 같은 강도로 그려집니다.

파일과 폴더를 선택할 때는 기본적으로 OS 대화상자를 사용합니다. “환경 설정 → 일반 → 내장 파일 브라우저 사용”을 켜면 내장 브라우저로 전환됩니다. 설정은 다음 실행에도 유지됩니다. 새 프로젝트를 만들 때는 기본 대화상자 안에서 프로젝트용 폴더를 만들고 선택하세요.

## 화면 배치와 히스토리

“창”에서 각 패널을 표시하고 도킹으로 배치를 변경할 수 있습니다. 패널 레일에 패널을 넣어 두고 아이콘으로 불러올 수 있습니다. 레일 너비를 넓히면 라벨이 표시되며, 순서 변경·그룹화·레일에서 빼기를 수행할 수 있습니다. 배치를 되돌리려면 “레이아웃 초기화”를 사용하세요.

Ctrl+Z / Ctrl+Y로 편집을 실행 취소하거나 다시 실행할 수 있으며, “히스토리”에서 작업 내역을 확인할 수 있습니다. Undo가 모든 설정이나 외부 파일 작업을 되돌리는 것은 아닙니다. “콘솔”은 처리 결과와 오류를 확인하는 데 사용합니다. 사용 방법은 이 공식 문서를 참고하세요. 언어는 일본어, 영어, 중국어, 한국어로 전환할 수 있습니다.

### 도구 설정 실행 취소

브러시, 지우개, 색 혼합／흐림, 스탬프, 패스의 도구 설정도 Undo/Redo를 지원합니다. 슬라이더나 숫자 입력란을 연속해서 드래그한 변경은 한 번의 실행 취소로 되돌립니다. 다른 도구로 전환한 뒤에도 이전에 바꾼 설정에 적용됩니다.

브러시나 스탬프 설정을 되돌리면 다음 스트로크부터 반영됩니다. 모든 설정이나 외부 파일 작업을 되돌릴 수 있는 것은 아닙니다.

## VRAM과 표시 품질

“환경 설정 → VRAM”에서는 프리셋을 기준으로 설정을 조절할 수 있습니다. 동작이 느리다면 먼저 미리보기 해상도를 낮추고, 필요에 따라 작업 해상도도 낮추세요.

| 설정 그룹 | 내용 |
| --- | --- |
| 텍스처 | 메시 UV 바깥 영역 처리, BC7 표시 압축, 채널 지연 로딩과 대상 채널 |
| 베이크 중간 버퍼 | 스냅샷, 라이브 스크래치, 레이어 체크포인트의 지연 할당과 최대 개수 |
| 가져오기 / GPU 준비 | 고속 GPU 경로와 GPU 메모리 할당 배치 |
| 미리보기 | 뷰포트와 UI 패널을 전체/절반/1/4 해상도로 표시 |
| 메모리 기반 설정 | 스테이징 풀, 블록 용량, 유휴 시 재사용 |
| 예산 | VRAM 예산과 초과 경고. 0은 예산 제한 없음 |
| 실험적 기능 | 신경망 텍스처 압축, 가상 텍스처 캐시, 편집하지 않는 텍스처 세트의 메모리 절약. 아래 설명 참고 |

### 가상 텍스처 캐시

가상 텍스처 캐시는 선택하지 않은 세트를 무손실 압축하여 디스크로 옮기고, 선택하면 복원합니다. 전체 해상도 표시도 지원합니다. 전체 해상도에서는 선택하지 않은 세트에 BC7 표시 복사본을 사용하므로 표시 색상이 약간 다를 수 있습니다. 편집 및 내보내기 데이터는 무손실로 유지됩니다.

선택한 세트는 페이지 예산보다 우선합니다. GPU 상주는 텍스처 세트 단위로 관리하며, 보이는 타일 단위로 스트리밍하지 않습니다.

### 편집하지 않는 텍스처 세트의 메모리 절약

“Reduce memory for non-edited texture sets”는 기본적으로 꺼져 있습니다. 지원 GPU에서는 선택한 세트와 편집 중인 세트를 원래 해상도로 유지합니다. 3초 이상 조작이 없으면 다른 세트를 무손실로 메모리 밖에 보관하고 1/4 해상도로 표시합니다.

전체 적용 레이어가 있으면 모든 세트를 유지합니다. 세트가 하나뿐인 씬에서는 채널 메모리를 줄이지 않습니다. 이 모드는 BC7, NTC, 기존 가상 텍스처 캐시보다 우선하며, 세트 전환 시 복원을 기다려야 할 수 있습니다.

자동 저장은 [저장과 복구](/ko/guide#projects)를 참고하세요. “일반”에는 패키지 압축 풀 위치 설정이 있습니다. “키 설정”에서 작업 이름이나 조건으로 검색하여 키보드와 마우스 할당을 변경할 수 있습니다.

## Lua와 플러그인

“스크립트(Lua)”에서는 입력한 코드나 Lua 파일을 실행하고 로그를 확인하거나 지울 수 있습니다. `hf` API에는 레이어 추가·편집, 마스크, 이미지 Fill, 머티리얼 프리셋, 브러시, 모델 불러오기, 씬 저장, 패키지, 텍스처 내보내기 등의 기능이 있습니다. 레이어 번호는 1부터 시작합니다.

```lua
hf.log('Layers: ' .. hf.layer_count())
hf.add_layer('paint', 'Practice layer')
```

상단 “플러그인(P)” 메뉴에서 플러그인을 실행합니다. 일반 Lua 스크립트와 패널을 등록하는 Lua 확장은 서로 다른 방식으로 실행됩니다. 목적에 맞는 자세한 가이드를 확인하세요.

- [플러그인 설치와 관리](./plugins.md): 추가, 저장 위치, 실행, 업데이트, 오류 확인
- [플러그인 만들기](./plugin-development.md): Lua 최소 예제, 공식 SDK 다운로드, DLL 빌드와 테스트
- [기본 조정 기능](./adjustments.md): 색조 보정, 톤 커브, 그라디언트 맵
