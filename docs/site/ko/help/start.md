# 시작하기 {#start}

## HarmoFlow 설치하기 {#app-install}

<GuideFlow kind="app-install" />

1. [BOOTH 상품 페이지](https://mametarovv.booth.pm/items/8754692)에서 정식판 또는 체험판 설치 프로그램을 다운로드합니다. **Ver.0.1.2는 ZIP으로 제공됩니다. 사용할 판의 ZIP을 다운로드하고 압축을 푼 다음, 안에 있는 설치 EXE를 실행하세요.** 파일 이름의 `full`은 정식판, `trial`은 체험판입니다.
2. 설치 EXE를 더블 클릭합니다. 설치 언어를 일본어·영어·중국어 간체·한국어 중에서 선택하고, 사용권 계약을 읽은 뒤 동의할 때만 계속합니다. 구매 전에도 정식판의 [사용권 계약](../terms.md)을 확인할 수 있습니다.
3. 설치 위치와 필요한 경우 바탕 화면 바로가기를 선택합니다. 정식판에서는 `.harmos` / `.harmopackage` 파일 연결도 선택할 수 있습니다. 체험판은 파일 연결을 변경하지 않습니다.
4. 완료 화면에서 실행하거나 시작 메뉴에서 **HarmoFlow**(체험판은 **HarmoFlow Trial**)를 엽니다. 앱 EXE만 다른 위치로 옮기지 말고 설치된 파일 구성을 그대로 유지하세요.

::: warning 시작이 멈춘다면
[시스템 요구 사항](../download.md#requirements-title)과 [시작 문제 확인](./troubleshooting.md#startup-checks)을 확인하세요. 경고의 의미와 다운로드 출처를 확인하지 않은 채 Windows 보호 기능을 끄지 마세요.
:::

## 처음 실행할 때 확인할 것 {#first-launch}

- 홈에서 프로젝트를 만들거나 UV가 있는 지원 모델을 불러옵니다. 먼저 작은 테스트 모델로 그리기와 저장을 확인하는 것이 좋습니다.
- “창 → 언어”에서 표시 언어를 바꿀 수 있습니다. 패널을 찾기 어렵다면 “창 → 레이아웃 초기화”를 사용하세요.
- 정식판과 체험판은 별도로 설치되며 설정과 머티리얼 캐시도 따로 사용합니다. **체험판은 편집과 프로젝트 저장을 지원하지만 텍스처 내보내기는 지원하지 않습니다.** 체험판에서 저장한 프로젝트는 정식판에서 열 수 있습니다.
- 머티리얼 목록은 앱에 포함됩니다. 다운로드형 이미지 머티리얼은 처음 사용할 때 인터넷이 필요합니다. 오프라인으로 작업하기 전에 [머티리얼 다운로드와 오프라인 사용](./materials.md#material-downloads)을 확인하세요.

## 업데이트 자동 알림 {#automatic-update-notifications}

Ver.0.1.1부터 시작할 때 백그라운드에서 새 버전을 확인합니다. 업데이트가 발견되면 창 위쪽 검색 상자 오른쪽에 파란색 다운로드 아이콘이 표시됩니다. 아이콘을 클릭하면 현재 버전, 새 버전과 “What's new”(이번 변경 내용)를 확인할 수 있습니다.

- **Get update**: 브라우저에서 업데이트를 받을 수 있는 페이지를 엽니다. 자동으로 수행되는 것은 확인과 알림이며, 설치 프로그램은 직접 다운로드하고 실행합니다. 먼저 아래 절차에 따라 백업을 준비하세요.
- **나중에**: 대화상자를 닫습니다. 알림 아이콘은 남으므로 같은 실행 중에 다시 열 수 있습니다.
- **Skip this update**: 해당 버전의 알림을 숨기며, 다시 시작해도 표시하지 않습니다. 더 새로운 버전은 알림 대상이 됩니다.

오프라인이거나 확인에 실패하면 알림이 표시되지 않습니다. 아이콘이 없다고 반드시 최신 버전인 것은 아닙니다. 다시 확인하려면 인터넷 연결을 확인하고 HarmoFlow를 다시 시작하거나 [BOOTH 상품 페이지](https://mametarovv.booth.pm/items/8754692)를 직접 확인하세요. 변경 내용과 소개 영상은 [업데이트 정보](../updates.md)에서도 볼 수 있습니다.

## 업데이트 전에 백업하기 {#update-backup}

<GuideFlow kind="update-backup" />

::: warning Ver.0.1.2의 3D 패스와 이전 버전 호환성
새 3D 패스가 포함된 장면은 Ver.0.1.1 이하에서 열 수 없습니다. 이전 버전에서도 사용할 장면은 변경 전 파일을 별도로 보관하세요. [3D 패스 호환성](./paths.md#path-uv-island-boundaries)도 확인하세요.
:::

1. 작업 중인 장면을 일반 저장하고 앱을 종료합니다. **프로젝트 폴더 전체를 다른 위치에 복사**하세요. `.harmos` 파일만 복사하지 말고 가져온 모델과 이미지를 함께 보관합니다. 이동용으로는 [패키지 내보내기](./projects.md)도 사용할 수 있습니다.
2. 직접 추가한 브러시와 플러그인도 원본 다운로드 파일이나 별도 백업을 보관합니다. 새 버전에서 저장한 장면은 이전 버전에서 열리지 않을 수 있으므로 업데이트 전 사본을 덮어쓰지 마세요.
3. BOOTH에서 <strong>같은 판(정식판／체험판)</strong>의 새 버전 ZIP을 받아 압축을 풉니다. 안에 있는 설치 EXE를 실행하고 기존 설치 위치를 선택합니다. 같은 판의 설치 프로그램은 기존 설치를 업데이트합니다.
4. 실행 후 버전을 확인합니다. 먼저 백업에서 만든 테스트 사본으로 모델·이미지·레이어·저장·다시 열기를 확인하세요. 정식판에서는 필요한 내보내기도 테스트합니다.

### 최신 버전 확인하기

[BOOTH 상품 페이지](https://mametarovv.booth.pm/items/8754692)에서 최신 버전과 배포 파일을 확인하세요. 업데이트 전에 작업을 저장하고 프로젝트를 백업하세요. 현재 사용하는 종류(정식판／체험판)에 맞는 새 버전 설치 프로그램을 받은 뒤 위의 업데이트 절차를 따르세요.

## 버전과 변경 이력 확인하기 {#version-changelog}

“**도움말 → HarmoFlow 정보**” 상단에서 앱 버전을 확인합니다. 같은 창의 “**변경 이력**” 탭에는 앱에 포함된 변경 사항이 표시됩니다. 제목 표시줄의 대괄호 안 숫자는 빌드 시각입니다. 문의할 때는 정식판／체험판 여부, 버전, 빌드 시각을 함께 기록하세요.

구매 조건은 [구매 전 FAQ](../download.md#purchase-faq), 사용 중 문제는 [문제 해결](./troubleshooting.md)을 참고하세요.

## 모델 불러오기부터 저장까지

1. **모델 불러오기**

   파일 메뉴에서 모델을 가져오거나 파일 탐색기에서 모델 파일을 창으로 드래그 앤 드롭할 수 있습니다. 홈 화면에 드롭해도 되며, 불러오기가 끝나면 작업 화면으로 전환됩니다. FBX, OBJ, glTF / GLB, DAE, PLY, STL, 3DS, BLEND를 지원합니다.

   모델이나 이미지를 여러 개 함께 드롭하면 첫 번째 지원 모델을 열고 나머지 파일은 프로젝트 에셋 라이브러리로 가져옵니다. 불러오는 도중에 받은 드롭은 현재 처리가 끝난 뒤 실행합니다.

2. **편집할 파트 선택하기**

   채널, UV 편집기, 텍스처 세트 설정의 선택은 서로 연동됩니다. 뷰포트에서 모델을 Shift+Alt+오른쪽 클릭하면 해당 위치의 파트로 전환됩니다. 파트가 하나뿐인 모델에서는 전환이 비활성화됩니다.

3. **레이어와 도구를 선택해 그리기**

   페인트 레이어를 선택하고 B를 눌러 페인트 도구로 전환한 뒤 모델 표면을 드래그합니다.

4. **씬 저장하기**

   Ctrl+S로 작업을 저장합니다. 나중에 레이어와 스트로크를 다시 편집할 수 있습니다.

5. **텍스처 내보내기**

   내보내기 패널에서 출력 위치, 형식, 채널을 선택하고 이미지를 내보냅니다.

::: tip 자동 베이크
모델을 불러올 때 메시 맵을 자동으로 베이크합니다. 베이크가 끝나기 전에 웨더링을 설정해도 맵이 생성된 후 반영됩니다.
:::

## glTF / GLB 이미지와 머티리얼 연결

glTF / GLB를 불러오면 지원되는 참조 이미지도 프로젝트 에셋 라이브러리로 가져와 BaseColor, Normal, Metallic, Roughness, Emission에 자동으로 연결합니다. 하나로 묶인 MetallicRoughness 이미지는 Roughness와 Metallic으로 분리하며, 지원되는 색상과 강도 값도 반영합니다.

프로젝트를 저장할 때 외부 형상 데이터와 참조 이미지도 함께 저장되므로, 저장한 프로젝트는 원래 폴더와 별개로 다시 열 수 있습니다. 이미지를 교체하려면 채널 패널의 “수동 텍스처 연결”을 사용하세요. 가져온 머티리얼의 연결은 레이어의 이미지 Fill과 별개입니다.

### 불러오기 경고와 제한

읽을 수 없는 이미지는 콘솔에 경고를 남기며, 불러올 수 있는 다른 지원 이미지는 적용됩니다. 형상 버퍼 등 모델에 꼭 필요한 파일이 없으면 모델 불러오기 자체가 실패할 수 있습니다.

성공적으로 가져온 AO 이미지는 프로젝트 에셋 라이브러리에 보관하지만, 가져온 AO를 표시하거나 적용하는 전용 채널은 지원하지 않습니다. 자동 베이크되는 AO 메시 맵과는 별개입니다.

이미지 자동 연결은 UV0을 대상으로 합니다. 다른 UV 세트를 참조하거나 KHR_texture_transform 같은 텍스처 좌표 확장을 사용하는 이미지는 자동 연결하지 않고 경고를 남깁니다. 이때 제외되는 것은 참조 이미지이며, 대체 색상이나 스칼라 값은 여전히 생성될 수 있습니다.


### 외부 파일과 가져오기 제한 {#model-import-limits}

- 폴더를 드롭하면 바로 안에 있는 파일만 가져옵니다. 하위 폴더의 내용은 자동으로 가져오지 않습니다.
- glTF/GLB 가져오기는 인터넷 URL로 참조된 이미지나 형상 데이터를 자동 다운로드하지 않습니다. 필요한 외부 파일을 로컬에 준비한 뒤 가져오세요.
- BLEND 호환 여부는 파일에 저장된 데이터 구조에 따라 달라집니다. 가져오기에 실패하면 콘솔을 확인하고, Blender에서 FBX 또는 glTF/GLB로 내보낸 모델도 시도하세요.
