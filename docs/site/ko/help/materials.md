## 이미지를 Fill에 사용하기

머티리얼 레이어 속성에서 대상 채널을 활성화하고 “이미지 Fill”에서 이미지를 선택하거나 프로젝트에서 드롭합니다. 이미지를 지정하면 해당 채널의 일정 값을 대체합니다. 수치 채널은 이미지의 R 채널을, 투명도는 알파를 사용합니다. “연결 해제”로 이미지를 제거할 수 있습니다.

UV 변환에는 반복 횟수, 위치, 회전, 이미지 반복이 있으며 해당 레이어의 이미지에 공통으로 적용됩니다. “UV 초기화”로 기본값으로 되돌릴 수 있습니다. “높이에서 노멀 생성”은 씬 전체에 적용됩니다. 지정한 Normal 이미지를 사용하려면 이 자동 생성을 끄세요.

## 패턴 만들기

“패턴 추가”에서 오염, 녹, 진흙 튐, 긁힘, 먼지, 흐름을 선택합니다. 이미지 자체가 아닌 설정을 유지하므로 나중에 분포를 조절할 수 있습니다.

| 설정 | 조절 대상 |
| --- | --- |
| 세밀함·스케일 | 무늬의 반복과 입자 크기 |
| 양 | 무늬가 덮는 비율 |
| 대비 | 무늬 경계의 강도 |
| 시드 | 같은 경향을 유지하면서 배치를 바꾸는 수치 |
| 옥타브 | 노이즈에 겹치는 세부 표현의 단계 수 |
| 색상 변화 | 무늬 안의 색상 편차 |
| 릴리프 | Height에 더하는 요철 |
| 반전 | 무늬 분포 반전 |
| 형상에 따른 배치·강도 | 볼록한 부분·오목한 부분·AO를 이용한 배치. 자세한 내용은 [웨더링](/ko/guide#weathering) 참고 |

패턴이 사용하는 채널에서는 이미지 Fill보다 패턴이 우선합니다. 이미지가 반영되지 않으면 “패턴 사용 중” 표시와 채널 활성화 상태를 확인하세요.

## 머티리얼 프리셋

현재 머티리얼을 등록하여 프로젝트 패널의 프리셋에서 다시 사용할 수 있습니다. 선택한 레이어에 적용하는 조작과 에셋을 추가하여 사용하는 조작을 구분해서 사용하세요. 저장한 프리셋은 오른쪽 클릭 메뉴에서 업데이트·이름 변경·삭제할 수 있으며, 즐겨찾기에도 등록할 수 있습니다. 내장 프리셋과 사용자가 저장한 프리셋은 가능한 편집 작업이 다릅니다.

### 원하는 영역에 머티리얼 칠하기

머티리얼 브라우저에서 머티리얼을 선택하면 브러시, 폴리곤 채우기, UV 셸 채우기로 일부 영역에 칠할 수 있습니다. 이미 칠한 머티리얼 레이어나 폴더를 선택하면 같은 머티리얼로 더 칠할 수 있습니다. [면과 UV 아일랜드 채우기](/ko/help/brush)를 참고하세요.

## 머티리얼 다운로드와 오프라인 사용 {#material-downloads}

현재 설치 프로그램에는 머티리얼 목록과 미리보기가 포함되지만, 다운로드 대상 이미지 머티리얼의 원본 이미지는 포함되지 않습니다. 이러한 이미지 머티리얼은 처음 사용할 때 다운로드합니다. **다운로드 아이콘이 있으면 아직 이미지가 필요합니다.** 목록을 오프라인에서 볼 수 있어도 머티리얼 자체를 오프라인에서 사용할 준비가 끝난 것은 아닙니다.

프로시저럴 머티리얼과 직접 가져온 이미지는 머티리얼 다운로드 없이 사용할 수 있습니다. 정식판과 체험판은 다운로드 캐시를 따로 관리합니다.

1. 온라인 상태에서 라이브러리의 머티리얼을 선택합니다. 이미지가 없는 머티리얼을 사용하는 작업을 하면 다운로드가 시작됩니다.
2. 미리 준비하려면 머티리얼을 오른쪽 클릭하고 **Download for offline use**(오프라인 사용을 위해 다운로드)를 선택합니다. 나중에 사용할 이미지를 준비하는 작업입니다.
3. 프로젝트 패널의 **Downloading → Verifying → Extracting**(다운로드 → 검증 → 압축 풀기)이 끝날 때까지 기다립니다.
4. 다운로드 후에는 캐시로 오프라인에서도 사용할 수 있습니다. 다운로드 중에 씬·레이어·도구 등의 대상을 바꿨다면, 완료 후 머티리얼을 다시 선택하여 현재 대상에 적용하세요.

다른 머티리얼을 다운로드하려면 현재 다운로드가 끝날 때까지 기다리거나 **Cancel download**(다운로드 취소)를 선택하세요. 오프라인으로 전환하기 전에 필요한 머티리얼을 각각 준비해 두세요.

### 실패하거나 취소한 다운로드 재시도 {#material-download-retry}

- 연결 상태를 확인한 뒤 프로젝트 패널에서 **Retry download**(다운로드 재시도)를 누릅니다. 취소한 뒤에도 재시도할 수 있습니다.
- 오류 메시지에 커서를 올리면 제공되는 세부 정보를 확인할 수 있습니다. **Dismiss**(닫기)는 실패／취소 상태 표시를 닫습니다.
- 제공자가 해당 머티리얼의 다운로드 파일을 등록하지 않았다는 메시지가 나오면, 연결을 재시도하는 것만으로 파일을 받을 수는 없습니다.
- 다운로드했지만 적용되지 않았다면 머티리얼을 다시 선택하고 대상 레이어와 활성화된 채널을 확인하세요.

### 다운로드한 머티리얼 제거 {#material-cache-uninstall}

디스크 공간을 확보하려면 머티리얼을 오른쪽 클릭하고 **Uninstall downloaded material...**(다운로드한 머티리얼 제거)를 선택합니다. 확인 창의 머티리얼 이름과 다운로드 용량을 확인한 뒤 진행하세요.

| 삭제되는 항목 | 유지되는 항목 |
| --- | --- |
| 해당 머티리얼의 다운로드 데이터(캐시) | 프로젝트에 이미 복사된 이미지, 머티리얼 항목과 미리보기, 이전 설치에 포함된 이미지가 있다면 해당 이미지 |

**프로젝트에 이미 복사된 이미지는 지워지지 않습니다.** 머티리얼도 목록에 남으므로 다음에 사용할 때 다시 다운로드할 수 있습니다. 이전 설치에 포함된 이미지가 남아 있다면 이를 사용할 수 있는 경우가 있습니다. 현재 설치 프로그램에 이미지 머티리얼의 원본 이미지가 포함된다는 뜻은 아닙니다. 앞으로 오프라인에서 사용할 머티리얼의 캐시는 남겨 두세요.

다운로드·그리기·다른 처리 중에는 제거할 수 없습니다. 버튼이 비활성화되어 있다면 처리가 끝났는지, 제거 가능한 데이터가 있는지 확인하세요. 추가 파일이나 링크 때문에 안전하게 제거할 수 없다는 메시지가 나오면 폴더 전체를 수동으로 삭제하지 말고 표시된 이유를 확인하세요. 제거에 실패하면 캐시 폴더의 권한과 다른 앱이 사용 중인지 확인한 후 재시도합니다.
