## 이미지를 Fill에 사용하기

머티리얼 레이어 속성에서 대상 채널을 활성화하고 “이미지 채우기”에서 이미지를 선택하거나 프로젝트에서 드롭합니다. 이미지를 지정하면 해당 채널의 일정 값을 대체합니다. 수치 채널은 이미지의 R 채널을, 투명도는 알파를 사용합니다. “지우기”로 이미지를 제거할 수 있습니다.

UV 변환에는 반복 횟수, 위치, 회전, 이미지 반복이 있으며 해당 레이어의 이미지에 공통으로 적용됩니다. “UV 초기화”로 기본값으로 되돌릴 수 있습니다. “높이에서 노멀 생성”은 씬 전체에 적용됩니다.

### 노멀 맵으로 요철만 추가하기 {#normal-map-only}

노멀 이미지만으로 요철을 추가하려면 이미지 Fill의 “노멀 맵으로 요철만 추가...”를 사용하세요. Normal만 활성화되고 장면 전체의 높이에서 노멀 생성이 꺼집니다. Height로 요철을 만드는 작업으로 돌아갈 때는 이 장면 전체 설정을 확인하세요.

## 패턴 만들기

“패턴 추가”에서 오염, 녹, 진흙 튐, 긁힘, 먼지, 흐름을 선택합니다. 이미지 자체가 아닌 설정을 유지하므로 나중에 분포를 조절할 수 있습니다.

| 설정 | 조절 대상 |
| --- | --- |
| 스케일 | 무늬의 반복과 입자 크기 |
| 강도 | 무늬가 덮는 비율 |
| 대비 | 무늬 경계의 강도 |
| 시드 | 같은 경향을 유지하면서 배치를 바꾸는 수치 |
| 디테일 | 노이즈에 겹치는 세부 표현의 단계 수 |
| 변화 | 무늬 안의 색상 편차 |
| 요철 | 패턴 영역에 요철 추가. 먼저 Height 채널을 켜세요 |
| 반전 | 무늬 분포 반전 |
| 메시 배치 / 메시 영향도 | 볼록한 부분·오목한 부분·AO를 이용한 배치. 자세한 내용은 [웨더링](/ko/guide#weathering) 참고 |

패턴은 BaseColor·Roughness·Metallic·Height에 적용되며, 이 채널에서는 이미지 Fill보다 우선합니다. Normal과 Emission에는 패턴이 적용되지 않습니다. 이미지가 반영되지 않으면 “(패턴이 적용됨)” 표시와 채널 활성화 상태를 확인하세요. “무작위”로 시드를 바꾸고 “반전”으로 분포를 뒤집을 수 있습니다. “패턴 제거”는 채널 값을 유지하면서 일반 Fill로 되돌립니다.

## 머티리얼 프리셋

현재 머티리얼을 등록하여 에셋 브라우저의 프리셋에서 다시 사용할 수 있습니다.

단일 레이어 프리셋으로 기존 Fill 레이어를 바꾸려면 잠기지 않은 Fill 레이어를 선택하고 “선택한 레이어에 적용”을 사용합니다. 채널 값, 이미지, 패턴 설정이 바뀌며 실행 취소로 되돌릴 수 있습니다.

머티리얼을 뷰포트로 드래그하면 새 레이어가 추가됩니다. 여러 레이어로 된 프리셋은 선택한 레이어 위에 편집 가능한 레이어와 폴더로 추가됩니다.

저장한 프리셋은 오른쪽 클릭 메뉴에서 업데이트·이름 변경·삭제할 수 있으며, 즐겨찾기에도 등록할 수 있습니다. 내장 프리셋과 사용자가 저장한 프리셋은 가능한 편집 작업이 다릅니다.

### 원하는 영역에 머티리얼 칠하기

대상 텍스처 세트를 먼저 선택한 뒤 에셋 브라우저에서 머티리얼을 고르세요. 브러시, 폴리곤 채우기, UV 셸 채우기는 현재 선택한 텍스처 세트 안의 일부 영역을 칠합니다. 이미 칠한 머티리얼 레이어나 폴더를 선택하면 같은 머티리얼로 더 칠할 수 있습니다. [면과 UV 아일랜드 채우기](/ko/help/brush)를 참고하세요.

머티리얼로 전체를 채울 때도 현재 선택한 텍스처 세트를 대상으로 편집합니다. 에셋 브라우저에서 새 머티리얼을 칠하기 시작하면 현재 선택한 텍스처 세트에 기록됩니다. 기존 레이어에 덧칠할 때는 그 레이어가 속한 세트가 대상입니다. 같은 머티리얼을 사용하는 파트는 최종 텍스처도 공유하므로 UV가 겹치는 위치의 변화가 다른 파트에도 보일 수 있습니다.

### 머티리얼 프리셋에 저장되는 내용 {#material-preset-data}

현재 머티리얼 등록은 선택한 하나의 Fill 레이어의 채널 값과 사용 설정, 이미지와 UV, 패턴 설정을 저장합니다. 장면 전체나 마스크, 레이어 불투명도를 저장하는 기능은 아닙니다. 오른쪽 클릭으로 선택한 레이어의 머티리얼로 덮어쓰면 채널 값과 패턴 설정으로 교체합니다. 이미지나 여러 레이어 구성을 유지하려면 원본 프리셋을 남기고 다른 이름으로 등록하세요. 사용자 프리셋은 최대 512개까지 저장할 수 있습니다.

### 머티리얼을 칠할 채널 {#material-paint-target}

머티리얼을 칠하거나 지우는 대상은 뷰포트 표시 모드에 따라 달라집니다. BaseColor·Normal·Roughness·Metallic·Height·Emission을 단독 표시하면 해당 채널만 편집합니다. PBR·NPR·레이어 마스크 보기에서는 모든 채널이 대상입니다. 덧칠하거나 지우기 전에 속성의 “Paint / erase target”을 확인하세요.

### 덧칠하거나 일반 그리기로 돌아가기 {#material-resume}

부분적으로 칠한 머티리얼의 Fill 레이어나 폴더를 선택하면 덧칠할 수 있습니다. 폴더의 대상 레이어는 같은 세트의 Fill 레이어이고 마스크가 활성화되어 있어야 합니다. 마스크 없이 전체를 덮는 Fill을 부분 편집하려면 먼저 마스크를 추가하세요. 일반 색상 그리기로 돌아가려면 속성의 “머티리얼 선택 해제”를 누릅니다. 적용된 머티리얼 레이어는 유지됩니다.

## 머티리얼 다운로드와 오프라인 사용 {#material-downloads}

Ver.0.3.0에서는 머티리얼 목록의 썸네일 데이터를 줄여 설치 프로그램과 신규 설치 용량이 작아졌습니다. 그리기에 쓰는 머티리얼 원본 이미지의 품질은 유지됩니다.

현재 설치 프로그램에는 머티리얼 목록과 미리보기가 포함되지만, 다운로드 대상 이미지 머티리얼의 원본 이미지는 포함되지 않습니다. 이러한 이미지 머티리얼은 처음 사용할 때 다운로드합니다. **다운로드 아이콘이 있으면 아직 이미지가 필요합니다.** 목록을 오프라인에서 볼 수 있어도 머티리얼 자체를 오프라인에서 사용할 준비가 끝난 것은 아닙니다.

프로시저럴 머티리얼과 직접 가져온 이미지는 머티리얼 다운로드 없이 사용할 수 있습니다. 정식판과 체험판은 다운로드 캐시를 따로 관리합니다.

1. 온라인 상태에서 라이브러리의 머티리얼을 선택합니다. 이미지가 없는 머티리얼을 사용하는 작업을 하면 다운로드가 시작됩니다.
2. 미리 준비하려면 머티리얼을 오른쪽 클릭하고 **Download for offline use**(오프라인 사용을 위해 다운로드)를 선택합니다. 나중에 사용할 이미지를 준비하는 작업입니다.
3. 에셋 브라우저의 **Downloading → Verifying → Extracting**(다운로드 → 검증 → 압축 풀기)이 끝날 때까지 기다립니다.
4. 다운로드 후에는 캐시로 오프라인에서도 사용할 수 있습니다. 다운로드 중에 씬·레이어·도구 등의 대상을 바꿨다면, 완료 후 머티리얼을 다시 선택하여 현재 대상에 적용하세요.

다른 머티리얼을 다운로드하려면 현재 다운로드가 끝날 때까지 기다리거나 **Cancel download**(다운로드 취소)를 선택하세요. 오프라인으로 전환하기 전에 필요한 머티리얼을 각각 준비해 두세요.

### 실패하거나 취소한 다운로드 재시도 {#material-download-retry}

- 연결 상태를 확인한 뒤 에셋 브라우저에서 **Retry download**(다운로드 재시도)를 누릅니다. 취소한 뒤에도 재시도할 수 있습니다.
- 오류 메시지에 커서를 올리면 제공되는 세부 정보를 확인할 수 있습니다. **Dismiss**(닫기)는 실패／취소 상태 표시를 닫습니다.
- 제공자가 해당 머티리얼의 다운로드 파일을 등록하지 않았다는 메시지가 나오면, 연결을 재시도하는 것만으로 파일을 받을 수는 없습니다.
- 다운로드했지만 적용되지 않았다면 머티리얼을 다시 선택하고 대상 레이어와 활성화된 채널을 확인하세요.

### 머티리얼과 데칼 캐시 관리 {#material-cache-management}

[Ver.0.2.0](https://github.com/MametaroGG/HarmoFlow/releases/tag/Ver.0.2.0)에서는 다운로드한 머티리얼과 데칼의 캐시 용량 상한을 설정하고 불필요한 데이터를 정리할 수 있습니다. 디스크 여유 공간에 맞춰 관리하세요. 첫 다운로드에는 인터넷 연결이 필요하며, 다운로드한 에셋은 오프라인에서도 사용할 수 있습니다. 오프라인 작업에 필요한 데이터는 남겨 두세요.

데칼 라이브러리 제거도 지원합니다. 배치한 데칼의 원본 데이터는 저장한 씬에도 유지됩니다. 데칼 255종과 첫 사용 시 라이브러리 전체 다운로드는 [데칼 라이브러리](./assets.md#decal-library)를 참고하세요. 개별 머티리얼 제거 방법은 아래와 같습니다.

### 머티리얼 데이터 제거하기 {#material-cache-uninstall}

디스크 공간을 확보하려면 머티리얼을 오른쪽 클릭하고 **Uninstall material data...**(머티리얼 데이터 제거)를 선택합니다. 확인 창에서 머티리얼 이름과 설치된 데이터의 용량을 확인하세요. 이 버전에서는 해당 메뉴가 영어로 표시될 수 있습니다.

이 작업은 해당 머티리얼의 다운로드한 맵과 앱 폴더에 남아 있는 대응하는 기본 제공 맵을 삭제합니다. 프로젝트에 이미 복사된 이미지, 라이브러리 항목, 머티리얼 설정과 미리보기는 유지됩니다.

다시 사용하려면 재다운로드가 필요합니다. 앞으로 오프라인에서 쓸 머티리얼의 설치 데이터는 남겨 두세요.

다운로드·그리기·다른 처리 중에는 제거할 수 없습니다. 버튼이 비활성화되어 있다면 처리가 끝났는지, 제거 가능한 데이터가 있는지 확인하세요. 추가 파일이나 링크 때문에 안전하게 제거할 수 없다는 메시지가 나오면 폴더 전체를 수동으로 삭제하지 말고 표시된 이유를 확인하세요. 제거에 실패하면 캐시 폴더의 권한과 다른 앱이 사용 중인지 확인한 후 재시도합니다.

## 머티리얼 마스크 변형(Ver.0.3.0) {#material-mask-transform}

마스크가 있는 머티리얼 레이어를 선택하고 축소 선택으로 마스크 모양을 따라 영역을 고릅니다. Ctrl+T 변형 프레임으로 이동·회전·확대 및 축소합니다. 재질 무늬는 머티리얼 좌표에 고정되며 마스크 범위만 바뀝니다. K 레이어 이동도 마스크를 옮깁니다.

마스크 변형이 포함된 씬을 다시 열려면 Ver.0.3.0 이상이 필요합니다. 구버전에서도 사용할 프로젝트는 [변경 전 사본을 보관](./projects.md#scene-version-compatibility)하세요.
