# 导出图片 {#export}

## 导出与保存场景的区别

<GuideMedia name="export-settings" />

在导出面板中选择输出位置、格式和分辨率。支持 PNG、JPG、TGA、EXR、PSD 等格式。保存场景以便继续编辑，与将完成的纹理导出为图片，是两项不同的操作。

如果只需要导出几何形状贴图，请在网格贴图烘焙界面使用 PNG 输出。贴图为线性数据。输出时会在目标位置新建文件夹。

## 输出设置

1. 在“通道”中选择导出分辨率。
2. 在“导出”中指定输出文件夹、基础名称和格式。
3. 启用所需通道，并选择法线贴图规范。
4. 点击“导出纹理”。

| 项目 | 选择方法 |
| --- | --- |
| PNG | 希望无损保存图片时使用的基本格式 |
| JPG | 用于减小彩色图片的文件大小。由于采用有损压缩，数值贴图请使用 PNG 等格式 |
| TGA | 用于交付给要求 TGA 的制作环境 |
| EXR | 用于交付给支持 EXR 的制作环境。仅更改格式不会提高原始编辑数据的精度 |
| PSD | 每个通道输出一个文件，包含栅格图层及可编辑的不透明度／混合设置。如需编辑 HarmoFlow 的笔画或调整参数，请同时保存 .harmos。详见下文 |
| OpenGL / DirectX | 选择切线空间 Normal 的绿色通道方向，并与目标环境的设置保持一致 |

### PSD 保留的内容

为每个通道创建 PSD，将绘画、填充和路径按原名称、顺序和可见状态保存为图像图层。不透明度与混合模式（正常、正片叠底、加法、叠加）作为可编辑的 PSD 设置保留。加法对应“线性减淡（添加）”。

蒙版与剪贴效果会烘焙到像素透明度中；文件夹保留层级、名称、可见状态和折叠状态（穿透混合）。对于 Paint、Fill、Path 的普通通道合成，不会仅为补偿合成差异而额外添加校正图层。

生成法线、法线的 UV 边界处理和立体高度效果，会按需保存为独立图层。如果需要重新编辑原始笔画或设置，请同时保存 Scene

### PSD 中的调整图层

调整图层会按目标通道导出为栅格图像图层。HarmoFlow 的调整参数不会保留为 Photoshop 原生调整图层。如需以后修改调整值，请同时保存 .harmos 场景。

导出的调整图像依赖于该位置下方图层的合成结果。在 PSD 中改变下方内容，不会自动重新计算 HarmoFlow 的调整。

普通图片格式会按通道分别输出。默认启用“合并使用同一材质的部件”，将使用相同材质的部件的 UV 区域合并为一组，不同材质则分别导出。UV 重叠的部分优先使用第一个部件的绘制结果。如果在重叠 UV 上绘制了不同内容，请关闭此设置，按部件分别导出。

## 网格 UV 外部的像素

在“首选项 → VRAM → 纹理”的“Outside mesh UVs”中，可选择用原纹理补全（Restore source texture）、透明（Transparent）或保留整张纹理（Keep full texture）。存储方式的更改会在下次导入模型或更改分辨率时生效。

不支持稀疏 GPU 存储时，也可透明导出。原纹理补全适用于普通导出，以及分层 PSD 的背景和合并图像。
