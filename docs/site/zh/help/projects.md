# 项目、保存与恢复 {#projects}

<GuideFlow kind="save-export" />

## 新建项目与导入模型

通过“文件 → 新建项目”选择保存位置，再使用“导入模型”加载模型。支持 FBX、OBJ、glTF / GLB、DAE、PLY、STL、3DS、BLEND。制作纹理前，请为模型准备好 UV。对于不含 UV 的格式或数据，支持导入并不代表可以进行纹理编辑。

项目是集中管理资源和场景的工作文件夹。在“项目设置”中可以更改根文件夹和纹理分辨率。场景扩展名为 `.harmos`。


导入包内素材请参阅[Unity Package导入](./assets.md#unitypackage-import)。FBX中的变形及部件显示请参阅[网格与形态键](./viewport.md#mesh-visibility)。

## 选择合适的保存方式

| 操作 | 用途 |
| --- | --- |
| 保存场景 | 保存当前编辑状态。Ctrl+S |
| 场景另存为 | 使用其他名称保存编辑状态 |
| 增量保存 | 递增编号并保留版本。Ctrl+Alt+S |
| 打开场景 | 从已保存的编辑状态继续工作 |
| 导出为包 | 将项目打包为 `.harmopackage` 以便携带 |
| 导出到上次位置 | 重复使用上一次的打包输出位置 |
| 打开包 | 解压到设置的位置并打开 |
| 指定解压位置并打开 | 选择本次解压位置并打开 |

## 自动保存与恢复

在“偏好设置 → 自动保存”中启用自动保存，并设置间隔（1〜60 分钟）、前缀、是否仅在有更改时保存，以及保留数量。保留数量为 0 时会保留全部文件。也可使用“立即自动保存”或打开保存文件夹。

通过“文件 → 恢复自动保存”选择已保存的快照。“恢复上次保存”可返回可用的上一次保存状态。确认恢复后的内容无误后，请正常保存场景。

### 查找和选择自动保存 {#autosave-location}

已保存项目的快照位于项目文件夹内的 `autosave` 中。未保存会话使用 HarmoFlow 的应用数据区域。请通过“偏好设置 → 自动保存”中的“当前文件夹”和“打开自动保存文件夹”确认实际位置。

在“恢复自动保存”中，先核对日期、时间和目标，再选择快照。属于项目的自动保存会以 `原场景名_recovered_编号` 的名称，作为独立场景加入项目的场景文件夹。项目中缺失的资源会被恢复，已有资源文件不会改变。未保存会话的自动保存会作为未保存场景打开，正常保存时可选择保存位置。恢复前应用也会尝试自动保存当前工作，但重要内容请先正常保存。

自动保存不能替代正常保存或备份。保留数量限制可能清理较旧的快照，因此需要长期保留的版本应另存、增量保存或备份。排查恢复问题时，请勿删除或移动原项目及自动保存数据。

## 在 GPU 错误后恢复工作 {#gpu-recovery}

::: warning 恢复需要成功的自动保存
GPU 错误后，应用会尝试创建恢复用自动保存，但不一定成功。保存失败、数据缺失或强制退出等情况可能导致无法恢复，也无法保证找回所有未保存的更改。
:::

1. 记录错误提示中的原因、操作和详细信息，确认提示是“工作已自动保存”还是“恢复用自动保存失败”。保存成功时，可选择“重新启动”，或选择“退出”后再次启动 HarmoFlow。
2. 下次启动时如出现“恢复工作”，请确认目标后选择“恢复”，并等待加载结束。如果原项目不可用，或工作原本尚未保存，内容可能作为未保存场景打开。
3. 检查恢复后的模型、图层、最近绘制的内容、材质和图片。能正常打开并不代表所有内容都已完整恢复。
4. 确认内容后，使用“保存场景”（Ctrl+S）。**仅执行恢复不会覆盖原场景文件；在正常保存之前，磁盘上的原文件保持不变。** 如果还想保留原有保存，请使用“场景另存为”。

如果打算稍后恢复，**请先将鼠标悬停在“暂不恢复”按钮上，在点击前记下工具提示中的自动保存路径。** 点击后会关闭恢复提示，但不会删除自动保存数据。之后可按需使用“恢复自动保存”检查。若没有提示、保存失败或恢复时再次退出，请保留原始数据，查看[GPU 错误排查与反馈](./troubleshooting.md#gpu-errors)。反复尝试恢复前，请先检查 GPU 负载与驱动状态。
