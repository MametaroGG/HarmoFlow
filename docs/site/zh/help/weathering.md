# 为边缘与凹部添加做旧效果 {#weathering}

## 让做旧效果贴合形状

1. **选择做旧用的填充图层**

   启用程序化图案，并调整颜色、Roughness 等参数。

2. **选择“按形状分布”**

   可选择“凸边”“凹边”或“遮蔽区域污垢（AO）”。“整个表面”表示不受形状限制的分布。

3. **调整强度与图案**

   用“形状蒙版强度”调整形状的影响程度，再通过“数量”“细节密度”等设置调整做旧效果的分布。

<GuideMedia name="place-weathering" />

## 保存设置与 UV 变换

按形状分布时，不会应用填充图片的 UV 变换。分布设置会保存到场景和材质预设中，并支持 Undo/Redo。
