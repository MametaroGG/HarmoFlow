# 为边缘与凹部添加做旧效果 {#weathering}

## 让做旧效果贴合形状

1. **选择做旧用的填充图层**

   启用程序化图案，并调整颜色、Roughness 等参数。

2. **选择“网格分布”**

   可选择“凸边缘”“凹边缘”或“遮蔽污垢 (AO)”。“整个表面”不按几何形状限制分布。

   如果网格贴图仍在烘焙，请等待完成后更新分布。若结果没有更新，请检查显示的错误，并使用“重新烘焙网格贴图”。

3. **调整强度与图案**

   用“网格影响强度”调整形状的影响程度，再通过“强度”“缩放”等设置调整做旧效果的分布。

## 保存设置与 UV 变换

按形状分布时，不会应用填充图片的 UV 变换。分布设置会保存到场景和材质预设中，并支持 Undo/Redo。
