# 术语说明 {#glossary}

## 纹理制作术语

| 术语 | 含义 |
| --- | --- |
| 网格、多边形 | 由顶点和面构成的 3D 形状；多边形指其中的面 |
| 网格部件 | 构成模型的部件。在 HarmoFlow 中是纹理集的划分单位 |
| UV、UV 岛（壳） | 3D 表面与 2D 图片之间的对应坐标；其中相互连接的区域称为 UV 岛 |
| 伪四边形 | 检测两个三角形，并将其作为等效四边形处理的机制 |
| 纹理集 | 某个部件使用的颜色、粗糙度等图片的集合 |
| 通道 | 构成材质质感的信息类型，如颜色、法线、粗糙度等 |
| PBR / NPR | 基于物理反射的表现方式／卡通等非真实感表现方式 |
| 烘焙 | 将笔画、几何形状等信息计算并写入图片的过程 |
| 网格贴图 | 根据模型形状计算出的图片，如曲率、遮蔽等 |
| 曲率、AO | 表面凹凸的趋势／被周围几何形状遮蔽的程度 |
| 法线、切线空间 | 面的朝向／以表面为基准的坐标系，用于常规 Normal 纹理 |
| 对象空间 | 以模型本身为基准的坐标系，用于几何形状贴图中的法线和笔画 |
| Height | 高度信息，用于显示凹凸效果，与编辑模型顶点不同 |
| Fill | 使用固定值、图片或生成图案进行填充的图层 |
| 程序化、种子 | 通过计算生成图案的方式／决定图案分布的数值 |
| Alpha、不透明度 | 表示透明度的信息／控制显示浓度的设置 |
| 蒙版、剪贴 | 指定显示区域的信息／利用下方图层绘制范围进行限制的功能 |
| 锚点、控制柄 | 路径经过的点／调整曲线方向和弯曲程度的手柄 |
| 形态键 | 通过权重混合顶点变形，以改变表情等的数据 |
| 线性、sRGB | 用与光强成比例的数值表示颜色的方式／用于显示的非线性颜色编码。彩色图像与粗糙度等数据贴图的处理方式不同 |
| VRAM、BC7 | GPU 显存／用于 GPU 的纹理压缩格式 |
| IBL、F0、ACES | 使用环境图片的照明／正面观察时的基础反射率／将亮度映射到显示范围的色调映射 |
| 高模、烘焙笼、UDIM | 高细节模型／用于限定传递射线范围的几何形状／使用多个 UV 瓦片的方式。目前的网格贴图烘焙尚不支持 |
