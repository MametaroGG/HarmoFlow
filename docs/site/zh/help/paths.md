# 绘制与编辑路径 {#paths}

<GuideMedia name="path-settings" />

## 创建路径

按 P 切换到路径工具，点击模型放置锚点。按 Enter 确认并保持路径开放，按 C 闭合，按 F 闭合并填充，按 Esc 取消。绘制过程中，Delete / Backspace 会撤销最后一个锚点。点击起点也可闭合路径。

点击已确认的路径可重新编辑。拖动锚点或控制柄可调整轮廓，点击曲线可添加点，按 Delete 可删除选中的点。点击最后一个锚点并收回出向控制柄，可以形成尖角。点击路径外部或按 Enter、Esc 可再次确认。也可以在 UV 编辑器中一边查看 UV 岛位置，一边进行编辑。

<GuideMedia name="edit-path" />

## 填充与双重描边

在路径面板中，可以分别设置填充、外描边和内描边。填充具有圆角／尖角和不透明度设置，描边具有宽度、硬度和不透明度设置，各部分均可选择绘制通道。交换色块或切换为“无”，可以实现仅描边或仅填充的效果。点击“重新烘焙路径”可更新结果。

## 为填充和描边指定材质

路径的填充、外描边和内描边可以分别使用不同的材质。选择对应色块，再从“材质”中选择，或从材质浏览器拖入。点击浏览器中的材质，也会将其分配给当前选中的填充或描边。选择“纯色”可恢复原来的颜色。

材质贴图和合成关系会保留，线宽和不透明度可按路径调整。这些设置支持场景保存和撤销／重做。
