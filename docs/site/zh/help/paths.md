# 绘制与编辑路径 {#paths}

<GuideMedia name="path-settings" />

## 创建路径

按 P 切换到路径工具。单击模型可放置尖角锚点，按住鼠标拖动可拉出控制柄并创建曲线。绘制新路径时，单击最后一个锚点可收回出向控制柄。

按 Enter 确认并保持路径开放，按 C 闭合，按 F 闭合并填充，按 Esc 取消。绘制过程中，Delete / Backspace 会撤销最后一个锚点。点击起点也可闭合路径。

一条路径只能位于一个纹理集内。开放路径至少需要两个锚点，闭合路径至少需要三个。绘制时，将指针放在 3D 视口上再按 C／F。

在 3D 视图中点击已完成的路径可重新编辑。拖动锚点或控制柄可调整轮廓，点击曲线可添加点，按 Delete 可删除选中的点。双击锚点可切换尖角与平滑。点击路径外部或按 Enter、Esc 可结束编辑。

也可以在 UV 编辑器中一边查看 UV 岛位置，一边进行编辑。操作方法请参阅 [UV 编辑器](./uv.md#uv-path-editing)。

## 填充与双重描边

在路径面板中，可以分别设置填充、外描边和内描边。填充具有圆角／尖角和不透明度设置，描边具有宽度、硬度和不透明度设置，各部分均可选择绘制通道。交换色块或切换为“无”，可以实现仅描边或仅填充的效果。点击“重新烘焙路径”可更新结果。

## 为填充和描边指定材质

路径的填充、外描边和内描边可以分别使用不同的材质。选择对应色块，再从“材质”中选择，或从资产浏览器拖入。点击浏览器中的材质，也会将其分配给当前选中的填充或描边。选择“纯色”可恢复原来的颜色。

材质贴图和合成关系会保留，线宽和不透明度可按路径调整。这些设置支持场景保存和撤销／重做。
