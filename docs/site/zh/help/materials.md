## 将图片用于填充

在材质图层的属性中启用目标通道，然后在“图片填充”中选择图片，或从项目中拖放图片。指定图片后，该通道的固定值会被图片替代。数值通道使用图片的 R 通道，透明度使用 Alpha 通道。点击“解除”可移除图片。

UV 变换包括平铺次数、位置、旋转和图片重复设置，会共同应用于该图层的图片。点击“重置 UV”可恢复初始值。“从高度生成法线”会作用于整个场景。如需使用指定的 Normal 图片，请关闭此自动生成功能。

## 创建图案

通过“添加图案”选择污渍、锈迹、泥点、划痕、灰尘或流痕。保存的是设置而不是图片本身，因此之后仍可调整分布。

| 设置 | 调整内容 |
| --- | --- |
| 细节密度、缩放 | 图案的重复频率和颗粒大小 |
| 数量 | 图案覆盖的比例 |
| 对比度 | 图案边界的强度 |
| 种子 | 在保持总体特征的同时改变分布的数值 |
| 倍频层数 | 叠加到噪声中的细节层数 |
| 颜色变化 | 图案中的颜色差异 |
| 浮雕 | 添加到 Height 的凹凸 |
| 反转 | 反转图案分布 |
| 按形状分布、强度 | 利用凸部、凹部和 AO 控制分布。详见[做旧](/zh/guide#weathering) |

对于图案使用的通道，图案的优先级高于图片填充。如果图片没有显示，请检查“图案正在使用”提示以及通道是否启用。

## 材质预设

可以保存当前材质，并在项目面板的预设中重复使用。请根据需要，选择应用到当前图层，或添加资源后使用。已保存的预设可通过右键菜单更新、重命名、删除或加入收藏。内置预设与用户保存预设可执行的编辑操作不同。

### 局部绘制材质

在材质浏览器中选择材质后，可用笔刷、多边形填充或 UV 壳填充进行局部绘制。选择已绘制的材质图层或文件夹，可继续使用同一材质添加覆盖范围。详见[填充面或 UV 岛](/zh/help/brush)。
