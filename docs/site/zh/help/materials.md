## 将图片用于填充

在材质图层的属性中启用目标通道，然后在“图像填充”中选择图片，或从项目中拖放图片。指定图片后，该通道的固定值会被图片替代。数值通道使用图片的 R 通道，透明度使用 Alpha 通道。点击“清除”可移除图片。

UV 变换包括平铺次数、位置、旋转和图片重复设置，会共同应用于该图层的图片。点击“重置 UV”可恢复初始值。“从高度生成法线”会作用于整个场景。如需使用指定的 Normal 图片，请关闭此自动生成功能。

## 创建图案

通过“添加图案”选择污渍、锈迹、泥点、划痕、灰尘或流痕。保存的是设置而不是图片本身，因此之后仍可调整分布。

| 设置 | 调整内容 |
| --- | --- |
| 缩放 | 图案的重复频率和颗粒大小 |
| 强度 | 图案覆盖的比例 |
| 对比度 | 图案边界的强度 |
| 随机种子 | 在保持总体特征的同时改变分布的数值 |
| 细节 | 叠加到噪声中的细节层数 |
| 变化 | 图案中的颜色差异 |
| 浮雕 | 在图案区域增减高度；需先启用 Height 通道 |
| 反转 | 反转图案分布 |
| 网格分布／网格影响强度 | 利用凸部、凹部和 AO 控制分布。详见[做旧](/zh/guide#weathering) |

对于图案使用的通道，图案的优先级高于图片填充。如果图片没有显示，请检查“（受图案影响）”提示以及通道是否启用。

## 材质预设

可以保存当前材质，并在资产浏览器的预设中重复使用。

若要用单图层预设替换现有填充图层，请选择未锁定的填充图层，再选择“应用到所选图层”。这会替换通道数值、图片和图案设置，可通过撤销恢复。

将材质拖入视口可添加新图层。多图层预设会在所选图层上方添加可编辑的图层和文件夹。

已保存的预设可通过右键菜单更新、重命名、删除或加入收藏。内置预设与用户保存预设可执行的编辑操作不同。

### 局部绘制材质

先选择目标纹理集，再在资产浏览器中选择材质。笔刷、多边形填充和 UV 壳填充会在当前选中的纹理集内进行局部绘制。选择已绘制的材质图层或文件夹，可继续使用同一材质添加覆盖范围。详见[填充面或 UV 岛](/zh/help/brush)。

使用材质整体填充时，目标也仅限于当前选中的纹理集，不会自动应用到模型中的其他纹理集。

## 材质下载与离线使用 {#material-downloads}

当前安装程序包含材质目录和预览，但不包含需要下载的图片材质的原始图片。这些图片材质会在首次使用时下载。**带有下载图标的材质仍需要获取图片。** 能离线浏览列表，并不表示材质本身已经可以离线使用。

程序化材质和自行导入的图片无需下载材质即可使用。完整版与试用版分别管理下载缓存。

1. 联网时从资源库中选择材质。使用尚未获取图片的材质时，会开始下载。
2. 如需提前准备，右键单击材质，选择 **Download for offline use**（下载以供离线使用）。此操作为之后的使用准备图片。
3. 等待资产浏览器中的 **Downloading → Verifying → Extracting**（下载 → 验证 → 解压）完成。
4. 下载完成后即可通过缓存离线使用。如果下载期间切换了场景、图层、工具或其他目标，请在完成后重新选择材质，将其用于当前目标。

如需下载另一种材质，请等待当前下载完成，或选择 **Cancel download**（取消下载）。离线之前，请逐个下载需要的材质。

### 下载失败或取消后重试 {#material-download-retry}

- 检查网络连接，再点击资产浏览器中的 **Retry download**（重试下载）。取消后也可以重试。
- 将鼠标悬停在错误信息上，可查看可用的详细信息。**Dismiss**（关闭）会关闭失败／取消状态提示。
- 如果提示提供方尚未发布该材质的下载文件，仅重试网络连接无法取得这些文件。
- 已下载但未应用时，请重新选择材质，并检查目标图层和已启用的通道。

### 卸载已下载的材质 {#material-cache-uninstall}

需要释放磁盘空间时，右键单击材质，选择 **Uninstall downloaded material...**（卸载已下载材质）。执行前请核对确认窗口中的材质名称和下载数据大小。

| 删除的内容 | 保留的内容 |
| --- | --- |
| 该材质已下载的数据（缓存） | 已复制到项目中的图片、材质条目和预览，以及旧安装中保留的附带图片（如有） |

**已经复制到项目中的图片不会被删除。** 材质也会保留在列表中，下次使用时可以重新下载。旧安装中可能仍有可使用的附带图片。这不表示当前安装程序包含图片材质的原始图片。仍需离线使用的材质，请保留其缓存。

下载、绘制或其他处理尚未结束时不能卸载。按钮不可用时，请等待处理完成，并确认是否存在可删除的数据。如果额外文件或链接导致无法安全删除，请检查提示原因，不要手动删除整个文件夹。如果卸载失败，请检查缓存文件夹权限及其他应用是否正在使用它，再重试。
