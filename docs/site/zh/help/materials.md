## 将图片用于填充

在材质图层的属性中启用目标通道，然后在“图像填充”中选择图片，或从项目中拖放图片。指定图片后，该通道的固定值会被图片替代。数值通道使用图片的 R 通道，透明度使用 Alpha 通道。点击“清除”可移除图片。

UV 变换包括平铺次数、位置、旋转和图片重复设置，会共同应用于该图层的图片。点击“重置 UV”可恢复初始值。“从高度生成法线”会作用于整个场景。

### 用法线贴图添加凹凸 {#normal-map-only}

要只用法线图片添加凹凸，请在图片填充中使用“仅添加法线贴图凹凸...”。该操作仅启用Normal，并关闭整个场景的从高度生成法线设置。返回用Height制作凹凸时，请检查这一场景级设置。

## 创建图案

通过“添加图案”选择污渍、锈迹、泥点、划痕、灰尘或流痕。保存的是设置而不是图片本身，因此之后仍可调整分布。

| 设置 | 调整内容 |
| --- | --- |
| 缩放 | 图案的重复频率和颗粒大小 |
| 强度 | 图案覆盖的比例 |
| 对比度 | 图案边界的强度 |
| 随机种子 | 在保持总体特征的同时改变分布的数值 |
| 细节 | 叠加到噪声中的细节层数 |
| 变化 | 图案中的颜色差异 |
| 浮雕 | 在图案区域增减高度；需先启用 Height 通道 |
| 反转 | 反转图案分布 |
| 网格分布／网格影响强度 | 利用凸部、凹部和 AO 控制分布。详见[做旧](/zh/guide#weathering) |

图案作用于 BaseColor、Roughness、Metallic 和 Height，并在这些通道中优先于图片填充。Normal 和 Emission 不受图案控制。如果图片没有显示，请检查“（受图案影响）”提示以及通道是否启用。“随机”可更换种子，“反转”可反转分布。“移除图案”会保留通道值并恢复为普通 Fill。

## 材质预设

可以保存当前材质，并在资产浏览器的预设中重复使用。

若要用单图层预设替换现有填充图层，请选择未锁定的填充图层，再选择“应用到所选图层”。这会替换通道数值、图片和图案设置，可通过撤销恢复。

将材质拖入视口可添加新图层。多图层预设会在所选图层上方添加可编辑的图层和文件夹。

已保存的预设可通过右键菜单更新、重命名、删除或加入收藏。内置预设与用户保存预设可执行的编辑操作不同。

### 局部绘制材质

先选择目标纹理集，再在资产浏览器中选择材质。笔刷、多边形填充和 UV 壳填充会在当前选中的纹理集内进行局部绘制。选择已绘制的材质图层或文件夹，可继续使用同一材质添加覆盖范围。详见[填充面或 UV 岛](/zh/help/brush)。

使用材质填充整个表面时，也以当前选中的纹理集为编辑目标。从资产浏览器开始绘制新的材质时，内容会记录到当前选中的纹理集中。在已有图层上继续绘制时，以该图层所属的纹理集为目标。使用同一材质的部件会共享最终纹理，因此UV重叠位置的变化也可能显示在其他部件上。

### 材质预设保存的内容 {#material-preset-data}

注册当前材质会保存所选一个Fill图层的通道值及开关、图片与UV设置、图案设置，不会保存整个场景、蒙版或图层不透明度。右键用所选图层材质覆盖时，会以通道值和图案设置替换预设。需要保留图片或多图层配方时，请保留原预设并另取名称注册。最多可保存512个用户预设。

### 材质绘制的目标通道 {#material-paint-target}

材质绘制和擦除的目标会随视口显示模式变化。单独显示BaseColor、Normal、Roughness、Metallic、Height或Emission时，只编辑该通道。PBR、NPR和图层蒙版视图会以全部通道为目标。添涂或擦除前，请查看属性中的“Paint / erase target”。

### 继续绘制或返回普通绘画 {#material-resume}

选择局部绘制材质的Fill图层或文件夹，可以继续添涂。文件夹内的目标图层必须属于同一纹理集，且均为启用了蒙版的Fill图层。要局部编辑没有蒙版的整面Fill，请先添加蒙版。点击属性中的“清除材质选择”可返回普通颜色绘制；已经应用的材质图层会保留。

## 材质下载与离线使用 {#material-downloads}

当前安装程序包含材质目录和预览，但不包含需要下载的图片材质的原始图片。这些图片材质会在首次使用时下载。**带有下载图标的材质仍需要获取图片。** 能离线浏览列表，并不表示材质本身已经可以离线使用。

程序化材质和自行导入的图片无需下载材质即可使用。完整版与试用版分别管理下载缓存。

1. 联网时从资源库中选择材质。使用尚未获取图片的材质时，会开始下载。
2. 如需提前准备，右键单击材质，选择 **Download for offline use**（下载以供离线使用）。此操作为之后的使用准备图片。
3. 等待资产浏览器中的 **Downloading → Verifying → Extracting**（下载 → 验证 → 解压）完成。
4. 下载完成后即可通过缓存离线使用。如果下载期间切换了场景、图层、工具或其他目标，请在完成后重新选择材质，将其用于当前目标。

如需下载另一种材质，请等待当前下载完成，或选择 **Cancel download**（取消下载）。离线之前，请逐个下载需要的材质。

### 下载失败或取消后重试 {#material-download-retry}

- 检查网络连接，再点击资产浏览器中的 **Retry download**（重试下载）。取消后也可以重试。
- 将鼠标悬停在错误信息上，可查看可用的详细信息。**Dismiss**（关闭）会关闭失败／取消状态提示。
- 如果提示提供方尚未发布该材质的下载文件，仅重试网络连接无法取得这些文件。
- 已下载但未应用时，请重新选择材质，并检查目标图层和已启用的通道。

### 管理材质与贴花缓存 {#material-cache-management}

[Ver.0.2.0](https://github.com/MametaroGG/HarmoFlow/releases/tag/Ver.0.2.0)为已下载的材质和贴花增加了缓存容量上限和无用数据清理功能，可按磁盘空间进行管理。首次下载需要互联网连接，已下载的资源可离线使用。请保留离线工作时所需资源的数据。

也可卸载贴花资源库。已放置贴花的源数据会保留在保存后的场景中。255种贴花和首次使用时整库下载的说明，请参阅[贴花资源库](./assets.md#decal-library)。单个材质的卸载步骤见下文。

### 卸载材质数据 {#material-cache-uninstall}

需要释放磁盘空间时，右键单击材质并选择 **Uninstall material data...**（卸载材质数据）。请在确认窗口中核对材质名称和已安装数据的大小。此版本中的该菜单项可能显示为英文。

此操作会删除该材质已下载的贴图，以及应用文件夹中残留的对应附带贴图。已经复制到项目中的图片、资源库条目、材质设置和预览会保留。

再次使用该材质时需要重新下载。如果之后需要离线使用，请保留其已安装数据。

下载、绘制或其他处理尚未结束时不能卸载。按钮不可用时，请等待处理完成，并确认是否存在可删除的数据。如果额外文件或链接导致无法安全删除，请检查提示原因，不要手动删除整个文件夹。如果卸载失败，请检查缓存文件夹权限及其他应用是否正在使用它，再重试。
