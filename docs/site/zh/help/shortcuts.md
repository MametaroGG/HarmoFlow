# 快捷键速查 {#shortcuts}

## 查看与修改按键设置

按键的作用会随当前面板和工具而变化。编辑输入框时，工具操作可能不会响应。

在“偏好设置 → 按键配置”中，可按操作名称或条件搜索，并修改键盘和鼠标绑定。带有“+”按钮的操作可以添加其他绑定。支持的类别包括常规、编辑、文件、工具、绘制、图层和 UV 编辑器。

固定操作不能修改。普通左键单击，以及与同时使用的操作冲突的组合，不能设为绑定。下表列出默认绑定。

## 操作、按键与手势

| 操作 | 按键与手势 |
| --- | --- |
| 饼状菜单 | 按住右键滑动，松开后选中；Esc 取消（3D 视口／UV 画布；已有的右键绑定优先） |
| 绘画 / 混色与模糊 / 路径 / 文字 | B / U / P / T |
| 相机旋转 | Alt+左键拖动 |
| 相机缩放 | 滚轮、Alt+右键拖动、Ctrl+左键拖动（向右或向上放大，向左或向下缩小） |
| 相机平移 | 中键拖动、Space+左键拖动 |
| 复制／剪切／粘贴／创建图层副本 | Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D（图层面板获得焦点时） |
| 删除图层 | Delete（图层面板获得焦点时） |
| 打开光标下的纹理集 | Shift+Alt+右键单击 |
| UV 画布平移 | 中键拖动，或 Space+左键拖动 |
| 笔刷大小 | [ / ]、Ctrl+Alt+左键或右键水平拖动 |
| 吸管 | 绘画时按 Ctrl+Shift+左键，松开后采用颜色 |
| 添加或取消选择 | 使用选择工具时 Shift+单击 |
| 确认开放路径 / 闭合 / 闭合并填充 | Enter / C / F（C、F仅在绘制路径时，光标位于视口上生效） |
| 取消路径绘制 / 删除绘制中的最后一个锚点 | Esc / Delete或Backspace |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 保存 / 增量保存 | Ctrl+S / Ctrl+Alt+S |
| 偏好设置 | Ctrl+, |
| 视口截图 | F12 |
| 暂停引擎 | Shift+Esc |

Delete或Backspace在绘制路径时删除最后一个锚点；编辑已有路径时，则删除选中的锚点。
