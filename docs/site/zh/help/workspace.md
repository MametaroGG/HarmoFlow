## 纹理集与网格部件

HarmoFlow 的纹理集以网格部件为单位。即使使用相同材质，不同部件仍会作为独立的纹理集处理。

普通笔刷和印章会画在当前选中的已有图层所属的纹理集中。如需绘制其他部件，请从图层面板顶部的列表切换纹理集，或对模型按 Shift+Alt+右键单击。从资产浏览器开始绘制新材质时，同样以当前选中的纹理集为目标。请先选择目标纹理集，再开始绘制。不会自动应用到其他纹理集。

## 各面板的功能

| 面板 | 功能 |
| --- | --- |
| 图层 | 叠加绘画与填充，调整可见性、不透明度和混合方式 |
| 通道 | 选择部件、设置工作分辨率、查看各通道 |
| 纹理集设置 | 位于图层旁的选项卡，用于查看通道和网格贴图 |
| UV 编辑器 | 查看当前部件的纹理和 UV 线框 |

## 打开面板与恢复布局

已关闭的面板可通过“窗口”菜单重新显示。如需恢复布局，请使用“重置布局”。将光标停留在各个项目上，可查看补充操作说明。
