# 界面与网格部件 {#workspace}


## Ver.0.3.0 的界面改进 {#workspace-020}

Ver.0.3.0 的饼状菜单会显示当前聚焦工具的名称和绑定按键，并可通过圆形子图标选择工具。视图导航还会显示平移、旋转、缩放操作及已设置的切换快捷键。

整理了饼状菜单的工具分组，以及从图层列表返回的操作。画笔笔触预览与预设名称不再重叠，下拉选项也可使用鼠标滚轮更改。

[外观设置](./settings.md#appearance-theme)支持深色、浅色、跟随系统、七种配色预设及自定义颜色。[快捷键设置](./shortcuts.md#visual-key-config)可通过键盘和鼠标示意图查看绑定。

## 搜索命令 {#command-search}

使用窗口顶部的搜索框，可以按名称查找保存、导入、偏好设置和面板显示切换等命令。点击候选项即可执行；按 Enter 会执行第一个候选项。按 Esc 或点击框外可关闭结果。如果看不到搜索框，请加宽窗口。查找素材时，请使用资产浏览器内的搜索框。

## 使用饼状菜单切换工具与图层 {#pie-menu}

从 Ver.0.1.1 起，可在 3D 视口或 UV 画布中，在光标周围打开饼状菜单。

1. 在 3D 视口或 UV 画布上按下鼠标右键。
2. 按住右键，向需要的项目滑动。
3. 松开右键即可选中该项目。按 Esc 取消；未滑动就松开时，也会关闭菜单而不选择任何项目。

可以在工作位置附近切换笔刷绘画、颜色混合、UV 壳填充等工具。已有的右键操作（例如相机控制和笔刷大小调整）在按下对应组合键时优先执行。键盘和鼠标操作请参阅[快捷键参考](./shortcuts.md)。

饼状菜单的呼出方式是固定操作。如果无法打开，请松开 Ctrl、Shift、Alt 等修饰键，结束绘制或文字输入后再试。

在 Ver.0.1.2 中，按住右键滑向图层项目，即可进入缩略图列表。在卡片上松开可选择图层，也可用卡片旁的控件切换显示、锁定等设置。请参阅[图层选择与设置](./layers.md#layer-pie-menu)。

## 纹理集与网格部件

HarmoFlow 的纹理集以网格部件为单位。即使使用相同材质，不同部件仍会作为独立的纹理集处理。

普通笔刷和印章会画在当前选中的已有图层所属的纹理集中。如需绘制其他部件，请从图层面板顶部的列表切换纹理集，或对模型按 Shift+Alt+右键单击。从资产浏览器开始绘制新的材质时，内容会记录到当前选中的纹理集中。在已有图层上继续绘制时，以该图层所属的纹理集为目标。使用同一材质的部件会共享最终纹理，因此UV重叠位置的变化也可能显示在其他部件上。

## 打开面板与恢复布局

已关闭的面板可通过“窗口”菜单重新显示。如需恢复布局，请使用“重置布局”。将光标停留在各个项目上，可查看补充操作说明。

## 将面板分离为独立窗口 {#detached-panels}

Ver.0.3.0 中，可以将面板标签拖到应用窗口外，成为独立窗口。移到其他显示器时，面板、文字和控件会按该显示器的 DPI 调整大小。也可以将标签重新停靠到原来的布局中。
