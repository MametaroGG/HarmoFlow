# 安装与管理插件 {#plugins}

插件可以为 HarmoFlow 添加操作面板和图像滤镜。本页介绍**如何使用获得的插件文件**。如果想自己制作，请参阅[制作插件](./plugin-development.md)；如需使用开箱即用的色彩校正、色调曲线和渐变映射，请参阅[内置调整功能](./adjustments.md)。

<GuideFlow kind="plugin-install" />

## 首先确认文件类型 {#plugin-types}

| 类型 | 添加或运行的位置 | 主要用途 |
| --- | --- | --- |
| Lua 扩展（`.lua`） | 插件 → 添加／浏览插件... | 注册带有滑块和按钮的面板，集中执行图层操作 |
| DLL 插件（`.dll`） | 同一个添加界面 | 使用原生代码注册图像滤镜等功能。需要 Windows x64 版本 |
| 普通 Lua 脚本（`.lua`） | 窗口 → 脚本 (Lua) → 运行／运行文件... | 执行一次 `hf` API 操作，与注册面板是不同的功能 |

**即使扩展名同为 `.lua`，普通脚本和用于插件的扩展也不相同。** 作为插件添加的 Lua 文件需要使用 `hf.register_panel` 注册面板。将普通脚本交给添加界面，并不会生成预期的插件面板。

::: warning 添加之前
请保存正在编辑的场景，并确认文件来源和支持的 HarmoFlow 版本。DLL 是与应用在同一进程中运行的原生代码。Lua 扩展虽然也有一些限制，但并不处于能够保证安全的隔离环境中。请只使用可信作者提供的文件。
:::

## 从添加到启动 {#install-plugin}

1. 打开顶部的“插件 → 添加／浏览插件...”。
2. 点击“添加插件...”，选择获得的 `.lua` 或 `.dll` 文件。
3. 文件会被复制到应用的存储位置，并开始加载。Lua 扩展会在绘画及其他正在进行的操作结束后注册。即使已显示添加成功，也请在 Lua 扩展列表中确认注册结果。
4. 再次打开顶部的“插件”菜单，选择已注册的项目。**添加与浏览界面用于管理，启动插件则通过插件菜单进行。**
5. 在小型测试场景中确认处理结果。如果扩展会添加图层，也请检查图层列表中是否生成了预期内容。

添加的文件会在下次启动时成为加载对象。如果启动菜单中没有对应项目，请参阅[无法正常加载时](#plugin-troubleshooting)。

当前实现启动时只会按文件名顺序尝试加载前16个Lua文件。运行期间最多可加载32个扩展，但如果希望重启后全部自动加载，请将 `extensions/` 目录下的 `.lua` 文件控制在16个以内。

## 文件保存在哪里？ {#plugin-folders}

通过应用添加时，文件会保存在 **HarmoFlow 可执行文件所在目录**下的以下文件夹中，不应放在项目文件夹中。

```text
HarmoFlow 可执行文件所在的文件夹/
├─ extensions/
│  └─ my_panel.lua
└─ plugins/
   └─ my_filter.dll
```

手动放置时也使用相同位置。启动时只会查找各文件夹**直接包含**的文件。请解压 ZIP，不要将文件放入更深层的子文件夹，并使用小写的 `.lua`／`.dll` 扩展名。通过添加界面复制时，扩展名会统一转换为小写。

添加界面不提供覆盖同名文件的操作。如果已经存在同名文件，请使用下面的更新步骤。

## 更新或删除 {#update-plugin}

1. 保存场景并退出 HarmoFlow。
2. 找到目标文件：Lua 扩展位于 `extensions/`，DLL 位于 `plugins/`。
3. 如需更新，先将旧文件备份到其他位置，再替换为新文件。如不再使用，将文件移出对应文件夹。
4. 重新启动 HarmoFlow，确认列表中的加载状态和菜单项目。

应用没有在运行中重新加载、卸载或删除插件的专用操作。再次加载同一个 DLL，或将具有相同面板 ID 的 Lua 扩展改名后重新添加，都不能实现更新。如果将备份以 `.dll`／`.lua` 扩展名留在同一文件夹中，启动时也会尝试加载，因此请将备份保存在其他位置。

## 无法正常加载时 {#plugin-troubleshooting}

| 现象或提示 | 检查事项 |
| --- | --- |
| 已存在同名文件／无法添加 | 同名文件不会被覆盖。请退出应用，确认旧文件后再替换 |
| 添加 Lua 后菜单中没有项目 | 查看列表中的 Lua 加载结果，确认文件不是普通脚本，而是通过 `hf.register_panel` 注册面板的扩展 |
| 重启后缺少部分 Lua 扩展 | 启动时只尝试按文件名顺序加载前16个文件，无效文件也计入数量。请检查 `extensions/` 目录下的 `.lua` 文件数量 |
| Lua 面板 ID 重复 | 检查 `extensions/` 中是否还留有同一扩展的旧版或副本 |
| `Could not load DLL` | 对照作者的说明，确认文件面向 Windows x64，且所需的运行时库和依赖 DLL 齐全 |
| `DLL exports no hf_plugin_init` | 未找到 HarmoFlow 所需的入口点。可能是用于其他应用的 DLL，或构建配置有误 |
| `Plugin init failed or wrong API version` | 确认插件支持的版本，并将加载结果告知作者 |
| `Already loaded` | 同一个 DLL 无法重新加载。更新时请退出应用，替换文件后重新启动 |
| 找不到手动放置的文件 | 确认文件直接位于应用旁的正确文件夹内、扩展名为小写，且已从 ZIP 中解压 |

在从其他网站寻找并添加来源不明的 DLL 之前，请先确认发布方列出的要求。报告问题时，请附上 HarmoFlow 和插件的版本、文件名、显示的错误，以及添加时的操作步骤，以便定位原因。
