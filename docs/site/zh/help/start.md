# 开始使用 {#start}

<GuideFlow kind="first-paint" />

## 从导入模型到保存

1. **导入模型**

   可从文件菜单导入模型，也可从资源管理器将模型文件拖放到窗口中。主页也支持拖放，导入完成后会进入工作区。支持 FBX、OBJ、glTF / GLB、DAE、PLY、STL、3DS、BLEND。

   一次拖入多个模型或图片时，会打开第一个受支持的模型，其余文件导入 Project。导入期间收到的拖放会在当前处理结束后执行。

2. **选择要编辑的部件**

   通道、UV 编辑器和纹理集设置中的选择会相互联动。在视口中对模型按 Shift+Alt+右键单击，可切换到该位置的部件。如果模型只有一个部件，切换功能将不可用。

3. **用图层编辑**

   在绘画图层上绘制，用填充图层叠加颜色和材质效果。先保存工作，再通过导出面板输出图片。


::: tip 自动烘焙
导入模型时会自动烘焙网格贴图。即使在完成前设置了做旧效果，贴图生成后也会应用。
:::

<GuideMedia name="first-stroke" />

## glTF / GLB 图片与材质绑定

导入 glTF / GLB 时，会将支持的引用图片导入 Project，并自动绑定到 BaseColor、Normal、Metallic、Roughness、Emission。打包的 MetallicRoughness 图片会拆分为 Roughness 和 Metallic，同时应用支持的颜色和强度值。

保存项目时，也会保存外部几何数据和引用图片，因此保存后的项目可脱离原文件夹重新打开。替换图片时，请使用通道面板中的“手动关联纹理”。这些导入材质的绑定与图层的图片 Fill 是不同设置。

### 导入警告与限制

无法读取的图片会在控制台中产生警告，其他能够加载且受支持的图片仍会应用。若缺少几何缓冲区等模型必需文件，整个模型导入可能失败。

成功导入的 AO 图片会保存在 Project 中，但尚不支持用于显示或应用导入 AO 的专用通道。这与自动烘焙的 AO 网格贴图是两回事。

图片自动绑定以 UV0 为目标。引用其他 UV 集，或带有 KHR_texture_transform 等纹理坐标扩展的图片，不会自动绑定，并会记录警告。跳过的是引用图片；材质的颜色或标量回退值仍可能生成。
