# 开始使用 {#start}

## 安装HarmoFlow {#app-install}

<GuideFlow kind="app-install" />

1. 从[BOOTH商品页面](https://mametarovv.booth.pm/items/8754692)下载正式版或试用版安装程序。**Ver.0.1.2以ZIP提供。下载并解压所选版本类型的ZIP，再运行其中的安装EXE。** 文件名中的 `full` 表示正式版，`trial` 表示试用版。
2. 双击安装EXE。安装向导可选择日语、英语、简体中文或韩语。阅读显示的许可协议，只有同意时才继续。购买前也可查看正式版的[使用许可协议](../terms.md)。
3. 选择安装位置，并按需创建桌面快捷方式。正式版还可选择关联 `.harmos` / `.harmopackage` 文件，试用版不会更改文件关联。
4. 从完成界面启动，或在开始菜单中打开 **HarmoFlow**（试用版为 **HarmoFlow Trial**）。请保持安装文件的完整结构，不要只把应用EXE移动到其他位置。

::: warning 如果无法启动
请检查[系统要求](../download.md#requirements-title)和[启动问题排查](./troubleshooting.md#startup-checks)。不要在未理解警告或未核实下载来源时关闭Windows的安全保护。
:::

## 首次启动时的检查 {#first-launch}

- 从主页新建项目，或导入带有UV的受支持模型。建议先用小型测试模型确认绘制和保存是否正常。
- 在“窗口 → 语言”中切换界面语言。如找不到面板，可使用“窗口 → 重置布局”。
- 正式版与试用版分别安装，设置和材质缓存也各自独立。**试用版支持编辑与保存项目，但不支持纹理导出。** 试用版保存的项目可在正式版中打开。
- 材质目录包含在应用中，需要下载的图像材质在首次使用时需要联网。在离线工作前，请查看[材质下载与离线使用](./materials.md#material-downloads)。

## 自动更新通知 {#automatic-update-notifications}

从 Ver.0.1.1 起，应用会在启动时于后台检查新版本。发现更新后，窗口顶部搜索框右侧会显示蓝色下载图标。点击图标可查看当前版本、新版本和“What's new”（本次变更内容）。

- **Get update**：在浏览器中打开获取更新的页面。自动进行的是检查与通知；安装程序需要自行下载并运行。请先按照下面的步骤做好备份。
- **稍后**：关闭对话框。通知图标会保留，可在本次运行期间再次打开。
- **Skip this update**：隐藏该版本的通知，重新启动后也不再显示。后续的新版本仍可触发通知。

离线或检查失败时不会显示通知。没有图标并不一定意味着已是最新版。需要再次检查时，请确认网络连接并重新启动 HarmoFlow，或直接查看 [BOOTH 商品页面](https://mametarovv.booth.pm/items/8754692)。[更新信息页面](../updates.md)也提供变更内容和介绍视频。

## 更新前备份 {#update-backup}

<GuideFlow kind="update-backup" />

::: warning Ver.0.1.2的3D路径与旧版兼容性
包含新3D路径的场景无法在Ver.0.1.1及更早版本中打开。如果还需要在旧版中使用，请单独保留修改前的文件。另请参阅[3D路径兼容性](./paths.md#path-uv-island-boundaries)。
:::

1. 正常保存当前场景并退出应用。**将整个项目文件夹复制到另一个位置。** 保留其中导入的模型和图像，而不只是复制 `.harmos` 文件。需要携带项目时，也可[导出项目包](./projects.md)。
2. 自行添加的笔刷和插件也应保留原始下载文件或单独备份。新版本保存的场景不一定能在旧版本中打开，因此请勿覆盖更新前的副本。
3. 从BOOTH下载<strong>同一版本类型（正式版／试用版）</strong>的新版本ZIP并解压。运行其中的安装EXE，选择现有安装位置。同一类型的安装程序会更新现有安装。
4. 启动后确认版本号。先用备份制作的测试副本检查模型、图像、图层、保存和重新打开；正式版还应测试所需的导出功能。

### 查看最新版本

请在[BOOTH商品页面](https://mametarovv.booth.pm/items/8754692)查看最新版本和下载文件。更新前先保存工作并备份项目。下载与当前所用类型（正式版／试用版）对应的新版本安装程序，然后按照上面的更新步骤操作。

## 查看版本与更新记录 {#version-changelog}

在“**帮助 → 关于HarmoFlow**”顶部查看应用版本。同一窗口的“**更新记录**”选项卡列出应用内附带的变更信息。标题栏方括号中的数字是构建时间。联系客服时，请一起记录正式版／试用版、版本号和构建时间。

购买条件请查看[购买前常见问题](../download.md#purchase-faq)，使用中的问题请查看[故障排查](./troubleshooting.md)。

## 从导入模型到保存

1. **导入模型**

   可从文件菜单导入模型，也可从资源管理器将模型文件拖放到窗口中。主页也支持拖放，导入完成后会进入工作区。支持 FBX、OBJ、glTF / GLB、DAE、PLY、STL、3DS、BLEND。

   一次拖入多个模型或图片时，会打开第一个受支持的模型，其余文件导入项目资源库。导入期间收到的拖放会在当前处理结束后执行。

2. **选择要编辑的部件**

   通道、UV 编辑器和纹理集设置中的选择会相互联动。在视口中对模型按 Shift+Alt+右键单击，可切换到该位置的部件。如果模型只有一个部件，切换功能将不可用。

3. **选择图层和工具进行绘制**

   选择绘画图层，按 B 切换到绘画工具，然后在模型表面拖动。

4. **保存场景**

   按 Ctrl+S 保存工作，以便稍后继续编辑图层和笔画。

5. **导出纹理**

   在导出面板中选择输出位置、格式和通道，再导出图片。


::: tip 自动烘焙
导入模型时会自动烘焙网格贴图。即使在完成前设置了做旧效果，贴图生成后也会应用。
:::

## glTF / GLB 图片与材质绑定

导入 glTF / GLB 时，会将支持的引用图片导入项目资源库，并自动绑定到 BaseColor、Normal、Metallic、Roughness、Emission。打包的 MetallicRoughness 图片会拆分为 Roughness 和 Metallic，同时应用支持的颜色和强度值。

保存项目时，也会保存外部几何数据和引用图片，因此保存后的项目可脱离原文件夹重新打开。替换图片时，请使用通道面板中的“手动绑定纹理”。这些导入材质的绑定与图层的图片 Fill 是不同设置。

### 导入警告与限制

无法读取的图片会在控制台中产生警告，其他能够加载且受支持的图片仍会应用。若缺少几何缓冲区等模型必需文件，整个模型导入可能失败。

成功导入的 AO 图片会保存在项目资源库中，但尚不支持用于显示或应用导入 AO 的专用通道。这与自动烘焙的 AO 网格贴图是两回事。

图片自动绑定以 UV0 为目标。引用其他 UV 集，或带有 KHR_texture_transform 等纹理坐标扩展的图片，不会自动绑定，并会记录警告。跳过的是引用图片；材质的颜色或标量回退值仍可能生成。


### 外部文件与导入限制 {#model-import-limits}

- 拖放文件夹时，只会导入其直接包含的文件，不会自动遍历子文件夹。
- glTF/GLB导入不会从互联网URL自动下载所引用的图片或几何数据。导入前，请在本地准备好所需的外部文件。
- BLEND能否导入取决于文件中的数据结构。如果导入失败，请查看控制台，并尝试从Blender导出为FBX或glTF/GLB后再导入。
