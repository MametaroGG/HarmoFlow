# 偏好设置、历史与扩展 {#settings}

<span id="启动与绘画手感的基本设置"></span>


## 选择外观与配色 {#appearance-theme}

Ver.0.2.0 提供深色、浅色和跟随系统三种外观，以及七种配色预设和自定义颜色。主页、加载画面、饼状菜单、视口和 UV 编辑器都会跟随所选配色。

Ver.0.3.0 的初始主题为“跟随系统”，根据 Windows 的深浅色设置显示。已有保存的外观设置优先。

UI 会根据高 DPI 显示器的缩放比例调整，改善高分辨率屏幕上文字和按钮过小的问题。下拉选项也可以使用鼠标滚轮更改。
## 首页与最近使用的场景

在首页左侧可以新建或选择项目、打开场景，也可从右侧的“最近使用的场景”继续工作。最多保留最近 20 条成功打开或保存的记录。可以按名称或路径搜索，通过每行的菜单仅移除历史记录，不会删除文件本身。点击右上角的“进入工作区”可返回编辑，通过“文件 → 首页”返回首页。关闭“启动时显示首页”后，下次会直接进入工作区。

最近使用的场景每行均有“打开”“打开文件位置”“复制路径”“从最近使用的文件中移除”操作。找不到文件时无法打开。切换项目文件夹不会关闭当前正在编辑的场景。

可在“窗口 → 语言”或“偏好设置 → 常规 → 语言”更改显示语言，选择会保留到下次启动。用户自己设置的材质名称和图层名称不会被翻译。

## 调整防抖

启用防抖的笔刷在斜着观察表面时，会适当增强防抖，以免屏幕上的轻微抖动在模型表面被放大。因此，在轮廓附近的跟随速度会比正面略慢。笔刷印迹按表面上的距离排列；如果观察角度过于倾斜，将正在绘制的面转向正面，可进一步提高稳定性。

在“绘画手感”中启用“随速度调整防抖”后，缓慢绘制时会抑制抖动，移动越快，跟随速度也越快。通过“速度响应”可调整变化幅度。防抖量为 0 的笔刷不受此设置影响。新笔刷的默认防抖量为 0.15，已有保存笔刷的防抖量保持不变。

## 调整笔压

Ver.0.3.0 为画笔、橡皮擦、混色和模糊添加了“Automatic pressure flow”（根据笔压自动调整流量）和抗锯齿（无、弱、中、强）。较轻的笔压会减弱涂色、擦除或混合效果，抗锯齿用于选择笔尖边缘的平滑程度。它们与笔压控制大小和不透明度是不同的设置。设置随笔画保存，也可保存到画笔和橡皮擦预设。重现新笔画需要 Ver.0.3.0 或更高版本。

“笔压控制大小”会根据笔压改变粗细，“笔压控制不透明度”会根据笔压改变浓淡。需要均匀浓度时，请同时检查笔压控制不透明度和 Automatic pressure flow。现有场景中的笔画会按照保存时的设置重新绘制。

请先加载模型；如果仍在加载或编辑路径，请先完成当前操作。可通过“偏好设置 → 绘画手感 → 通过试画校准”校准笔压。在视口中的模型上用笔以不同力度试画几条线，然后点击“自动调整并预览”。在确认界面重新试画，通过“更软”“更硬”微调，最后点击“完成”保存。点击“取消”则不做更改。鼠标输入不会用于自动调整；如果笔压变化或样本不足，会提示继续试画。试画不会画入场景。

试画只显示最新的一笔，开始下一笔时会清除上一笔。可清除试画预览，也可在确认页面选择重新试画，从头进行校准。

<GuideMedia name="calibrate-pressure" />

要调整笔压曲线或最小笔压，请在“偏好设置 → 绘画手感”中展开“高级笔压设置”。笔压曲线的“软”会让较小的力度也能画出粗线，“硬”则需要较大的力度才会变粗。最小笔压决定轻触时的下限，笔压平滑度决定变化的平缓程度。提高平滑度会带来跟随延迟。图表显示输入与输出的关系，监视器显示当前校正后的笔压。这些笔压设置会自动保存，并应用于所有笔刷，对鼠标不生效。

开启“使用校准曲线”时，“笔压曲线”和“最小笔压”不可调节。需要手动调整这两项时，请先关闭“使用校准曲线”。

同一界面中也可调整当前笔刷的笔压大小、防抖和绘制间距。每个笔刷的设置请保存到笔刷预设中，以便切换使用。

## 使用笔的侧键

笔的侧键可作为数位板驱动程序中分配的鼠标点击使用。单独按下设为“右键单击”的侧键不会旋转相机，与 Alt 配合时可缩放。按住右键时，即使笔尖接触数位板也不会绘制。松开侧键时，如果笔尖仍接触数位板，必须先将笔抬起，之后才会恢复绘制。即使笔尖比侧键稍早接触数位板，也会按右键单击处理，并撤销刚开始绘制的线条。按住 Shift+Alt 期间，笔尖接触数位板也不会绘制。设为“左键单击”或“中键单击”的侧键也可像鼠标按键一样使用。使用侧键的左键单击绘制时，由于没有笔压，会以与鼠标相同的力度绘制。

在 Ver.0.1.2 的[图层饼状菜单](./layers.md#layer-pie-menu)中，数位板也可以通过将指针停在列表上方或下方来浏览图层，移回中央即可停止。用笔尖轻点卡片也可选择图层。3D 视口和 UV 编辑器均支持此操作。

## 切换文件选择界面

选择文件或文件夹时，默认使用操作系统的对话框。启用“偏好设置 → 常规 → 使用内置文件浏览器”后，会切换到内置浏览器，此设置在下次启动时仍会保留。此设置适用于打开模型、场景等文件选择流程。添加插件和运行Lua文件仍使用操作系统的对话框。新建项目时，请在标准对话框中创建并选择项目文件夹。

## 界面布局与历史记录

通过“窗口”菜单显示各个面板，并通过停靠调整布局。可将面板收纳到面板栏中，通过图标打开。加宽面板栏后会显示标签，也可重新排序、分组或将面板移出栏。需要恢复布局时，请使用“重置布局”。

按 Ctrl+Z / Ctrl+Y 可撤销或重做编辑，在“历史记录”中可查看操作。Undo 并不能撤销所有设置或外部文件操作。“控制台”用于查看处理结果和错误。操作说明请参阅本官方文档。界面语言可在日语、英语、中文和韩语之间切换。

### 撤销工具设置

笔刷、橡皮擦、混色／模糊、印章和路径的工具设置均支持撤销／重做。连续拖动滑块或数值框会合并为一次撤销操作。即使已经切换工具，撤销仍会作用于之前修改的设置。

恢复笔刷或印章设置后，变化会体现在下一笔。并非所有设置或外部文件操作都能撤销。

### 将面板分离为独立窗口 {#settings-detached-panels}

Ver.0.3.0 中，可以将面板标签拖到应用窗口外，成为独立窗口。移到其他显示器时，面板、文字和控件会按该显示器的 DPI 调整大小。也可以将标签重新停靠到原来的布局中。

### 使用面板栏 {#panel-rail-operations}

将面板标题栏拖到面板栏上，可将其收起为图标。点击图标打开，再次点击关闭。打开另一个面板栏图标时，会关闭此前从面板栏打开的面板。将已打开面板的标题拖离面板栏，可按普通面板放置。右键点击图标并选择“从面板栏移除”，可移除该图标。面板栏顶部的箭头可切换仅图标或图标加名称的显示方式。

### 在历史记录中前后移动 {#history-navigation}

在“窗口 → 历史记录”中，点击一行即可恢复到该操作完成后的状态。“Latest state”（最新状态）会执行所有保留的重做步骤。加载或绘制等操作进行中，无法跳转历史状态。撤销后进行新的编辑，会替换后续的重做历史。

在“偏好设置 → 常规 → Maximum history (0 = unlimited)”中，可设置撤销和重做合计保留的条目数。默认是100条，0表示不限。更改后点击“保存”应用设置。超过上限时，先移除最早的撤销记录，必要时再移除最远的重做记录；移除后无法恢复。连续拖动滑块等合并操作计为一条记录。

### 查看FPS与帧时间 {#performance-panel}

“窗口 → FPS / Frame time”显示FPS、平均/P95/最大帧时间、超过50ms的帧数和曲线。统计基于最近240帧的实际耗时，包含帧率限制和空闲等待，并非只测量GPU渲染时间。比较某项操作前，可点击“Reset measurements”（重置测量）。面板还会显示实验性纹理流式处理是否为ON或OFF。

## VRAM 与显示质量

在“偏好设置 → VRAM”中，可以从预设开始调整。如果运行较慢，请先降低预览分辨率，必要时再降低工作分辨率。

### 预设与预览分辨率 {#vram-presets}

Ver.0.3.0 中，如果尚未保存显存设置，HarmoFlow 会根据 GPU 显存容量和电脑内存容量，自动选择“最高质量”“均衡”或“低显存”。用户保存设置优先。选择依据是容量，而不是实时变化的可用内存。

“均衡”使用完整分辨率的视口预览和半分辨率的 UI 面板预览，保留编辑数据与导出质量。

同时减少了 UV 壳外工作图像，以及历史记录和导出时的临时内存占用。UV 外的节省效果取决于 GPU 支持情况和 UV 布局，编辑数据和导出质量保持不变。

“最高质量”使用完整分辨率预览；“低显存”使用四分之一分辨率预览、BC7显示压缩等设置。单独修改设置后会切换为“自定义”。选择“最高质量”“均衡”或“低显存”会关闭实验性功能。仅选择“自定义”不会改变当前设置。

“一半”“四分之一”指预览图像的宽和高。打开UV编辑器时，UI预览分辨率会根据画布大小自动调整。导出分辨率不会因此改变。

修改VRAM选项后，请点击“偏好设置”窗口底部的“保存”。只关闭窗口不会应用这些更改。网格UV外部像素的存储模式更改会在下次加载模型或更改分辨率时生效。

| 设置组 | 内容 |
| --- | --- |
| 纹理 | 网格 UV 外部区域的处理、BC7 显示压缩、通道延迟加载及目标通道 |
| 烘焙中间缓冲区 | 快照、实时临时缓冲区和图层检查点的延迟分配与最大数量 |
| 导入 / GPU 准备 | 高速 GPU 路径与 GPU 分配批次 |
| 预览 | 以全分辨率、1/2 或 1/4 分辨率显示视口和 UI 面板 |
| 内存基础设施 | 暂存池、内存块容量和空闲时复用 |
| 预算 | VRAM 预算与超限警告。0 表示不限制预算 |
| 实验性功能 | 神经纹理压缩、虚拟纹理缓存，以及非编辑中纹理集的内存优化。详见下文 |

如果需要将绘制本身限制在UV岛内的像素，请使用笔刷面板中的[“移除UV边缘扩展（严格）”](./brush.md#strict-uv-padding)。它与网格UV外部区域的存储和导出设置不同。

### 显存预算的作用 {#vram-budget}

VRAM预算用于警告和部分缓存调整，并不会禁止所有超过指定数值的内存分配。使用量进度条是估计值，可能包含其他应用使用的显存。设为0表示不设置预算。

### 显示图像压缩 {#display-compression}

BC7仅压缩视口显示副本。“未选中集使用 BC7”保留选中纹理集的常规预览；“所有集使用 BC7”也包括选中的纹理集。编辑图像和导出数据不会被压缩。常规BC7显示副本为256〜512px；完整分辨率的虚拟纹理缓存使用不同的处理方式。

“神经纹理压缩（视口）”是实验性功能，默认关闭。它通过较小的数据表示重建显示图像，因此细节和颜色可能与原图不同。预览为256〜512px，编辑和导出图像保持不变。“潜在表示缩减倍数”默认为4，最小为2。当完整分辨率虚拟纹理缓存或非编辑纹理集的省内存功能优先时，不使用此模式。

### 虚拟纹理缓存

虚拟纹理缓存将未选中的纹理集无损压缩后暂存到磁盘，并在选中时恢复。支持全分辨率显示。全分辨率下，未选中的纹理集使用 BC7 显示副本，因此显示颜色可能略有差异；编辑和导出数据仍然无损。

当前选中的纹理集优先于页面预算。GPU 驻留以纹理集为单位管理，不是按可见瓦片进行流式加载。

### 非编辑中纹理集的内存优化

Ver.0.3.0 自动选择的预设会关闭“Reduce memory for non-edited texture sets”和虚拟纹理缓存。用户保存的设置优先，实际运行取决于GPU支持情况和编辑状态。启用后，在支持的 GPU 上，选中和正在编辑的纹理集保持原分辨率。至少三秒没有操作后，其他纹理集会无损移出内存，并以 1/4 分辨率显示。

当前活动图层以全部纹理集为目标时，所有纹理集都会保留在内存中。只有一个纹理集的场景不会减少通道内存。此模式优先于 BC7、NTC 和旧版虚拟纹理缓存；切换纹理集时可能需要等待恢复。

自动保存请参阅[保存与恢复](/zh/guide#projects)。“常规”中可设置包的解压位置。在“按键配置”中，可按操作名称或快捷键搜索，并修改键盘和鼠标绑定。

## Lua 与插件

“脚本 (Lua)”可执行输入的代码或 Lua 文件，以及查看和清除日志。`hf` API 提供添加和编辑图层、蒙版、图片填充、材质预设、笔刷、模型导入、场景保存、打包和纹理导出等操作。图层编号从 1 开始。

```lua
hf.log('Layers: ' .. hf.layer_count())
hf.add_layer('paint', 'Practice layer')
```

从顶部“插件”菜单启动插件。普通Lua脚本与注册面板的Lua扩展使用不同的执行方式。请按目的阅读详细指南。

- [安装与管理插件](./plugins.md)：添加、保存位置、启动、更新与排错
- [制作插件](./plugin-development.md)：Lua最小示例、官方SDK下载、DLL构建与测试
- [内置调整功能](./adjustments.md)：色调校正、色调曲线与渐变映射


### 脚本执行与撤销 {#lua-execution-undo}

普通Lua脚本会等待正在进行的绘制或其他处理结束后再执行。Lua指令有约2秒的执行时限，但不一定能中断已经调用的所有处理。请将长任务拆分为较小步骤，并查看输出日志中的错误。普通脚本与扩展动作不同，不会自动将整个脚本合并为一次撤销，也不会在出错时整体回滚。运行前请保存场景。
