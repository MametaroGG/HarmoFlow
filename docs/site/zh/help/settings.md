# 首选项、历史与扩展 {#settings}

## 启动与绘画手感的基本设置

在首页左侧可以新建或选择项目、打开场景，也可从右侧的“最近使用的场景”继续工作。最多保留最近 20 条成功打开或保存的记录。可以按名称或路径搜索，通过每行的菜单仅移除历史记录，不会删除文件本身。点击右上角的“进入工作界面”可返回编辑。

启用防抖的笔刷在斜着观察表面时，会适当增强防抖，以免屏幕上的轻微抖动在模型表面被放大。因此，在轮廓附近的跟随速度会比正面略慢。笔刷印迹按表面上的距离排列；如果观察角度过于倾斜，将正在绘制的面转向正面，可进一步提高稳定性。

在“绘画手感”中启用“根据速度调整防抖”后，缓慢绘制时会抑制抖动，移动越快，跟随速度也越快。通过“速度跟随”可调整变化幅度。防抖量为 0 的笔刷不受此设置影响。新笔刷的默认防抖量为 0.15，已有保存笔刷的防抖量保持不变。

“笔压控制大小”会根据笔压改变粗细，“笔压控制浓度”会根据笔压改变浓淡。绘制均匀的墨线时，请关闭笔压对浓度的影响。现有场景中的笔画会按照保存时的设置重新绘制。

可通过“首选项 → 绘画手感 → 试画并调整笔压”校准笔压。用笔以不同力度画几条线，然后点击“自动调整并确认”。在确认界面重新试画，通过“更柔软”“更硬”微调，最后点击“完成”保存。点击“取消”则不做更改。鼠标输入不会用于自动调整；如果笔压变化或样本不足，会提示继续试画。试画不会画入场景。

启动时，可以从首页新建项目、选择项目文件夹或打开场景。点击“进入工作界面”开始编辑，通过“文件 → 首页”返回。关闭“启动时显示首页”后，下次会直接进入工作界面。

在“首选项 → 绘画手感”中可以调整笔压。笔压曲线的“轻触”会让较小的力度也能画出粗线，“用力按压”则需要较大的力度才会变粗。最小笔压决定轻触时的下限，笔压平滑度决定变化的平缓程度。提高平滑度会带来跟随延迟。图表显示输入与输出的关系，监视器显示当前校正后的笔压。这些笔压设置会自动保存，并应用于所有笔刷，对鼠标不生效。

同一界面中也可调整当前笔刷的笔压大小、防抖和绘制间距。每个笔刷的设置请保存到笔刷预设中，以便切换使用。

笔的侧键可作为数位板驱动程序中分配的鼠标点击使用。单独按下设为“右键单击”的侧键不会旋转相机，与 Alt 配合时可缩放。按住右键时，即使笔尖接触数位板也不会绘制。松开侧键时，如果笔尖仍接触数位板，必须先将笔抬起，之后才会恢复绘制。即使笔尖比侧键稍早接触数位板，也会按右键单击处理，并撤销刚开始绘制的线条。按住 Shift+Alt 期间，笔尖接触数位板也不会绘制。设为“左键单击”或“中键单击”的侧键也可像鼠标按键一样使用。使用侧键的左键单击绘制时，由于没有笔压，会以与鼠标相同的力度绘制。

选择文件或文件夹时，默认使用操作系统的对话框。启用“首选项 → 常规 → 使用内置文件浏览器”后，会切换到内置浏览器，此设置在下次启动时仍会保留。新建项目时，请在标准对话框中创建并选择项目文件夹。

## 界面布局与历史记录

通过“窗口”菜单显示各个面板，并通过停靠调整布局。可将面板收纳到面板栏中，通过图标打开。加宽面板栏后会显示标签，也可重新排序、分组或将面板移出栏。需要恢复布局时，请使用“重置布局”。

按 Ctrl+Z / Ctrl+Y 可撤销或重做编辑，在“历史记录”中可查看操作。Undo 并不能撤销所有设置或外部文件操作。“控制台”用于查看处理结果和错误。操作说明请参阅本官方文档。界面语言可在日语、英语、中文和韩语之间切换。

### 撤销工具设置

笔刷、橡皮擦、混色／模糊、印章和路径的工具设置均支持撤销／重做。连续拖动滑块或数值框会合并为一次撤销操作。即使已经切换工具，撤销仍会作用于之前修改的设置。

恢复笔刷或印章设置后，变化会体现在下一笔。并非所有设置或外部文件操作都能撤销。

## VRAM 与显示质量

在“首选项 → VRAM”中，可以从预设开始调整。如果运行较慢，请先降低预览分辨率，必要时再降低工作分辨率。

| 设置组 | 内容 |
| --- | --- |
| 纹理 | 网格 UV 外部区域的处理、BC7 显示压缩、通道延迟加载及目标通道 |
| 烘焙中间缓冲区 | 快照、实时临时缓冲区和图层检查点的延迟分配与最大数量 |
| 导入 / GPU 准备 | 高速 GPU 路径与 GPU 分配批次 |
| 预览 | 以全分辨率、1/2 或 1/4 分辨率显示视口和 UI 面板 |
| 内存基础设施 | 暂存池、内存块容量和空闲时复用 |
| 预算 | VRAM 预算与超限警告。0 表示不限制预算 |
| 实验性功能 | 神经纹理压缩、虚拟纹理缓存，以及非编辑中纹理集的内存优化。详见下文 |

### 虚拟纹理缓存

虚拟纹理缓存将未选中的纹理集无损压缩后暂存到磁盘，并在选中时恢复。支持全分辨率显示。全分辨率下，未选中的纹理集使用 BC7 显示副本，因此显示颜色可能略有差异；编辑和导出数据仍然无损。

当前选中的纹理集优先于页面预算。GPU 驻留以纹理集为单位管理，不是按可见瓦片进行流式加载。

### 非编辑中纹理集的内存优化

“Reduce memory for non-edited texture sets”默认关闭。在支持的 GPU 上，选中和正在编辑的纹理集保持原分辨率。至少三秒没有操作后，其他纹理集会无损移出内存，并以 1/4 分辨率显示。

存在全局图层时，会保留所有纹理集。只有一个纹理集的场景不会减少通道内存。此模式优先于 BC7、NTC 和旧版虚拟纹理缓存；切换纹理集时可能需要等待恢复。

自动保存请参阅[保存与恢复](/zh/guide#projects)。“常规”中可设置包的解压位置。在“按键配置”中，可按操作名称或条件搜索，并修改键盘和鼠标绑定。

## Lua 与插件

“脚本 (Lua)”可执行输入的代码或 Lua 文件，以及查看和清除日志。`hf` API 提供添加和编辑图层、蒙版、图片填充、材质预设、笔刷、模型导入、场景保存、打包和纹理导出等操作。图层编号从 1 开始。

```lua
hf.log('レイヤー数: ' .. hf.layer_count())
hf.add_layer('paint', '描き込み')
```

从顶部“插件(P)”菜单启动插件。“添加／浏览插件...”可添加 .lua 或 .dll 文件，并查看加载状态。添加的文件在下次启动时仍可使用。也可将 DLL 文件直接放入可执行文件旁的 plugins 文件夹。

请仅添加来自可信来源的插件。DLL 插件使用 C ABI SDK，位于 `sdk/harmoflow_api.h`；开发示例位于 `examples/sample_plugin/`。
