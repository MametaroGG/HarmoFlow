# 视口、网格与显示 {#viewport}

## 移动相机

默认使用 Alt+左键拖动旋转，使用中键拖动或 Space+左键拖动平移。滚轮、Alt+右键拖动和 Ctrl+左键拖动均可缩放；向右或向上拖动会放大。“枢轴 360”模式不支持平移。如果修改过按键配置，请以当前绑定为准。

点击“正面”可返回正视图。“自由旋转”允许通过平移改变旋转中心。使用“截图”或按 F12 可将视口保存为 PNG。

视口顶部的“聚焦图层”可将相机移近所选图层的绘制范围。绘画图层以笔画为基准，路径图层以形状为基准，材质图层则以目标网格的范围为基准。聚焦时选择其他图层，相机会跟随到该图层；点击“全部”可显示整个模型。空的绘画图层或路径图层无法聚焦。

## 切换显示方式

显示菜单包含 PBR、NPR、六种通道的单独显示和图层蒙版。根据需要选择通道，例如用 BaseColor 检查颜色，用 Roughness 检查粗糙度分布。PBR 用于检查包含光线反射的材质质感，NPR 用于检查卡通风格效果。此预览不保证与外部着色器完全一致。

“着色设置”可调整光源的方位、高度、强度和颜色，以及环境光的强度、饱和度和颜色。PBR 可设置高光、曝光、法线强度、基础反射率（F0）和 ACES 色调映射。NPR 可设置亮度下限和上限。如果设置变得混乱，可使用“重置着色设置”还原。

“线框设置”可控制显示开关、背面显示、颜色、不透明度、线宽，以及是否隐藏检测到的伪四边形对角线。此处的设置与 UV 编辑器中的线框设置相互独立。

## 选择与隐藏部件

使用选择工具点击部件，按住 Shift 可添加或取消选择，在空白处拖动可进行框选，按 Esc 可取消选择。可通过工具选项显示或隐藏选中部分。“网格”面板列出部件名称、材质和三角形数量，并提供单独切换可见性，以及“全部显示”“全部隐藏”。

## 查看形态键

对于包含形态键的模型，可在“形态键”面板中将权重调整为 0〜1。支持名称搜索、按网格筛选和仅显示使用中的项目。可通过“全部重置”“仅将已应用项归零”或按组重置来恢复。若模型不含形态键，则没有可操作的对象。
