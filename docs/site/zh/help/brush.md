## 绘制基础

选择绘画图层，按 B 切换到绘画工具，然后在模型上拖动。笔画以表面位置、法线等信息保存，并烘焙到当前 UV 上。启用多个 PBR 通道后，可以用同一笔画同时绘制颜色、粗糙度等内容。

| 设置 | 效果 |
| --- | --- |
| 大小 | 笔画粗细。也可以使用方括号键或 Ctrl+Alt+水平拖动调整 |
| 硬度 | 笔尖边缘的模糊程度。降低后边缘更柔和 |
| 不透明度 | 单次绘制的浓度，与整个图层的不透明度不同 |
| 间距 | 笔尖印迹之间的距离。增大后更容易形成分离的点 |
| 防抖 | 抑制输入轨迹抖动的强度 |
| 笔压控制大小 | 将笔压应用于笔刷大小 |
| 笔尖 | 选择圆形笔尖或导入的图片笔尖 |
| 对称 | 以选定的 X / Y / Z 轴进行对称绘制 |
| 多通道绘制 | 启用需要绘制的通道并设置数值 |

在笔刷面板中，可以按类别选择预设，也可以将调整后的设置保存为预设。使用“导入 PNG 笔刷”可添加自定义笔尖。橡皮擦的大小、笔尖等设置在专用面板中调整。

也可右键单击项目内的图片，选择“Register as Brush Tip”，在笔刷面板中使用。

按 U 或点击手指图标打开“Color blending”。选择绘画图层，然后在 3D 视图或 UV 编辑器中拖动。此工具使用已有颜色，不会加入当前选中的颜色。

- Blur（模糊）：柔化边界
- Color mix（混色）：混合周围颜色
- Fingertip（涂抹）：沿笔画方向拉伸颜色
- Bristle blend（笔触混合）：保留细微纹理

每种笔刷分别保留大小、强度和浓度等设置。按 B 可返回普通绘画。也可用于柔化蒙版和材质的已绘制区域。

## 填充面或 UV 岛

多边形填充会填充点击的面，UV 壳填充会填充该面所属的 UV 岛。请先通过悬停高亮确认目标范围，再点击填充。“应用伪四边形”会将检测到的一对三角形视为一个四边形。

### 用材质绘画

在材质浏览器中选择材质后，可用笔刷将其画到模型上。工具栏中的“多边形填充”和“UV 壳填充”，可将颜色、法线、粗糙度等一并应用到 3D 视图或 UV 编辑器中点击的区域。更换材质不会改变当前绘制方式。

选择已绘制的材质图层或材质文件夹，可以继续添加覆盖范围。橡皮擦会擦除笔刷范围内的材质覆盖。对已有图层进行普通绘画时，目标限于该图层所属的纹理集；从资源库开始绘制新材质时，则以最先触及的部件为目标。

## 吸管与调色板

使用绘画工具时，按住 Ctrl+Shift 可预览模型上合成后的 BaseColor。按住 Ctrl+Shift+左键并移动，松开鼠标即可采用该颜色。如果先于鼠标松开 Ctrl+Shift，则会取消操作。拾取的是 BaseColor，而不是包含光照效果的屏幕颜色。

“调色板”包含颜色调整、近似色、颜色历史和混色器。在混色器上拖动可混合颜色，右键单击或按 Alt 可拾取颜色。“色板”面板用于选择已保存的颜色，不需要的颜色可以通过右键菜单删除。
