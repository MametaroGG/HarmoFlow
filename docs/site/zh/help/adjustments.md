# 颜色调整、色调曲线与渐变映射 {#adjustments}

这三种效果都会调整下方图层的合成结果，并保留原有绘制内容。调整整体亮度和色彩时使用**色调校正**；分别控制暗部、中间调和亮部时使用**Tone Curve（色调曲线）**；根据亮度重新分配颜色时使用**Gradient Map（渐变映射）**。

## 添加和重新编辑 {#add-and-edit}

1. 在图层面板中选择目标纹理集，以及希望叠加调整的位置。
2. 点击半圆形的“New adjustment layer”图标，然后选择“色调校正”“Tone Curve”或“Gradient Map”。
3. 选中新图层，在属性中设置“目标通道”和效果参数。修改颜色时，先选择 BaseColor。
4. 切换图层可见性来比较效果。以后再次选中此图层即可修改参数。移动图层会改变它所影响的下方内容。

目标通道包括 BaseColor、Normal、Roughness、Metallic、Height 和 Emission。一个调整图层只影响所选的一个通道。Roughness、Metallic 和 Height 表示数值分布，调整它们时应关注材质变化，而不是只看颜色。

也可以从[插件](./plugins.md)打开这些效果。选择“目标纹理集”和“目标通道”，查看视口中的实时预览，再点击“应用”以添加可编辑的调整图层。点击“取消”，或在调整窗口获得焦点时按 Esc，可恢复原来的显示。

当前版本的部分控件仍显示英文。下文在操作步骤中保留界面上的实际名称。

## 颜色调整 {#color-adjustment}

无需重新绘制，即可修改整体亮度、色彩鲜艳程度和色相。

| 参数 | 范围／默认值 | 作用 |
| --- | --- | --- |
| 亮度 | −1～1／0 | 整体提亮或变暗 |
| 对比度 | 0～3／1 | 减弱或增强明暗差异 |
| 饱和度 | 0～3／1 | 0为无彩色，1保留原饱和度，更高则更鲜艳 |
| 色相 | −180～180／0 | 旋转色相，改变色彩倾向 |
| 伽马 | 0.1～3／1 | 调整中间调；大于1会提亮，小于1会变暗 |

建议先小幅调整亮度和对比度，再处理饱和度、色相，最后用伽马微调。极端参数可能损失亮部或暗部层次，请对比 BaseColor 单通道与正常材质显示。“Reset adjustment”可恢复默认值。

## 色调曲线 {#tone-curve}

横轴为原始亮度（Input），纵轴为调整后的亮度（输出）。左下对应暗部，右上对应亮部。曲线高于对角线的部分会变亮，低于对角线的部分会变暗。

1. 在“Channel”中选择“RGB (Master)”调整总体明暗；需要单独调整颜色时，选择“Red (R)”“Green (G)”或“Blue (B)”。
2. 点击图表添加控制点，拖动控制点改变曲线。也可用“Input”和“输出”调整所选点。
3. 略微压低暗部并抬高亮部，可增强对比度。效果过强时降低“Strength”：0表示不调整，1表示完整效果。

每条曲线支持2～16个点，包含两个端点。“Input”和“输出”的范围均为0～1。左右端点的输入位置固定，不能删除；中间控制点可以通过“Remove point”移除。

“Curve presets”包括线性、对比度、Soft contrast、Lift shadows、哑光和Darken。预设只应用于当前选择的曲线。RGB整体曲线处理后，还会应用各自的R、G、B曲线。

## 渐变映射 {#gradient-map}

渐变映射读取下方内容的亮度，按从暗到亮的顺序分配颜色。它不是沿视口的左右方向绘制渐变；模型上亮度接近的部分，无论位置在哪里，都会获得相近的配色。

1. 选择渐变条上的色标，通过颜色选择器或 #RRGGBB 设置颜色。
2. 拖动色标或调整“位置”，决定哪种亮度对应此颜色。0%一侧对应暗部，100%一侧对应亮部。
3. 需要中间色时点击“Add color”。例如暗部用藏蓝、中间调用红色、亮部用淡黄色，即可根据原有明暗构成三色配色。
4. 降低“Strength”可保留更多原始颜色。0表示不调整，1表示完整映射。

支持2～16个色标。“Remove”移除所选色标，“Reverse”会将颜色及其位置左右翻转。可以在“Presets”中搜索和选择配色，再修改颜色与位置。色标只能在相邻色标之间移动。

## 保存、导出与效果检查 {#save-and-check}

- 请同时保存 .harmos 场景，以便继续编辑效果参数。三种效果保存后均可重新编辑，参数修改支持撤销／重做。
- 普通图片导出包含合成后的效果。PSD会导出目标通道的栅格图层，不会生成Photoshop原生调整图层。在Photoshop中修改下方图层，也不会自动重新计算此效果。详见[导出](./export.md)。
- 看不到变化时，检查目标纹理集、通道、图层可见性、不透明度和顺序，并确认调整图层下方存在内容，且未被蒙版或剪贴限制。
- 这些效果不会填充原本透明的区域。需要在空白处添加颜色时，请使用[材质或绘画图层](./layers.md)。
