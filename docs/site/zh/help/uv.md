## 在 UV 编辑器中绘制与移动

选择绘画工具和绘画图层，在 UV 编辑器画布上拖动，即可在对应的模型表面绘制。使用滚轮缩放，中键拖动或 Space + 左键拖动进行平移。Shift + Space + 左键或右键拖动可旋转视图。Shift + Space + 左键或右键双击仅重置角度，保留缩放比例和显示位置。“显示全部”会重置旋转、平移和缩放。平移和旋转时会显示专用光标。此编辑器也可用于编辑路径锚点，但不能重新展开 UV 布局本身。

对于文字、形状和图片印章，可在视口上使用 Ctrl + Alt + 拖动调整大小，使用 Shift + Space + 拖动调整角度。两种操作均支持左键和右键。

## 调整线框与背景

通过“UV 线框”切换线条显示，通过“线框设置”调整颜色、不透明度和线宽。默认使用较细的线框。

- **三角形** — 同时显示内部边缘。可隐藏检测到的伪四边形的对角线。
- **UV 壳** — 显示 UV 岛的外轮廓。四边形的岛会只显示外框。
- **显示全部** — 将已缩放或移动的视图恢复为可看到全部内容的状态。

在背景选择中，可以切换 BaseColor 等通道，以及已生成的曲率、AO、法线和位置贴图。
