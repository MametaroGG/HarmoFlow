# Keyboard shortcut reference {#shortcuts}

## Check and change key bindings

A key's function can depend on the active panel or tool. Tool shortcuts may be unavailable while you are editing a text field.

In Preferences → Key Config, search by action name or condition to change keyboard and mouse bindings. Actions with a + button allow an additional binding. Categories include General, Edit, File, Tools, Drawing, Layers, and UV Editor.

Fixed actions cannot be changed. Ordinary left-click and combinations that conflict with actions used at the same time cannot be assigned. The table below shows the default bindings.

## Actions and keys or gestures

| Action | Key or gesture |
| --- | --- |
| Paint / Color blending / Path / Text | B / U / P / T |
| Rotate camera | Alt+left drag |
| Zoom camera | Mouse wheel, Alt+right drag, Ctrl+left drag (right or up to zoom in, left or down to zoom out) |
| Pan camera | Middle drag, Space+left drag |
| Copy / Cut / Paste / Duplicate layer | Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D (when the Layers panel has focus) |
| Delete layer | Delete (when the Layers panel has focus) |
| Open texture set under cursor | Shift+Alt+right-click |
| Pan UV canvas | Middle drag, or Space+left drag |
| Brush size | [ / ], Ctrl+Alt+horizontal drag with either the left or right button |
| Eyedropper | Ctrl+Shift+left mouse button while painting; release to pick |
| Add to / remove from selection | Shift+click with the Selection tool |
| Finish an open path / close / close and fill | Enter / C / F (C and F: viewport hovered while drafting a path) |
| Cancel path drafting / remove the last draft anchor | Esc / Delete or Backspace |
| Undo / Redo | Ctrl+Z / Ctrl+Y |
| Save / Save incrementally | Ctrl+S / Ctrl+Alt+S |
| Preferences | Ctrl+, |
| Capture viewport | F12 |
| Pause engine | Shift+Esc |

Delete or Backspace removes the last anchor while drafting a path. When editing an existing path, it deletes the selected anchor.
