# はじめる {#start}

<GuideFlow kind="first-paint" />

## 最初の1枚を描く

1. **モデルを読み込む**

   ファイルメニューから読み込むか、モデルファイルをウィンドウへドラッグ＆ドロップします。ホーム画面へのドロップにも対応します。

2. **編集するパーツを選ぶ**

   チャンネルパネルで対象を選びます。モデルをShift+Alt+右クリックして、その位置のパーツに切り替えることもできます。パーツが1つの場合、切り替えは無効です。

3. **レイヤーとツールを選んで描く**

   ペイントレイヤーを選び、Bキーでペイントツールに切り替えます。モデルの表面をドラッグして描きます。

4. **シーンを保存する**

   Ctrl+Sで作業を保存します。後からレイヤーやストロークを編集するためのデータです。

5. **テクスチャを書き出す**

   エクスポートパネルで出力先・形式・チャンネルを選び、画像を書き出します。

::: tip 自動ベイク
モデル読み込み時にメッシュマップを自動ベイクします。完了前に汚しを設定しても、生成後に反映されます。
:::

## 読み込めるモデル

FBX、OBJ、glTF／GLB、DAE、PLY、STL、3DS、BLENDに対応しています。テクスチャ制作に使うモデルにはUVを用意してください。

複数のモデルや画像をまとめてドロップした場合は、最初の対応モデルを開き、残りはProjectに取り込みます。ホーム画面では読み込み後に制作画面へ切り替わります。

## glTF／GLBの画像を引き継ぐ

glTF／GLBを読み込むと、対応する参照画像をProjectに取り込み、BaseColor・Normal・Metallic・Roughness・Emissionに自動で紐づけます。MetallicRoughness画像はRoughnessとMetallicへ分離し、対応する色・強度も反映します。外部の形状データと画像も保存対象になるため、プロジェクト保存後は元フォルダーから独立して開けます。差し替えには「手動テクスチャ紐づけ」を使います。これはレイヤーの画像Fillとは別です。

### 自動で引き継げない場合

読み込めない画像はコンソールに警告が出ます。読み込めた対応画像は適用されます。読み込んだAO画像の専用チャンネル表示・適用には未対応で、自動ベイクするAOメッシュマップとは別です。自動紐づけはUV0が対象です。UV0以外の参照やKHR_texture_transformなどのテクスチャ座標拡張を持つ画像は自動紐づけされず、警告が記録されます。形状バッファなど、モデル本体に必要なファイルが欠けている場合は、モデルの読み込み自体が失敗することがあります。
