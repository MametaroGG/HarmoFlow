# はじめる {#start}

## インストールする {#app-install}

<GuideFlow kind="app-install" />

1. [BOOTHの商品ページ](https://mametarovv.booth.pm/items/8754692)で、製品版または体験版のインストーラーをダウンロードします。**配布ファイルは1本のEXEです。ZIPの解凍や分割BINの結合は不要です。** ファイル名の `full` は製品版、`trial` は体験版を表します。
2. ダウンロードしたセットアップEXEをダブルクリックします。日本語・英語・簡体字中国語・韓国語から案内の言語を選び、表示された使用許諾契約を確認して、同意する場合だけ続けます。製品版の[使用許諾契約](../terms.md)は購入前にも確認できます。
3. インストール先と、必要に応じてデスクトップショートカットを選びます。製品版では `.harmos` / `.harmopackage` の関連付けも選択できます。体験版は関連付けを変更しません。
4. 完了画面から起動するか、スタートメニューの **HarmoFlow**（体験版は **HarmoFlow Trial**）を開きます。アプリのEXEだけを別の場所へ移動せず、インストールされた構成のまま使ってください。

::: warning 起動時に止まる場合
[動作環境](../download.md#requirements-title)と[起動できないときの確認](./troubleshooting.md#startup-checks)を参照してください。警告の意味や配布元を確認せずに、Windowsの保護を無効化しないでください。
:::

## 初回起動で確認すること {#first-launch}

- ホームからプロジェクトを新規作成するか、UVのある対応モデルを読み込みます。最初は小さなテスト用モデルで、描画と保存を確認すると安心です。
- 表示言語は「ウィンドウ → 言語」で変更できます。パネル配置が分からなくなったら「ウィンドウ → レイアウトをリセット」を使います。
- 製品版と体験版は別々にインストールされ、設定と素材キャッシュも別です。**体験版は編集・プロジェクト保存に対応しますが、テクスチャの書き出しはできません。** 体験版で保存したプロジェクトは製品版で開けます。
- 素材一覧は本体に含まれます。ダウンロード対象の画像素材は初回使用時に通信が必要です。出先などで使う前に、[素材のダウンロードとオフライン利用](./materials.md#material-downloads)を確認してください。

## 更新前にバックアップする {#update-backup}

<GuideFlow kind="update-backup" />

1. 作業中のシーンを通常保存し、アプリを終了します。**プロジェクトフォルダー全体を別の場所へコピー**して残してください。`.harmos` だけをコピーするのではなく、読み込んだモデルや画像を含むフォルダーを保管します。持ち運び用には[パッケージ出力](./projects.md)も利用できます。
2. 自分で追加したブラシ・プラグインなども、配布元のファイルや別のバックアップを残します。新しい版で保存したシーンを古い版で開けるとは限らないため、更新前のコピーは上書きしないでください。
3. BOOTHから新しいバージョンの**同じ版（製品版／体験版）**のインストーラーを取得し、既存のインストール先へ実行します。同じ版のインストーラーは既存のインストールを更新します。
4. 起動後にバージョンを確認し、まずバックアップから用意したテスト用コピーで、モデル・画像・レイヤー・保存と再読み込みを確かめます。製品版では必要な書き出しも確認します。

### 更新のお知らせについて

起動時にインターネットへ接続できる場合、新しいバージョンのお知らせを確認します。**お知らせだけで、アプリ本体を自動ダウンロード・自動インストールするものではありません。**「ストアページを開く」からBOOTHへ進みます。「後で」は今回のお知らせを閉じ、「このバージョンをスキップ」はそのバージョンのお知らせを以後表示しません。

オフラインなどで確認できなくても起動を妨げません。お知らせが出ないことだけでは最新版と判断せず、BOOTHの商品ページも確認してください。

## バージョンと更新履歴を確認する {#version-changelog}

「**ヘルプ → HarmoFlowについて**」の上部にアプリのバージョンが表示されます。同じ画面の「**更新履歴**」タブで、そのアプリに含まれる変更一覧を確認できます。タイトルバーの角括弧内に表示される数字はビルド日時です。問い合わせ時は、製品版／体験版の別とバージョン、ビルド日時を一緒に記録してください。

購入条件は[購入前FAQ](../download.md#purchase-faq)、操作中の問題は[トラブルシューティング](./troubleshooting.md)を参照してください。

## 最初の1枚を描く

1. **モデルを読み込む**

   ファイルメニューから読み込むか、モデルファイルをウィンドウへドラッグ＆ドロップします。ホーム画面へのドロップにも対応します。

2. **編集するパーツを選ぶ**

   チャンネルパネルで対象を選びます。モデルをShift+Alt+右クリックして、その位置のパーツに切り替えることもできます。パーツが1つの場合、切り替えは無効です。

3. **レイヤーとツールを選んで描く**

   ペイントレイヤーを選び、Bキーでペイントツールに切り替えます。モデルの表面をドラッグして描きます。

4. **シーンを保存する**

   Ctrl+Sで作業を保存します。後からレイヤーやストロークを編集するためのデータです。

5. **テクスチャを書き出す**

   エクスポートパネルで出力先・形式・チャンネルを選び、画像を書き出します。

::: tip 自動ベイク
モデル読み込み時にメッシュマップを自動ベイクします。完了前に汚しを設定しても、生成後に反映されます。
:::

## 読み込めるモデル

FBX、OBJ、glTF／GLB、DAE、PLY、STL、3DS、BLENDに対応しています。テクスチャ制作に使うモデルにはUVを用意してください。

複数のモデルや画像をまとめてドロップした場合は、最初の対応モデルを開き、残りはProjectに取り込みます。ホーム画面では読み込み後に制作画面へ切り替わります。

## glTF／GLBの画像を引き継ぐ

glTF／GLBを読み込むと、対応する参照画像をProjectに取り込み、BaseColor・Normal・Metallic・Roughness・Emissionに自動で紐づけます。MetallicRoughness画像はRoughnessとMetallicへ分離し、対応する色・強度も反映します。外部の形状データと画像も保存対象になるため、プロジェクト保存後は元フォルダーから独立して開けます。差し替えには「手動テクスチャ紐づけ」を使います。これはレイヤーの画像Fillとは別です。

### 自動で引き継げない場合

読み込めない画像はコンソールに警告が出ます。読み込めた対応画像は適用されます。読み込んだAO画像の専用チャンネル表示・適用には未対応で、自動ベイクするAOメッシュマップとは別です。自動紐づけはUV0が対象です。UV0以外の参照やKHR_texture_transformなどのテクスチャ座標拡張を持つ画像は自動紐づけされず、警告が記録されます。形状バッファなど、モデル本体に必要なファイルが欠けている場合は、モデルの読み込み自体が失敗することがあります。
