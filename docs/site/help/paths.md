# パスを描く・編集する {#paths}

<GuideMedia name="path-settings" />

## パスを作成する

Pでパスツールへ切り替え、モデル上をクリックしてアンカーを置きます。Enterで開いたまま確定、Cで閉じる、Fで閉じて塗り、Escでキャンセルします。作図中のDelete / Backspaceは最後のアンカーを取り消します。始点クリックでも閉じられます。

確定済みパスはクリックして再編集できます。アンカーやハンドルをドラッグして輪郭を整え、曲線上のクリックで点を追加、Deleteで選択点を削除します。最後のアンカーをクリックして出力ハンドルを引っ込めると角を作れます。パス外のクリック・Enter・Escで再確定します。UVエディタでも島の位置を確認しながら編集できます。

<GuideMedia name="edit-path" />

## 塗りと二重の枠線

パスパネルで塗り、外側枠線、内側枠線を個別に設定します。塗りには角の丸い／尖った設定と不透明度、枠線には幅・硬さ・不透明度があり、それぞれ描画チャンネルを選べます。色見本の交換や「なし」への切替で、線だけ・塗りだけの表現にもできます。「パスを再ベイク」で反映を更新できます。

パスの塗り・外側線・内側線には、それぞれ別のマテリアル素材を使えます。対応するスウォッチを選び、「素材」から選択するか、素材ブラウザーからドラッグしてください。素材ブラウザーのクリックでも、選択中の塗り／線へ割り当てられます。「単色」で元の色に戻せます。素材のマップや重ね合わせを保持し、線幅・不透明度はパスごとに調整できます。シーン保存とUndo／Redoに対応します。
