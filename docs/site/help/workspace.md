## パイメニューでツールを切り替える {#pie-menu}

Ver.0.1.1では、3DビューとUVキャンバスで、カーソルの周囲にパイメニューを開けます。

1. 3DビューまたはUVキャンバス上で、右ボタンを押します。
2. 右ボタンを押したまま、使いたい項目の方向へスライドします。
3. 右ボタンを離すと、その項目が選択されます。取り消すときはEscを押します。スライドせずに離した場合も選択せずに閉じます。

ブラシペイントや色混ぜ・ぼかし、UVシェル塗りなどを、手元で切り替えられます。カメラ操作やブラシサイズ変更など、設定済みの右ボタン操作が優先される組み合わせでは、パイメニューは開きません。キーとマウスの一覧は[ショートカット早見表](./shortcuts.md)を参照してください。

パイメニューの呼び出しは固定操作です。開かないときは、Ctrl・Shift・Altなどの修飾キーを離し、描画や文字入力などの操作を終えてから試してください。

## テクスチャセットとメッシュパーツ

HarmoFlowのテクスチャセットはメッシュパーツ単位です。同じマテリアルを使っているパーツも、別々のテクスチャセットとして扱います。

通常のブラシやスタンプは、選択中の既存レイヤーが属するテクスチャセットに描かれます。ほかのパーツへ描くには、一覧からセットを切り替えるか、モデルをShift+Alt+右クリックします。アセットブラウザーから新たに塗るマテリアルも、現在選択中のテクスチャセットが対象です。塗り始める前に対象のセットを選んでください。ほかのセットには自動で適用されません。

## パネルでできること

| パネル | できること |
| --- | --- |
| レイヤー | ペイントやFillを重ね、表示・不透明度・合成を調整 |
| チャンネル | パーツの選択、作業解像度、各チャンネルの確認 |
| テクスチャセット設定 | レイヤー横のタブ。チャンネルとメッシュマップの確認 |
| UVエディタ | 選択中のパーツのテクスチャとUVワイヤーを確認 |

## パネルを開く・配置を戻す

閉じたパネルは「ウィンドウ」メニューから再表示できます。配置を戻したいときは「レイアウトをリセット」を使います。操作の補足は各項目にカーソルを重ねると表示されます。
