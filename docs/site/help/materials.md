## 画像をFillに使う

マテリアルレイヤーのプロパティで対象チャンネルを有効にし、「画像Fill」で画像を選ぶか、プロジェクトからドロップします。画像指定はそのチャンネルの一定値を置き換えます。数値チャンネルは画像のR、透明度はアルファを使います。「解除」で画像を外せます。

UV変換には繰り返し数、位置、回転、画像の繰り返しがあり、そのレイヤーの画像に共通で適用されます。「UVをリセット」で初期値へ戻せます。「高さからノーマルを生成」はシーン全体に作用します。指定したNormal画像を使う場合は、この自動生成をオフにします。

## パターンを作る

「パターンを追加」から汚し、錆、泥はね、擦り傷、埃、流れを選びます。画像そのものではなく設定を保持するので、後から分布を調整できます。

| 設定 | 調整するもの |
| --- | --- |
| 細かさ・スケール | 模様の繰り返しと粒の大きさ |
| 量 | 模様が覆う割合 |
| コントラスト | 模様の境界の強さ |
| シード | 同じ傾向のまま配置を変える数値 |
| オクターブ | ノイズに重ねる細部の段数 |
| 色の変化 | 模様内の色むら |
| レリーフ | Heightに加える凹凸 |
| 反転 | 模様の分布を反転 |
| 形状による配置・強さ | 凸・凹・AOを用いた配置。詳しくは[汚し](/guide#weathering) |

パターンが使用するチャンネルでは画像Fillよりパターンが優先されます。画像が反映されないときは「パターンが使用中」の表示とチャンネルの有効状態を確認してください。

## マテリアルプリセット

現在のマテリアルを登録し、プロジェクトパネルのプリセットから再利用できます。選択中のレイヤーへ適用する操作と、素材を追加して使う操作を使い分けます。保存したプリセットは右クリックから更新・名前変更・削除でき、お気に入りにも登録できます。内蔵プリセットとユーザー保存プリセットでは編集できる操作が異なります。

素材ブラウザーでマテリアルを選ぶと、ブラシ・ポリゴン塗り・UVシェル塗りで部分的に塗れます。塗布済みの素材レイヤーやフォルダーを選ぶと、同じ素材で塗り足せます。詳しくは「面やUV島を塗る」を参照してください。
