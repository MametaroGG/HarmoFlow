## 画像をFillに使う

マテリアルレイヤーのプロパティで対象チャンネルを有効にし、「画像Fill」で画像を選ぶか、プロジェクトからドロップします。画像指定はそのチャンネルの一定値を置き換えます。数値チャンネルは画像のR、透明度はアルファを使います。「解除」で画像を外せます。

UV変換には繰り返し数、位置、回転、画像の繰り返しがあり、そのレイヤーの画像に共通で適用されます。「UVをリセット」で初期値へ戻せます。「高さからノーマルを生成」はシーン全体に作用します。指定したNormal画像を使う場合は、この自動生成をオフにします。

## パターンを作る

「パターンを追加」から汚し、錆、泥はね、擦り傷、埃、流れを選びます。画像そのものではなく設定を保持するので、後から分布を調整できます。

| 設定 | 調整するもの |
| --- | --- |
| 細かさ・スケール | 模様の繰り返しと粒の大きさ |
| 量 | 模様が覆う割合 |
| コントラスト | 模様の境界の強さ |
| シード | 同じ傾向のまま配置を変える数値 |
| オクターブ | ノイズに重ねる細部の段数 |
| 色の変化 | 模様内の色むら |
| レリーフ | Heightに加える凹凸 |
| 反転 | 模様の分布を反転 |
| 形状による配置・強さ | 凸・凹・AOを用いた配置。詳しくは[汚し](/guide#weathering) |

パターンが使用するチャンネルでは画像Fillよりパターンが優先されます。画像が反映されないときは「パターンが使用中」の表示とチャンネルの有効状態を確認してください。

## マテリアルプリセット

現在のマテリアルを登録し、プロジェクトパネルのプリセットから再利用できます。選択中のレイヤーへ適用する操作と、素材を追加して使う操作を使い分けます。保存したプリセットは右クリックから更新・名前変更・削除でき、お気に入りにも登録できます。内蔵プリセットとユーザー保存プリセットでは編集できる操作が異なります。

素材ブラウザーでマテリアルを選ぶと、ブラシ・ポリゴン塗り・UVシェル塗りで部分的に塗れます。塗布済みの素材レイヤーやフォルダーを選ぶと、同じ素材で塗り足せます。詳しくは「面やUV島を塗る」を参照してください。

## 素材のダウンロードとオフライン利用 {#material-downloads}

現在の配布版には素材一覧とプレビューが含まれますが、ダウンロード対象の画像マテリアルの元画像は含まれません。画像マテリアルは初めて使うときに取得します。**ダウンロードアイコン付きの素材は、まだ画像の取得が必要です。** 一覧をオフラインで見られても、その素材をオフラインで使えるとは限りません。

プロシージャル素材と、自分で取り込んだ画像は、マテリアルのダウンロードなしで使えます。取得済みのキャッシュは製品版と体験版で別々に管理されます。

1. オンラインの状態で、ライブラリから使いたい素材を選びます。未取得の素材を使う操作をするとダウンロードが始まります。
2. 作業前に準備するなら、素材を右クリックして「オフライン用にダウンロード」を選びます。これは画像を準備する操作です。
3. プロジェクトパネルの「ダウンロード中 → データを確認中 → 画像を展開中」が完了するまで待ちます。
4. 取得後はキャッシュを使ってオフラインでも利用できます。ダウンロード中にシーン・レイヤー・ツールなどを切り替えた場合は、完了後に素材をもう一度選び、現在の対象へ適用してください。

別の素材を取得したいときは、進行中のダウンロードが終わるのを待つか「取得をキャンセル」を使います。オフラインにする前に、必要な素材をそれぞれ取得しておきましょう。

### 失敗・キャンセルしたとき {#material-download-retry}

- 通信状態を確認して、プロジェクトパネルの「再試行」を押します。キャンセル後も再試行できます。
- エラー表示にマウスを重ねると、詳細がある場合は確認できます。「閉じる」は失敗・キャンセルの表示を閉じます。
- 「配布元にダウンロードファイルが登録されていない」と表示される素材は、通信の再試行だけでは取得できません。
- 取得済みなのに適用されないときは、素材を再選択し、対象のレイヤーと有効なチャンネルを確認してください。

### ダウンロード済み素材を削除する {#material-cache-uninstall}

ディスクの空きを増やすには、素材を右クリックして「ダウンロード済み素材をアンインストール...」を選びます。確認画面に表示される素材名と容量を見てから実行してください。

| 削除するもの | 残るもの |
| --- | --- |
| その素材のダウンロード済みデータ（キャッシュ） | 作品に取り込み済みの画像、素材一覧とプレビュー、旧インストールに同梱画像がある場合はその画像 |

**作品に取り込み済みの画像は消えません。** 素材も一覧から消えないので、次に使うときに再ダウンロードできます。旧インストールの同梱画像が残っている環境では、それを利用できる場合があります。現在の配布版に画像マテリアルの元画像が同梱されているという意味ではありません。オフラインでこれから使う素材のキャッシュは残してください。

ダウンロードや描画・他の処理の途中は削除できません。削除ボタンが無効な場合は処理の完了と削除できるデータの有無を確認します。追加ファイルやリンクがあるため安全に削除できないと表示された場合は、フォルダーごと手作業で消さず、表示された理由を確認してください。削除に失敗した場合は保存先の権限や他のアプリで使用中でないかを確認して再試行します。
