# 画像を書き出す {#export}

## 書き出しとシーン保存の違い

<GuideMedia name="export-settings" />

エクスポートパネルで出力先・形式・解像度を選択します。PNG、JPG、TGA、EXR、PSDなどに対応しています。編集を再開するためのシーン保存と、完成したテクスチャの画像出力は別の操作です。

形状マップだけを取り出す場合は、メッシュマップのベイク画面からPNG出力を使います。マップはリニアデータです。出力先には新しいフォルダーを作成します。

## 出力設定

1. 「チャンネル」で書き出し解像度を選びます。
2. 「エクスポート」で出力先フォルダー、ベース名、形式を指定します。
3. 必要なチャンネルをオンにし、ノーマルマップの規約を選びます。
4. 「テクスチャをエクスポート」を押します。

| 項目 | 選び方 |
| --- | --- |
| PNG | 画像の劣化を避けて保存したいときの基本形式 |
| JPG | 色画像の容量を抑える用途。非可逆圧縮のため数値マップにはPNGなどを選ぶ |
| TGA | TGAを要求する制作環境へ渡す場合 |
| EXR | EXRを扱う制作環境へ渡す場合。元の編集データの精度が形式変更だけで増えるわけではない |
| PSD | チャンネルごとに画像レイヤー付きPSDを作成。保持する情報と制限は下記を参照 |
| OpenGL / DirectX | 接線空間Normalの緑チャンネルの向きを選択。出力先の設定と合わせる |

## PSDに保存される情報

元のストロークや補正値を後から編集する場合は、HarmoFlowのシーン（.harmos）も保存してください。

### 保持する情報

- ペイント・塗りつぶし・パスは、元の名前・順序・表示状態を持つ画像レイヤーとして保存します
- 不透明度と合成モードはPSD上でも編集できます。通常・乗算・加算・オーバーレイに対応し、加算は「覆い焼き（リニア）- 加算」になります
- フォルダーは階層・名前・表示状態・折りたたみ状態を保持し、通過合成で保存します

### 画像に焼き込む情報

マスクとクリッピングは、画素の透明度に焼き込みます。Paint・Fill・Pathの通常チャンネル合成には、合成差を埋めるためだけの補正レイヤーを追加しません。生成ノーマル・法線のUV境界処理・立体的な高さの結果は、必要に応じて別レイヤーに保存します。

調整レイヤーも対象チャンネルの画像レイヤーとしてPSDへ書き出します。HarmoFlowの調整パラメーターをPhotoshopの調整レイヤーとして保持する形式ではありません。補正値を後から編集するには.harmosも保存してください。補正用の画像は、その位置より下の合成結果を前提にするため、PSD側で下地を変更してもHarmoFlowの補正が自動再計算されるわけではありません。

## パーツをまとめて書き出す

通常の画像形式はチャンネル別に出力されます。初期設定では「同じマテリアルのパーツをまとめる」が有効です。同じマテリアルを使うパーツのUV領域を1組にまとめ、別のマテリアルは分けて書き出します。UVが重なる部分は先頭パーツの描画を優先します。重なったUVに別々の絵を描いている場合は、この設定をオフにしてパーツごとに書き出してください。

## UVの外側をどう書き出すか

「環境設定 → VRAM → テクスチャ」の「メッシュUVの外側」で、元テクスチャで補完／透明／テクスチャ全体を保持を選べます。保存方式の変更は次のモデル読み込みか解像度変更で反映されます。「透明」の書き出しはスパースGPU非対応でも利用できます。元テクスチャ補完は通常の出力と、レイヤー付きPSDの背景・統合画像に適用されます。
