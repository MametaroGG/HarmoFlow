# ベイクされた形状情報を見る {#mesh-maps}

## メッシュマップを確認する

<GuideMedia name="mesh-maps" />

「テクスチャセット設定」のメッシュマップ一覧に、自動生成されたマップが表示されます。サムネイルをクリックすると拡大でき、「UVエディタに表示」で背景に切り替えられます。

## 4種類のマップの見方

| マップ | 読み方 |
| --- | --- |
| 曲率 | 白が凸、灰色が平面、黒が凹 |
| アンビエントオクルージョン（AO） | 白は遮蔽なし。暗い部分ほど遮蔽されている |
| オブジェクト空間法線 | モデル内での面の向きをRGBで表す。チャンネルのNormalとは用途が異なる |
| 位置 | モデル全体の境界内の位置をRGBで表す |

## ベイクの解像度と対応範囲

自動ベイクは各テクスチャセットにつき1024pxです。「再ベイク」で更新できます。手動出力の解像度は自動ベイクには適用されません。

1. 「ファイル → メッシュマップをベイク...」を開き、「テクスチャセット番号」と「解像度」を選びます。解像度は256 / 512 / 1024 / 2048pxから選べます。
2. 「メッシュマップをベイク」を押して完了を待ちます。
3. 表示されたテクスチャセットと画像サイズを確認してから「4種類のマップをPNG出力...」を押します。

解像度の選択だけでは、表示中の自動ベイク結果は変わりません。

::: details 現在の対応範囲
現在のモデルの全パーツから生成するセルフベイクです。AOは64本の半球レイ、最大距離はモデル対角長の15%です。曲率は面の角度とエッジからの距離で求めます。

UVは0〜1を対象とし、同一テクスチャセット内の重複UVでは最初の面を共有します。ハイポリからの転写、ケージ、UDIM、ID・厚み・Bent Normalのベイクは未対応です。


:::


### 手動ベイクとPNG出力 {#mesh-map-output}

手動ベイク画面は「テクスチャセット設定 → ベイク・出力...」からも開けます。「自動ベイク結果を使用（1024px）」で自動結果へ戻せます。PNGはリニアデータで、curvature.png・ao.png・object_normal.png・position.pngの4ファイルを新しいフォルダーへ出力します。前の出力は上書きしません。モデル変更の案内が出た場合は、現在の形状で再ベイクしてから出力してください。
