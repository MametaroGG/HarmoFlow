# 困ったとき {#troubleshooting}

## UVが枠だけに見える

::: details 対処方法
「ワイヤー設定」の表示を「三角形」に変更します。UVシェル表示では島の外周だけが描かれます。


:::

## ワイヤーが濃い・密集して見える

::: details 対処方法
線幅と不透明度を下げるか、UVシェル表示に切り替えます。テクスチャ自体を確認したいときはUVワイヤーをオフにできます。


:::

## パーツを切り替えられない

::: details 対処方法
読み込んだモデルにパーツが1つしかない場合、切替欄は無効です。複数パーツではチャンネル上部から選択できます。


:::

## メッシュマップが表示されない

::: details 対処方法
自動ベイクが完了するまで待ちます。エラーが表示されている場合は内容を確認し、「再ベイク」を試してください。読み込むモデルを変更すると古い処理結果は破棄されます。


:::


## レイヤーパネルの表示

レイヤーパネルの歯車メニューで内容のプレビュー表示を切り替えられます。この設定はUIレイアウトに保存されます。プレビューには、描画済みマテリアルのBaseColorを小さなUV画像で表示します。各行のためにレイヤー全体を再ベイクするのではなく、GPUベイクの結果を再利用します。

フォルダー行はペイントレイヤーの行より高さを抑えて表示され、選択中の行には内側に枠線が付きます。レイヤー名の上半分または下半分へドラッグすると、対応する挿入位置に線が表示されます。フォルダーの中央へドラッグすると枠線が表示され、フォルダー内へ移動します。フォルダーの上端・下端では挿入位置に線が表示され、子レイヤーを含むフォルダー全体の前後へ並べ替えられます。フォルダーを移動しても子レイヤーは保持され、Undo/Redoにも対応します。
