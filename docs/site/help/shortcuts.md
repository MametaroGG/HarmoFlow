# ショートカット早見表 {#shortcuts}

## キー設定を確認・変更する

操作するパネルやツールによってキーの意味が変わります。入力欄を編集中はツール操作を受け付けない場合があります。

「環境設定 → キーコンフィグ」で操作名や条件を検索し、キー・マウスの割り当てを変更できます。「＋」がある操作には別の割り当ても追加できます。一般・編集・ファイル・ツール・描画・レイヤー・UVエディタなどが対象です。固定操作は変更できません。通常の左クリックや、同時に使う操作と衝突する組み合わせは登録できません。

## 操作とキー・ジェスチャー

以下は既定の割り当てです。変更済みの場合は、キーコンフィグの表示を確認してください。

| 操作 | キー・ジェスチャー |
| --- | --- |
| ペイント / 色混ぜ・ぼかし / パス / テキスト | B / U / P / T |
| カメラ回転 | Alt+左ドラッグ |
| カメラズーム | ホイール、Alt+右ドラッグ、Ctrl+左ドラッグ（右か上で拡大、左か下で縮小） |
| カメラパン | 中ドラッグ、Space+左ドラッグ |
| レイヤーをコピー／切り取り／貼り付け／複製 | Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D（レイヤーパネルがフォーカス中） |
| レイヤー削除 | Delete（レイヤーパネルがフォーカス中） |
| カーソル下のテクスチャセットを開く | Shift+Alt+右クリック |
| UVキャンバスのパン | 中ドラッグ、またはSpace+左ドラッグ |
| ブラシサイズ | [ / ]、Ctrl+Alt+左または右ボタンで水平ドラッグ |
| スポイト | ペイント中にCtrl+Shift+左ボタン、離して採用 |
| 選択を追加・解除 | 選択ツールでShift+クリック |
| 開いたパスを確定 / 閉じる / 閉じて塗る | Enter / C / F（C・Fはパス作図中、ビューポート上） |
| パス作図をキャンセル / 作図中の最後のアンカーを削除 | Esc / DeleteまたはBackspace |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Y |
| 保存 / 増分保存 | Ctrl+S / Ctrl+Alt+S |
| 環境設定 | Ctrl+, |
| ビューポート撮影 | F12 |
| エンジン一時停止 | Shift+Esc |

DeleteまたはBackspaceは、パス作図中は最後のアンカーを削除します。既存のパスを編集中は、選択したアンカーを削除します。
