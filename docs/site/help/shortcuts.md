# ショートカット早見表 {#shortcuts}


## キーボードとマウスの図で確認する {#visual-key-config}

Ver.0.3.0のキーコンフィグでは、キーボードとマウスの図から割り当てを確認・編集できます。キーによる絞り込み、移動キー・テンキーの表示、日本語・英語・韓国語・中国語の配列表示に対応しています。長いショートカットの見切れも改善しました。

保存済みの設定がある場合は、下の初期割り当て表よりもアプリのキーコンフィグ表示を優先してください。

### 選択ツールの操作（Ver.0.3.0） {#selection-tool-shortcuts}

Ver.0.3.0ではMが選択範囲、Sがブラシ系ツールのシンメトリー切替です。Ctrl+Tは選択部分の変形、Kはレイヤー移動を呼び出します。長方形・楕円・投げ縄・折れ線・選択ペン・選択消し・シュリンク・メッシュ選択など、個別の選択ツールには初期キーがありません。ツール列・パイメニューから選ぶか、キーコンフィグで割り当ててください。旧版のV・W・E・Rなどを初期キーとして使わないでください。

- 長方形・楕円の選択中にShiftを押すと、正方形・正円にできます
- 選択ペン・選択消しは筆圧とブラシサイズのショートカットに対応します。現在の割り当てはキーコンフィグで確認してください
- 選択した塗りは移動・回転・拡縮できます。使い分けは[塗りの選択と変形](./brush.md#paint-selection-transform)を参照してください
## キー設定を確認・変更する

「環境設定 → キーコンフィグ」では、左側で「操作名」「ショートカット」の検索方法を切り替え、操作を選びます。右側の「選択した操作」に現在の割り当てが表示されます。割り当てのボタンをクリックして編集し、「＋ 追加」で別の割り当てを追加します。未設定の操作は一覧に「未割り当て」と表示されます。

「キーボード・マウス」の図では、色付きのキーが割り当て済みです。キーを選ぶと操作を絞り込めます。配列の選択欄とCtrl・Shift・Altの表示があり、「移動キー・テンキー」は折りたたみ欄にまとまっています。

設定画面では「既定に戻す」「削除」「キャンセル」を使えます。固定操作は変更できません。通常の左クリックや、同時に使う操作と衝突する割り当ては登録できません。使いたいキーが別の操作に割り当てられている場合は、先にその割り当てを見直してください。

以下は、操作一覧とキーボード・マウスの図を備えたキーコンフィグ画面です。

キーの追加・変更・削除・既定へのリセットはその場で保存されます。

### パス

C・Fはパス作図中、ビューポート上の操作です。DeleteまたはBackspaceは作図中の最後のアンカーを削除します。既存のパスを編集中は、選択したアンカーを削除します。

Escは作図中のパスを取り消します。3Dビューで確定済みのパスを再編集中の場合は、編集内容を残して再編集を終えます。

「パスを閉じる」の初期登録はCですが、「透明色を切り替え」もCを使います。保存済み設定の読込みで「パスを閉じる」が未割り当てになる場合があります。「未割り当て」と表示されている場合は、競合しないキーを割り当ててください。

| 操作 | キー・マウス操作と条件 |
| --- | --- |
| 開いたまま確定 | Enter<br>作図中、または3Dでパスを再編集中 |
| パスをキャンセル | Esc<br>作図中、または3Dでパスを再編集中 |
| 直前のアンカーを削除 | Delete / Backspace<br>作図中 |
| パスを閉じる | キーコンフィグで確認（初期登録：C）<br>作図中・3Dビュー上 |
| 閉じて塗り | F<br>作図中・3Dビュー上 |
| 選択アンカーを削除 | Delete / Backspace<br>アンカー選択時。3Dビュー／UVエディタ |
| 角と曲線を切り替え | 左ダブルクリック<br>3Dビューで再編集のために開いたパスのアンカー上 |
